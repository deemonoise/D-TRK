# D-TRK для Anbernic RG35XXSP с KNULLI

[English](README.md)

## Установка и запуск

1. Распакуйте `d-trk-rg35xxsp.zip` в `/userdata/roms/ports/`. Рядом должны лежать `D-TRK-RG35XXSP.sh` и каталог `d-trk-rg35xxsp/`.
2. В KNULLI выберите **Start → Game Settings → Update Gamelists**. Откройте **Ports → D-TRK-RG35XXSP**. Если для пункта задано имя **D-TRK** в метаданных KNULLI, откройте его под этим именем.
3. При первом запуске открывается демопроект. Нажмите **Start** для воспроизведения и ещё раз для остановки. **FILE → New** открывает выбор шаблона.

## Управление

| Кнопки | Действие |
|---|---|
| **L1 / R1** | Переключить экран. Из GRID кнопка L1 сразу открывает FILE. |
| **L2 / R2** | Переключить вкладку или вид GRID. В **MIX → X → Track controls** выбрать дорожку. |
| **Крестовина** | Переместить курсор или выделение. |
| **A / B** | Подтвердить или вернуться. В GRID кнопка A ставит ноту, **A + стрелки** правят значение. |
| **X / Y** | Открыть контекстное меню или выполнить клик энкодера. |
| **Select + A / B** | Очистить шаг или выделение в GRID, отменить правку в GRID или SONG. Select работает как Shift. |
| **Start**, **Vol− / Vol+** | Запуск и остановка, громкость средствами KNULLI. |

В **MIX** стрелки вверх и вниз регулируют мастер-громкость, влево и вправо — кроссфейдер. В **Track controls** стрелки управляют громкостью и панорамой дорожки, **A** включает solo, **B** — mute.

Для выхода сохранитесь через **FILE → Save** и выберите **Quit tracker**. Если есть несохранённые правки, **Keep editing** возвращает к проекту.

## Экран, звук и запись

Лаунчер использует SDL Mali с резким текстом на штатном экране 640 × 480. Звук идёт через системное ALSA-устройство `default` с маршрутом KNULLI/PipeWire.

В **MIX → X → Record…** доступен **RESAMPLE** для записи звука самого трекера. Если транспорт остановлен, нажмите **Start** после запуска записи. В лаунчере RG35XXSP источники **MIC** и **LINE** отключены. Надпись **RESAMPLE (NO SHIELD)** в списке источников означает, что доступна запись внутреннего звука.

## Файлы проектов

Данные хранятся в `/userdata/saves/d-trk-rg35xxsp/`. Для переноса проекта скопируйте `projects/ИМЯ.mtp` и одноимённую папку `projects/ИМЯ/`, если она есть. В ней лежат сэмплы и пользовательские волновые таблицы. Чтобы перенести все данные, закройте трекер и скопируйте весь каталог. MIDI для импорта кладите в `midi/`, WAV — в `samples/`.

Для передачи по Wi-Fi узнайте IP в **FILE → SYSTEM → Network file transfer…**. Экран показывает общую подпись `saves/d-trk/`. Фактическая папка проектов RG35XXSP в ресурсе `smb://IP/share` — `saves/d-trk-rg35xxsp/`. Если используете SCP, укажите `/userdata/saves/d-trk-rg35xxsp/`.

## Сборка для RG35XXSP

Для сборки SDL нужны компилятор C++17, Make и SDL2 с `sdl2-config` в PATH. Выполните команды из корня репозитория.

```sh
make -C ports/rg35xxsp -j4 all check-navigation
target/rg35xxsp/native/d-trk --self-test
ports/rg35xxsp/package.sh
```

Последняя команда собирает ARM64-архив через Docker. Передайте путь к готовому ARM64 ELF, чтобы только упаковать его. Архив появится в `target/brick/d-trk-rg35xxsp.zip`. Прежняя команда `DTRK_TARGET=rg35xxsp ports/brick/package.sh` также работает.

## Диагностика

- **Пункт отсутствует в Ports.** Проверьте, что `D-TRK-RG35XXSP.sh` и папка `d-trk-rg35xxsp/` лежат прямо в `/userdata/roms/ports/`, затем обновите список игр.
- **Permission denied.** Выполните `chmod +x /userdata/roms/ports/D-TRK-RG35XXSP.sh /userdata/roms/ports/d-trk-rg35xxsp/d-trk`.
- **Нет звука или сразу возвращается меню.** Проверьте громкость и выход звука в KNULLI. Ошибки SDL или загрузки приложения ищите в `/userdata/saves/d-trk-rg35xxsp/launcher.log`.
