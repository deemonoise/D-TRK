# D-TRK для Anbernic RG351V на ArkOS

[English version](README.md)

## Установка и запуск

1. Распакуйте `d-trk-rg351v.zip` в каталог `ports/` карты, с которой ArkOS открывает игры. Это `/roms/ports/` или `/roms2/ports/`, если игры лежат на второй карте.
2. Рядом должны находиться `D-TRK.sh` и папка `d-trk-rg351v/`. Перезапустите EmulationStation из его меню, затем откройте **Ports → D-TRK**.
3. При первом запуске откроется демо. Нажмите **Start** для воспроизведения. Чтобы вернуться в ArkOS, выберите **FILE → Quit tracker**.

Порт использует SDL2, KMSDRM для изображения и ALSA для звука. На экране 640×480 сохраняются пропорции интерфейса 3∶2, а текст отрисовывается в разрешении экрана.

## Управление

| Кнопки | Действие |
| --- | --- |
| L1 / R1 | Переключение экранов |
| L2 / R2 | Переключение вкладок или видов GRID. В режиме управления дорожками MIX выбирают дорожку |
| Крестовина | Перемещение курсора. При редактировании чисел влево/вправо меняют значение на 1, вверх/вниз — на 10, если параметр допускает крупный шаг |
| A / B | Подтвердить / назад |
| X / Y | Контекстное меню / щелчок энкодера |
| Select | Shift. В GRID Select + A очищает, Select + B отменяет правку |
| Start | Запуск или остановка воспроизведения |

Проекты, сэмплы, пресеты и журнал запуска хранятся в `saves/d-trk-rg351v/` на той же карте. В **FILE → SYSTEM → Network file transfer…** показаны адрес и каталог данных. Для SSH включите **Options → Enable Remote Services** в ArkOS.

Для USB MIDI используйте порт USB OTG. В штатной ArkOS для RG351V нет служб Bluetooth и PipeWire, которые D-TRK использует для BLE MIDI в KNULLI.

## Сборка

Соберите общий SDL-порт кросс-компилятором Linux ARM64 с libc, совместимой с вашей версией ArkOS. Передайте бинарник в `ports/rg351v/package.sh /путь/к/d-trk`. Архив появится в `target/rg351v/d-trk-rg351v.zip`.
