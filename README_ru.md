# D-TRK

16-дорожечный трекер со встроенным синтезатором: **WT32-SC01 Plus** (ESP32-S3, экран 480×320 с тачем) и синт-плата **Teensy 4.1**.
16 паттернов, song mode, Fill (каждый N-й / Euclid / случайно) для нот, громкости и FX, сохранение на microSD, импорт MIDI-файлов.
Встроенный звук: FM, драм-машины 808 / 909, синтезатор SYNTH (пила / квадрат / треугольник и wavetable), сэмплер и chiptune, стерео 44,1 кГц через ЦАП PCM5102A и усилитель для наушников — каждая дорожка играет во внутренний синт или во внешний MIDI.

Руководство пользователя: [docs/manual_ru.md](docs/manual_ru.md). English: [README.md](README.md).
Корпус для 3D-печати и схема питания от аккумулятора: [enclosure/](enclosure/README_ru.md).

## Архитектура

Устройство — две платы, связанные UART-линком:

- **WT32-SC01 Plus (ESP32-S3)** — трекер: секвенсор, интерфейс (экран, тач, энкодер, кнопки), MIDI OUT, Wi-Fi-страница прошивки.
- **Teensy 4.1 — синт-плата**: движок синтезатора (`mt::Synth` из `lib/core` внутри `AudioStream` библиотеки Teensy Audio, 44,1 кГц стерео, 32 голоса, из них до 16 «тяжёлых» — FM / DRUM / SYNTH WT), единственная карта microSD (SdFat, FAT32 или exFAT), банк сэмплов в её flash программ, ЦАП PCM5102A и усилитель для наушников MAX97220.
- **Линк**: `UART_NUM_2` ESP (GPIO TX 13 / RX 14) ↔ `Serial1` Teensy (RX1 0 / TX1 1), 3 Мбод, кадры COBS с CRC16, версия протокола 1. События синта идут с меткой времени и играются через 4 мс после отправки; состояние звука зеркалится диффом `SynthModel` (базовая структура `Project`); файлы — через удалённую `fs::FS`, которую обслуживает Teensy.

Статус-бар показывает состояние синт-платы в поле CPU: `NO SYNTH` (нет ответа: секвенсор и MIDI OUT работают, файлы и внутренний звук — нет), `SYNTH FW` (не совпала версия протокола — обновите синт-плату), `SYNC` (передаётся состояние звука), иначе — `CPU NN%` синт-платы. PROJ → SYS: Synth fw (версия), Link (счётчики), Card, CPU profile, Update synth (из `/firmware/teensy.hex` на карте).

## Подключение

Встроенные дисплей и тач уже разведены на плате; свой слот microSD платы не используется (карта — в Teensy). Энкодер, MIDI-выход и линк к Teensy подключаются к разъёму расширения платы (Extended IO), расширитель PCF8575 со всеми кнопками — к разъёму Debug. ЦАП и усилитель для наушников — на Teensy. Полная схема пайки (питание, MIDI, кнопки, линк, ЦАП, наушники) — [docs/wiring_ru.md](docs/wiring_ru.md).

| GPIO | Что подключить | Как |
|---|---|---|
| 10 | MIDI OUT | через резистор 10 Ом на Tip TRS-гнезда (см. схему ниже) |
| 11 | Энкодер, вывод A | второй конец — общий вывод энкодера на GND |
| 12 | Энкодер, вывод B | |
| 13 | Линк TX | на вывод 0 (RX1) Teensy, см. [Синт-плата](#синт-плата-teensy-41) |
| 14 | Линк RX | на вывод 1 (TX1) Teensy |
| 21 | запас | на вывод 2 Teensy (резерв, не используется) |
| 43 / 44 | SDA / SCL модуля PCF8575: кнопка энкодера, **Play**, **Shift**, кнопки дорожек | разъём Debug (TXD0 / RXD0), **обязательно**, см. ниже |
| 3.3V | MIDI OUT | через резистор 33 Ом на Ring TRS-гнезда |
| GND | Общий | общий вывод энкодера, вторые выводы кнопок, Sleeve TRS-гнезда, GND Teensy |

Входы A и B энкодера настроены с внутренней подтяжкой к 3,3 В (`INPUT_PULLUP`), внешние резисторы не нужны. Все кнопки — на расширителе PCF8575, у его выводов своя слабая подтяжка; кнопка замыкает вывод на GND.

### Энкодер

Обычный механический EC11 с кнопкой (4 импульса на щелчок). Средний вывод из тройки A–C–B — на GND, крайние — на GPIO 11 и 12. Если при вращении значение идёт в обратную сторону, поменяйте местами A и B.

Желательно поставить конденсаторы 10 нФ с A и B на GND — уменьшат дребезг. В прошивке есть аппаратный фильтр PCNT и программный дебаунс кнопок 5 мс.

### Кнопки на PCF8575 (обязательно)

Кнопка энкодера, Play, Shift и 8 кнопок дорожек MX с 8 светодиодами 3 мм в окнах свичей подключаются через расширитель PCF8575 на I2C (порт 0; порт 1 занят тачем). Дорожек 16, кнопки дорожек работают с видимой половиной (1–8 или 9–16, см. ниже). Если модуль не ответил при старте, прошивка запустится, но работать будут только тач и вращение энкодера: кнопка энкодера, Play, Shift и кнопки дорожек не действуют.

| PCF8575 | Подключение |
|---|---|
| SDA / SCL | GPIO 43 / 44 (TXD0 / RXD0 разъёма Debug) |
| VCC / GND | 3,3 В / GND (с того же разъёма) |
| INT | не подключать |
| A0–A2 | любые: прошивка ищет модуль на 0x20–0x27 |
| P00–P07 | кнопки дорожек 1–8, второй вывод на GND |
| P13 | кнопка энкодера (кнопка вала), второй вывод на GND |
| P14 | кнопка **Play**, второй вывод на GND |
| P15 | кнопка **Shift**, второй вывод на GND |
| P16 / P17 | кнопки **A** / **B** (под Shift / Play), второй вывод на GND; задел, прошивка их пока не использует |
| P10–P17 | катоды LED 1–8, кроме P13–P17 (заняты кнопками выше) |

Раскладка задаётся в `src/hw/pins.h` (`kTrackBtnBit`, `kTrackLedBit`, `kEncSwBit`, `kPlayBit`, `kShiftBit`): если вывод испорчен, кнопку можно перенести на вывод неустановленного LED (номер 8–15 = P10–P17), а этот LED пометить `0xFF`. Так как на P13–P17 теперь кнопка энкодера, Play, Shift, A и B, светодиодам 4–8 нужны другие свободные выводы, иначе они не ставятся (`0xFF`). На экземпляре автора P00 и P10 читаются как нажатые, поэтому кнопка 1 перенесена на P12, светодиоды не установлены, свободен P11.

Безопасный старт (держать Shift при включении) работает как раньше: прошивка читает Shift с расширителя до автозагрузки.

```
+3.3V ──[330 Ω]──|>|── P1x     (LED горит, когда P1x = 0)
```

- 330 Ом — для красных/жёлтых/зелёных LED (≈ 4 мА). Белым и синим при 3,3 В не хватает запаса: 47–68 Ом, яркость будет плавать от экземпляра.
- PCF8575 тянет вывод вниз (до 25 мА), вверх — только слабой подтяжкой, поэтому LED включаются только по катоду, как на схеме.
- Подтяжки SDA/SCL 4,7 кОм к 3,3 В обычно стоят на модуле — проверить.
- INT не нужен: прошивка опрашивает модуль каждые 5 мс. Найденный адрес печатается в USB-лог (`trackio: PCF8575 at 0x..`).
- Если площадки A0–A2 никуда не замкнуты и на модуле нет резисторов к GND, адрес висит в воздухе и может «гулять» — тогда замкнуть площадки на GND.
- GPIO 43/44 свободны, потому что лог и прошивка идут через родной USB (`ARDUINO_USB_CDC_ON_BOOT=1`). При старте загрузчик ESP32 печатает в TXD0 (GPIO 43) — модулю это не мешает.
- Кнопки и светодиоды работают с видимой половиной дорожек — 1–8 или 9–16; половину выбирает курсор (ушёл за 8-ю дорожку — показывается вторая половина, в шапке GRID — `1-8` / `9-16`). Кнопка N — выбрать дорожку N этой половины, Shift + N — mute той же дорожки (toast показывает настоящий номер, 1–16), в правке GRID — ввод ступеней лада. LED N — та же дорожка: горит у выбранной, вспыхивает при нотах; активность другой половины не показывается. Подробно — в [руководстве](docs/manual_ru.md#trackkeys).

### Синт-плата (Teensy 4.1)

```
WT32-SC01 Plus (Extended IO)        Teensy 4.1
  GPIO 13 (UART TX) ───────────────── 0  (RX1)
  GPIO 14 (UART RX) ───────────────── 1  (TX1)
  GPIO 21           ───────────────── 2  (запас, не используется)
  5V (выход IP5306) ───────────────── VIN
  GND               ───────────────── GND
```

- Обе платы на 3,3 В, согласование уровней не нужно; выводы Teensy не 5 В-толерантны.
- Перемычку VUSB–VIN на обороте Teensy разрезать, чтобы USB компьютера и IP5306 не питали друг друга.
- Карта microSD ставится в слот Teensy. ЦАП — на I2S1 Teensy, см. [ЦАП](#цап-pcm5102a).

### MIDI OUT (TRS тип A, 3,3 В)

```
+3.3V  ──[33 Ω]── Ring   (MIDI DIN pin 4)
GPIO10 ──[10 Ω]── Tip    (MIDI DIN pin 5)
GND    ────────── Sleeve (MIDI DIN pin 2, экран)
```

- Распиновка TRS **тип A** (стандарт MMA): Tip = pin 5, Ring = pin 4. Для устройств типа B (некоторые Arturia, Novation) нужен переходник A→B или поменять Tip и Ring местами.
- Для 5-контактного DIN-гнезда: те же резисторы на pin 4 и pin 5, GND на pin 2.
- UART без инверсии, 31250 бод. Опционально можно поставить буфер 74HC14 (два инвертора последовательно) между GPIO10 и резистором 10 Ом.
- MIDI-входа нет: устройство всегда ведущее, отправляет clock, Start/Stop/Continue.

### Встроенная периферия (для справки)

| Узел | Пины |
|---|---|
| microSD (SPI) | CS 41, MOSI 40, CLK 39, MISO 38 — не используется (карта в Teensy), резерв |
| Тач FT6336U (I2C) | SDA 6, SCL 5, INT 7, RST 4 (общий с LCD) |
| Дисплей ST7796 | шина 8080, 8 бит (внутренняя разводка платы) |

GPIO 1, 2, 42 идут на встроенный приёмопередатчик RS485, на разъём выведены только линии A/B. GPIO 35, 36, 37 идут на встроенный усилитель NS4168 и разъём SPK; они не используются: динамик снят, звук идёт с ЦАП синт-платы (см. ниже). GPIO 43/44 (разъём Debug) заняты PCF8575.

## Звук

Встроенный синтезатор: 32 инструмента (FM — 8 машин; DRUM — 16 машин в духе TR-808 / TR-909; SYNTH — 2 осциллятора BL saw / square / tri или wavetable, sub, noise, sync; SAMPLE — сэмплы проекта, играют из flash; CHIP — pulse, triangle, saw, noise, metal, 16 wavetable; см. ниже), у каждого — фильтр и LFO; работает на синт-плате: 32 голоса, 44,1 кГц, стерео, панорама дорожки (TRACK → Pan, равномощная; хранится в проекте, у старых проектов — центр). Дорожка переключается в TRACK → Out: INT (по умолчанию в новом проекте) или MIDI. Звук идёт на ЦАП PCM5102A на I2S1 Teensy, а с него — на усилитель для наушников MAX97220; встроенный усилитель NS4168 и разъём SPK платы WT32 не используются. Мастер-громкость: вкладка MIX → MAIN, 0–200 % (выше 100 % — до +6 дБ, пики громких аккордов мягко подрезаются); сохраняется с проектом и попадает в Render WAV. Громкость выхода устройства: PROJ → SYS → Phones, 0–100 %, настройка устройства — хранится в памяти платы.

### ЦАП (PCM5102A)

Распространённый модуль (фиолетовый GY-PCM5102, чёрный «PCM5102 audio DAC v2» и подобные), на Teensy.

| Модуль ЦАП | Куда | Примечание |
|---|---|---|
| VIN | 3V3 Teensy (или 5 В) | на модуле свой стабилизатор (LDO) |
| GND | GND | звезда аудиоземли, см. ниже |
| BCK | Teensy 21 (BCLK1) | такт битов |
| LCK (LRCK, WS) | Teensy 20 (LRCLK1) | такт слов (левый / правый канал) |
| DIN | Teensy 7 (OUT1A) | данные |
| SCK (MCLK) | GND | без MCLK: PLL ЦАП берёт такт с BCK |
| FMT | L (GND) | формат I2S |
| FLT | L (GND) | фильтр с обычной задержкой |
| DEMP | L (GND) | де-эмфазис выключен |
| XSMT | H (3,3 В) | звук включён; при L выход заглушён |

На многих модулях FMT, FLT, DEMP и XSMT — перемычки-площадки H / L на обороте, у SCK своя площадка или вывод на гребёнке — сверьтесь с шелкографией своего модуля.

Синт-плата шлёт 44,1 кГц, 16 бит, стерео (`AudioOutputI2S` библиотеки Teensy Audio, BCK = 64 fs). Выходы L / R — линейный уровень: 2,1 В RMS на полной шкале, относительно земли (без постоянной составляющей). В отличие от прежнего выхода SPK, их можно подавать в микшер, звуковую карту, активные колонки или рекордер — с выходов L / R ЦАП (до усилителя) или с выхода усилителя для наушников.

### Усилитель для наушников (MAX97220)

```
ЦАП L   ── IN L+        OUT L ── Tip    (левый)
ЦАП GND ── IN L−        OUT R ── Ring   (правый)
ЦАП R   ── IN R+        GND   ── Sleeve (общий, здесь это GND)
ЦАП GND ── IN R−
плата 5V (или 3.3V) ── VCC     GND ── GND     SHDN ── VCC
```

- Входы дифференциальные: «+» каждого канала — на выход ЦАП, «−» — на GND ЦАП (AGND). Названия выводов на шелкографии модуля могут отличаться — сверьтесь.
- DirectDrive: выходы относительно земли, разделительные конденсаторы не нужны; Sleeve гнезда — на GND, как обычно.
- Питание: 5 В с выхода IP5306 после тумблера (та же линия, что питает платы) или 3,3 В. SHDN, если выведен, — на VCC (усилитель работает).
- Полная шкала PCM5102A 2,1 В RMS больше, чем усилитель может выдать: если звук хрипит или слишком громкий — убавьте Phones (PROJ → SYS) или поставьте делитель / потенциометр между ЦАП и входами усилителя.
- Земля: провода аудиоземли короткие, звезда у GND ЦАП: земли ЦАП, усилителя и гнезда наушников сходятся в одной точке, от неё один провод — на GND Teensy. Так в наушники не пролезает писк повышающего преобразователя IP5306.
- Перед первым включением — Phones (PROJ → SYS) на минимум, наушники не на ушах, затем поднимать.

Внутренний звук отстаёт от MIDI-дорожек на несколько миллисекунд: события играются через 4 мс после отправки по линку, плюс аудиобуфер (постоянно, без джиттера; пока не компенсируется). Нагрузку синт-платы показывает `CPU NN%` в правом углу статус-бара (жёлтый от 60%, красный от 85% или после срыва звука — слышимого щелчка).

### Сэмплы

- Сэмплы принадлежат проекту: у каждого проекта свой список (до **128**), инструмент (INST → Sample) выбирает только из него. На карте проект — это `/projects/NAME.mtp` и папка `/projects/NAME/` с его сэмплами (`<сэмпл>.wav`, моно, 16 бит). Папку пишет Save: недостающие и изменённые WAV записываются, файлы удалённых из проекта сэмплов удаляются. Не удалось записать папку — «SAMPLES NOT SAVED», проект остаётся несохранённым (`*`), следующий Save допишет.
- Перенос проекта на другую карту или трекер — скопировать `.mtp` и его папку (вынуть карту из Teensy и картридером). Load и автозагрузка подтягивают во flash сэмплы, которых там нет, из папки проекта (с прогрессом); не нашлось файла или он изменён — сэмпл помечается `MISSING` (молчит), toast «N SAMPLES MISSING».
- Банк сэмплов во flash программ Teensy (с 0x60200000, ~5,75 МБ, ≈ 1 мин моно при 44,1 кГц, до 128 записей) — кэш, из которого сэмплы играют. Одинаковые данные в разных проектах хранятся один раз. Когда места нет, импорт и загрузка сами вытесняют сэмплы других проектов (сначала большие) и уплотняют flash; иначе «BANK FULL». Кэш не зависит от карты, обновление прошивки синт-платы его не трогает.
- FILE → SAMPLES: строка `FREE n / m KB  CACHE k KB` (CACHE — место под сэмплы других проектов), **Import WAV…**, **Compact** (уплотнить flash), **Clear cache** (удалить из flash всё, чего нет в текущем проекте), затем сэмплы проекта: имя, длина, размер, красное `MISSING`. Клик по сэмплу — **Rename** (меняет имя и в инструментах; сэмпл MISSING переименовать нельзя) или **Delete** (убрать из проекта; файл удалит следующий Save).
- `/samples` на карте (создаётся сама) — библиотека для импорта, можно с подпапками до 4 уровней. Import WAV…: сначала папки (`name/`, клик — войти, `< Up (..)` — наверх), затем `.wav`; скрытые файлы (macOS `._*`) не показываются. Play на файле — прослушать (первые 8 с, повторный Play — стоп; транспорт в этом списке кнопкой Play не запускается). Импортированный сэмпл попадает в папку проекта при сохранении.
- WAV: PCM **8 / 16 / 24 бит**, моно или стерео (стерео сводится в моно), любая частота: выше 44,1 кГц понижается до 44,1 кГц, ниже хранится как есть. **Float и 32 бит не поддерживаются** («UNSUPPORTED WAV»).
- Import, Rename, Delete, Compact и Clear cache — только при остановленном воспроизведении (запись во flash Teensy ставит звук на паузу).
- Старые проекты (когда сэмплы были общими): при загрузке список строится из инструментов, сэмплы берутся из flash по старым именам. Сохраните такой проект один раз — появится его папка.

### FM

**FM** — 8 машин в стиле Model:Cycles: KICK, SNARE, METAL, PERC, TONE, CHORD, CLAP, HAT. Вместо операторов — 5 макросов: DECAY (длина), COLOR (яркость / индекс), SHAPE (вариант тембра; у CHORD — тип аккорда), SWEEP и CONTOUR (огибающая питча или индекса). Ударные играют one-shot (длина ноты и ADSR не важны, новая нота обрывает предыдущую), TONE и CHORD держат ноту (attack / sustain / release из ADSR). TONE может быть POLY, остальные машины моно на дорожке.

P-lock: fx `DEC`, `COL`, `SHP`, `SWP`, `CON` (0–127) задают макрос для ноты своего шага; на шаге без ноты — для звучащей ноты до следующей. Работают у FM, DRUM и SYNTH.

### KIT (драм-дорожка)

Тип инструмента **KIT** — 8 лейнов: каждый либо свой мини-сэмплер (сэмпл проекта, Volume, Pitch, Decay), либо ссылка на любой из 32 инструментов. Дорожка с KIT становится драм-дорожкой: в GRID вместо нот — 8 квадратиков на шаг, в правке — пэд из 8 кнопок (и кнопки дорожек 1–8) включают лейны. Лейн моно с choke, лейны звучат вместе. На MIDI-дорожке лейны уходят своими нотами (Note лейна) — для внешней драм-машины. Fx `ACC` — маска лейнов с полной громкостью, остальные на 60 %. Fill (NOTE) пишет в выбранный лейн. Подробнее — [руководство](docs/manual_ru.md#drumtrack).

### DRUM (808 / 909)

**DRUM** — 16 «аналоговых» машин: BD8, SD8, TOM8, CP8, RS8, CL8, CB8, HH8, CY8 (808) и BD9, SD9, TOM9, CP9, RS9, HH9, CY9 (909). Те же 5 слотов макросов и локи `DEC…CON`, но имена у каждой машины свои (TONE, SNAPPY, DRIVE, N.DEC, HP…); пустой слот — серый «-». DECAY есть у всех. Все машины one-shot и моно на дорожке: новая нота обрывает предыдущую (choke), note-off не важен; Attack, Decay, Sustain, Release, Mode, Glide серые. Нота C4 — базовая высота машины. Закрытый / открытый хэт — короткий и длинный DECAY. Тембры — приближение к оригиналам (хэты и тарелки 909 там сэмплы, здесь — синтез). FM, DRUM и SYNTH с WT-осциллятором вместе — не больше 16 голосов одновременно (лишний забирает самый старый).

### SYNTH (осцилляторы и wavetable)

**SYNTH** — «аналоговый» синтезатор: 2 осциллятора, у каждого режим **SAW**, **SQR**, **TRI** (без алиасинга, PolyBLEP) или **WT** (волновая таблица 64 кадра × 256 точек с мипмапами, позиция кадра — SHAPE), плюс sub (квадрат на −1 / −2 октавы от осц. 1), белый шум, hard sync осц. 2 от осц. 1, семитоны осц. 2 (±24) и своя AD-огибающая на SHAPE (Env>Shp ±). Огибающая громкости — ADSR, Mode POLY / MONO и Glide как у CHIP. Страницы INST: MAIN / ENV / **OSC** / **MOD** / FILT / LFO.

- 5 макросов на тех же слотах, что у FM / DRUM: **SHP1** (PW квадрата или кадр WT осц. 1), **SHP2** (то же для осц. 2), **MIX** (осц. 1 ↔ осц. 2), **DET** (detune осц. 2, ±50 центов), **SENV** (глубина env→SHAPE). Локи — fx `DEC`, `COL`, `SHP`, `SWP`, `CON` соответственно; LFO dest — SHP1…SENV.
- Таблицы: 8 вшитых (`*SAWSQR`, `*PWM`, `*SINSAW`, `*TRISQR`, `*FORMANT`, `*ORGAN`, `*SYNC`, `*BELL`) — строятся во flash-банк синт-платы при первом старте, работают без карты. Свои — **IMPORT…** в выборе таблицы (тап / клик по строке Table) из `/wavetables` на карте (с подпапками до 4 уровней): WaveEdit (кадры по 256 точек, до 64) и Serum / Vital (кадры по 2048 или чанк `clm`; больше 64 кадров — берутся равномерно). Одна таблица в банке — 96 КБ, в проекте до 32 таблиц. Занятое имя с другими данными получает суффикс `-2`, `-3`…
- Таблицы проекта Save пишет в `/projects/NAME/wt/<имя>.wav`, Load подтягивает недостающие во flash оттуда. Нет таблицы ни во flash, ни в папке — имя в INST красное, осциллятор молчит.
- Импорт — только при остановленном воспроизведении («STOP PLAYBACK FIRST»). 37 заводских пресетов (BASS, LEAD, PAD, KEYS, PLUCK, FX) на вшитых таблицах; свои — в `/presets/SYNTH/`.

### Фильтр и LFO

У всех типов в конце списка INST:

- **Filter** OFF / LP / BP / HP (SVF, 12 дБ/окт), **Cutoff** 20 Гц…14 кГц, **Reso** 0–127, **Flt env** ±6 октав со своими **Flt attack** / **Flt decay** (HOLD — держать), **Key track** 0–100 % (от C4). Фильтр стоит после всего голоса; OFF — обход, старые проекты звучат как раньше.
- **LFO** wave / rate / depth / dest — теперь на всех типах. Цели PITCH, VOL, CUTOFF — везде; DECAY…CONTOUR — только FM, DRUM и SYNTH (у SYNTH — SHP1…SENV).
- P-lock фильтра: fx `FLT` (cutoff) и `RES` (резонанс), 0–127, на любом INT-инструменте с включённым фильтром; на шаге без ноты — для звучащих голосов дорожки до следующей ноты.

### Drive, reverb, компрессор

- **Drive** (INST → FILT, первая строка): tanh-перегруз перед фильтром, лок `DRV`, цель LFO `DRIVE`.
- **Reverb**: Rvb send у инструмента (лок `RVB`), размер / затухание / уровень в PROJ. Стерео (Freeverb), буферы в RAM Teensy.
- **Компрессор** на весь встроенный звук (PROJ → Comp, Comp rel) с **sidechain** от дорожки (SC track, SC depth): поставьте SC track на бочку — микс «качает».
- **ARP**: fx `ARM` задаёт порядок (вверх, вниз, вверх-вниз, случайно) и число нот на шаг (1–8); ARP + CHD в одном шаге арпеджирует аккорд.
- **4 LFO** на инструмент (INST → LFO), каждый в Гц или синхронный с темпом (1/32 … 8 тактов), с перезапуском на ноте или свободный на дорожку от старта воспроизведения (с TEMPO — привязан к такту); fx шага `LFO` / `LFD` / `LFS` / `LFW` / `LFT` / `LFR` выбирают LFO, лочат depth / rate / wave / dest и сбрасывают фазу.
- **Lo-fi**: fx `BIT` (разрядность) и `SRR` (частота дискретизации) на ноту; **DJ-фильтр** на мастер (PROJ → FX).
- **Грув** паттерна (PROJ → SONG → Groove: MPC 54–66, SHUFFLE, PUSH, LAID BACK, DRUNK, BOOM BAP, HOUSE) и **Humanize** дорожки (TRACK → NOTE); условия `CND PRE / NEI`, нарастание/спад громкости у `RAT` (`4^`, `4v`).
- **Шаговый арп** `ARS` (INT и MIDI): ноты CHD (или ARP 0/x/y, или сама нота) в диапазоне 1–4 октав звучат отдельными нотами на следующих пустых шагах дорожки — каждый шаг или через N; до следующей ноты, OFF или смены паттерна. Список fx в GRID сгруппирован: ноты и арп, время, случайность, высота и громкость, звук, сэмпл, посылы, MIDI.
- **Velocity**: Vel>Cut (срез фильтра) и Vel>Dec (макрос DECAY) в INST → ENV.

Всё выключено по умолчанию: старые проекты и пресеты звучат как раньше. Пресеты с новыми полями — версии 4, старая прошивка их не откроет.

### Пресеты

Кнопка **PRESET** в шапке INST (или Shift + долгое нажатие энкодера) → **Load** / **Save**.

- **Load:** список типа инструмента (стрелки в шапке или Shift + поворот — другой тип). В корне — `[FACTORY]` (145 заводских: 33 CHIP, 37 FM, 38 DRUM, 37 SYNTH, по категориям; в одной категории или папке видно до 63 строк), затем свои папки и файлы. Выбранный пресет сразу ставится в инструмент и играет C4. **OK** — оставить, **CANCEL** (или долгое нажатие) — вернуть как было, **DEL** — удалить свой пресет.
- **Save:** **SAVE** — имя на клавиатуре (есть такой — спросит про перезапись), **+DIR** — новая папка, клик по файлу — записать поверх. Имя файла становится и именем инструмента.
- На карте: `/presets/CHIP|SAMPLE|FM|DRUM|SYNTH/…/NAME.mti` (204 байта, формат v3; старые v1 / v2 читаются), до 4 уровней папок внутри типа. SAMPLE-пресет ставит свой сэмпл, только если он есть в проекте, иначе сэмпл и Root остаются прежними. SYNTH-пресет хранит имена таблиц: таблицы нет в проекте — она импортируется из `/wavetables/<имя>.wav` (при остановленном воспроизведении), иначе имя красное.

Подробно (вкладка INST, браузер пресетов, таблица машин DRUM, SYNTH и таблицы, fx SLD/VIB/ARP/VSL/OFS/CUT, DEC/COL/SHP/SWP/CON, FLT/RES) — в [руководстве](docs/manual_ru.md#sound).

## Песня и живое исполнение

- **Song mode** (BANK): у элемента цепочки — паттерн, транспонирование мелодических дорожек (±24), число проходов (x1–x16) и сцена mute (S1–S8), которая ставится, когда элемент начинается. В строке цепочки `P05 +3 x2 S1`; Shift + поворот в правке строки выбирает поле.
- **Сцены mute**: 8 плиток под цепочкой — тап вызывает, долгий тап сохраняет текущие mute, Shift + тап очищает.
- **Своя длина дорожки** (TRACK → Pat len): дорожка крутит свои первые N шагов внутри паттерна (полиметрия); в GRID шаги дальше — серые, граница отмечена линией.
- **Fill**: Shift + Play держать во время игры — играют шаги с `CND FIL`, молчат с `NFL`; короткое нажатие — пауза, как раньше.
- **REC** (меню GRID): во время игры кнопки дорожек пишут ступени лада в звучащий шаг текущей дорожки (на драм-дорожке — лейны), Shift + N стирает.
- **PERF** (меню GRID): эффект, пока кнопка держится — 1 RAT 2, 2 RAT 4, 3 фильтр закрыт, 4 открыт, 5 delay, 6 короткий DECAY, 7 затухание, 8 mute.

Подробнее — [руководство](docs/manual_ru.md#song).

## Микшер и рендер

- **MIX** — отдельная вкладка внизу, рядом с TRACK: 8 полос половины дорожек с курсором (фейдер громкости, посылы delay / reverb, M / S) и полоса MAIN — общая громкость 0–200 % (переехала из PROJ).
- Громкость дорожки с любого экрана: держать её кнопку и крутить энкодер (Shift ×10); не в правке GRID, REC и PERF.
- **FILE → Render WAV…**: паттерн или вся песня (ALL, только solo-дорожки или STEMS — каждая дорожка в свой файл) в `/samples/render/<проект>_P01.wav` / `_SONG.wav`, стерео 16 бит 44,1 кГц, рендерит синт-плата, с delay / reverb / компрессором и хвостом 2 с. Файл можно забрать с карты или импортировать обратно как сэмпл (сведётся в моно).
- **GRID → Resample track / pattern**: паттерн (текущая дорожка или все слышимые) в новый сэмпл проекта `RS1`, `RS2`… — нормализация к −1 dBFS, тишина в конце обрезается, до 60 с.
- Рендер и ресэмплинг — только при остановке, примерно в реальном времени, отмена долгим нажатием энкодера или Play.

Подробнее — [руководство](docs/manual_ru.md#render).

## Интерфейс

- **Темы оформления**: PROJ → SYS → Theme, 17 готовых (CLASSIC, AMBER, PHOSPHOR, NORD, DRACULA, SOLARIZED, GRUVBOX, MONOKAI, TOKYO, MOCHA, ROSE PINE, GAMEBOY, C64, SYNTHWAVE, OCEAN, CONTRAST, PAPER). Настройка устройства: хранится в памяти платы, проект не меняет.
- **Страницы** в TRACK (MAIN / NOTE / MIDI) и PROJ (SONG / FX / COMP / SYS): тап по закладке, или энкодер на закладках и клик (Shift+клик — назад); список прокручивается по кругу.
- **PERF**: эффект каждой кнопки настраивается в PROJ → PERF (RAT 2/3/4/8, ROLL UP, FILTER LOW/HIGH, DELAY/REVERB MAX, CRUSH, DOWNSAMPLE, DRIVE, SHORT DECAY, FADE, MUTE), при нажатии — тост с названием.
- **Шаблоны проекта** (FILE → New: EMPTY, 808 SET, 909 SET, FM SET, CHIPTUNE, MIDI 8 и свои из `/templates`, Save as template), **8 демо-песен** (FILE → New → Demo songs: транс, чиптюн, эсид, лоу-фай, синтвейв, даб-техно, IDM, хаус), **автосохранение** в `/projects/<имя>.auto` (PROJ → SYS → Autosave, FILE → Restore autosave), **безопасный старт** (Shift при включении — без автозагрузки), **журнал сбоев** `/projects/crashlog.txt` и версия прошивки в PROJ → SYS.
- **MIX**: энкодер — громкость MAIN, Shift+поворот — дорожки A (1–8) / B (9–16); громкость дорожки — её кнопка + энкодер, mute — Shift+кнопка, solo — тап. У каждой дорожки индикатор уровня, внизу осциллограф с автоусилением и индикатор уровня / CLIP.

## Карта памяти

Карта стоит в слоте microSD **Teensy** (свой слот WT32 не используется); трекер работает с ней через линк. **FAT32** или **exFAT**, длинные имена. Перенос файлов — вынуть карту из Teensy и картридером. При переходе с одноплатной версии скопируйте содержимое старой карты на новую.

Папки `/projects`, `/midi`, `/samples`, `/wavetables` и `/presets` (с подпапками `FM`, `DRUM`, `SAMPLE`, `CHIP`, `SYNTH`) прошивка создаст сама; `/firmware/teensy.hex` — прошивка синт-платы для Update synth. MIDI-файлы для импорта кладите в `/midi`, WAV для импорта в проекты — в `/samples`, волновые таблицы для SYNTH — в `/wavetables`. Сэмплы проекта лежат в `/projects/NAME/`, его таблицы — в `/projects/NAME/wt/` (пишет трекер при сохранении), пресеты инструментов — в `/presets/<ТИП>/`.

## Wi-Fi

FILE → **Wi-Fi firmware…**: трекер подключается к домашней сети (сеть и пароль вводятся на экране и хранятся во flash) и открывает страницу `http://d-trk.local/firmware` (или по IP с экрана). На странице два раздела:

- **Tracker (.bin)** — обновление прошивки ESP32-S3 файлом `.pio/build/wt32/firmware.bin`;
- **Synth board (.hex)** — обновление прошивки Teensy файлом `.pio/build/teensy41/firmware.hex`: трекер кладёт его на карту синт-платы как `/firmware/teensy.hex`, Teensy проверяет образ в буфере OTA (FlasherX) и только потом прошивает себя и перезагружается. Без Wi-Fi — скопировать файл в `/firmware/teensy.hex` на карте и запустить PROJ → SYS → Update synth.

Файлового менеджера больше нет: проекты, сэмплы, MIDI-файлы и пресеты переносятся на карте, вынутой из Teensy.

Пока режим открыт, воспроизведение остановлено. Выход — EXIT, долгое нажатие энкодера или другая вкладка; Wi-Fi выключается.

**Безопасность:** пароля на странице нет. Пока режим открыт, любой в той же сети может прошить трекер и синт-плату. Не включать в чужих и публичных сетях.

Подробнее — [руководство](docs/manual_ru.md#wifi).

## Сборка и прошивка

Нужен [PlatformIO](https://platformio.org/).

```
pio run -e wt32 -t upload          # трекер (ESP32-S3): собрать и прошить по USB
pio run -e wt32-ota -t upload      # трекер по Wi-Fi: на трекере открыт FILE → Wi-Fi firmware…
pio run -e teensy41 -t upload      # синт-плата: первая прошивка по USB Teensy (Teensy Loader)
pio run -e teensy41                # .hex синт-платы для Wi-Fi-страницы или /firmware/teensy.hex
pio test -e native                 # тесты ядра на компьютере (955 тестов)
```

- **Первая прошивка Teensy** — по её USB через Teensy Loader (до закрытия корпуса); дальше синт-плата обновляется с трекера (Wi-Fi-страница или PROJ → SYS → Update synth).
- Таблица разделов ESP своя (`partitions.csv`): два слота прошивки по ~8 МБ (`app0` / `app1`); старого раздела `samples` больше нет. После перехода на неё прошить один раз по USB (`pio run -e wt32 -t upload`): OTA таблицу разделов не меняет. Настройки Wi-Fi (NVS) сохраняются — `nvs` и `otadata` на прежних адресах.
- Flash программ Teensy: прошивка с 0x60000000, буфер OTA с 0x60100000, банк сэмплов с 0x60200000.

Служебные окружения:

| Env | Для чего |
|---|---|
| `teensy41-bench` | бенч пула голосов на Teensy: результаты в USB serial и лог линка; проекты из этой сборки не сохранять |
| `teensy41-desk` | настольный режим: голая Teensy на компьютере, линк по USB serial, звук — USB audio; управление — `scripts/link_desk.py hello\|notes\|status\|fs\|selftest` |
| `wt32-echo` + `teensy41-echo` | проверка проводки линка: эхо-тест между платами |
