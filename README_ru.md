# D-TRK

<p align="center">
  <a href="docs/img/tracker.jpg"><img src="docs/img/tracker.jpg" alt="D-TRK" width="320"></a>
</p>

Карманный 16-дорожечный трекер со встроенным синтезатором. Собран на **WT32-SC01 Plus** (ESP32-S3, тач-экран 480×320): энкодер, кнопки Play, Shift, A и B и 8 механических кнопок дорожек. С кнопками A / B трекером можно пользоваться почти без тачскрина: навигация, редактирование и переключение страниц делаются энкодером и кнопками. Звук стерео, через ЦАП PCM5102A и усилитель в наушники. MIDI OUT (TRS) отдаёт ноты, clock и Start / Stop. Прошивка открытая (GPL v3), корпус для 3D-печати тоже (CERN-OHL-S).

Руководство пользователя: [docs/manual_ru.md](docs/manual_ru.md). Подключение: [docs/wiring_ru.md](docs/wiring_ru.md). English: [README.md](README.md).

## Возможности

### Секвенсор

- 16 дорожек, 16 паттернов, от 4 до 128 шагов, темп 20–300 BPM, свинг.
- У каждой дорожки своя длина и скорость (1/4, 1/2, x1, x2, x4): полиметрия, медленные пэды поверх быстрых грувов.
- В шаге: нота, громкость, аккорд (36 типов × 4 обращения) и 6 fx-команд: слайд, вибрато, ретриггер, арп, условия срабатывания (вероятность, fill, «предыдущий сработал»…), p-lock параметров звука, панорамы и LFO.
- Fill нот, громкости или любого fx на каждый N-й шаг, по Euclid или случайно, с рампами значений.
- Генераторы, которые пишут сразу нотами: **ARP** (106 паттернов, в том числе 64 из Access Virus), **CHORDS** (55 прогрессий в тональности проекта, 32 ритма, RANDOM, Mutate, голосоведение) и **BASS** (48 басовых паттернов, идут за аккордами). Свои паттерны сохраняются через Capture.
- Грувы (MPC, shuffle, drunk, boom bap, house…) и humanize на дорожку.
- Лады, undo, выделение, копирование.

### Встроенный звук

32 инструмента, до 24 голосов, 32 кГц, стерео с панорамой на дорожку. Типы:

- **FM**: 8 машин в духе Model:Cycles (kick, snare, metal, perc, tone, chord, clap, hat) с 5 макросами.
- **DRUM**: 16 машин в духе TR-808 и TR-909.
- **SYNTH**: 2 осциллятора (saw / square / tri без алиасинга или wavetable), sub, шум, hard sync. Импортирует таблицы WaveEdit, Serum и Vital.
- **SAMPLE**: сэмплер со слайсами, импорт WAV с карты. Сэмпл-эдитор работает и без тачскрина.
- **CHIP**: pulse, triangle, noise, metal и wavetable для чиптюна.
- **KIT**: драм-дорожка из 8 лейнов, у каждого свой сэмпл или любой инструмент.

У каждого инструмента фильтр LP / BP / HP с огибающей и 4 LFO (синхронизируются с темпом, модулируют друг друга, управляются с шага). 145 заводских пресетов.

### Микс и эффекты

- Микшер: фейдеры, панорама, посылы, mute / solo, индикаторы уровня, осциллограф.
- Insert дорожки: drive (TANH, CLIP, FOLD, RECT), bit crush, downsample и trance gate с 16-шаговым рисунком. Пресеты инструментов несут рекомендуемый insert.
- Envelope follower: уровень одной дорожки двигает параметр другой (sidechain-«качание», ducking, auto-wah).
- Посылы: delay (DIGITAL, TAPE, PING-PONG), псевдостерео reverb с shimmer, MOD-шина (chorus, ensemble, flanger, phaser).
- Мастер: компрессор с sidechain, EQ-полки, PERF-эффекты-«вставки» (repeat, roll, reverse, scratch, tape stop, gate, LP / HP фильтр, crush, downsample, drive, delay / reverb / MOD throw, tape wobble, freeze).
- Каждую дорожку можно направить во внутренний синт или на внешний MIDI.

### Живое исполнение и песня

- **SONG**: до 128 слотов, у каждого паттерн и mute 16 дорожек. Повтор делается тапом A, mute в слоте ставится тапом или кнопкой дорожки. Play на вкладке SONG играет песню, на остальных крутит паттерн; Shift + Play — песня с курсора на любой вкладке; переключение SONG / LOOP на лету, undo правок песни.
- **PERF**: эффекты-«вставки» на весь микс, пока держишь кнопку (repeat, roll, reverse, scratch, tape stop, gate, фильтр, crush, downsample, drive, delay / reverb / MOD throw, tape wobble, freeze), энкодер задаёт глубину, несколько кнопок складываются; назначение кнопок настраивается.
- **REC**: запись нот с кнопок дорожек прямо во время игры.
- Shift + Play: песня с курсора SONG на любой вкладке; удержание во время игры — fill.

### Файлы и удобства

- Проекты, сэмплы и пресеты на microSD, автосохранение, шаблоны и 8 демо-песен.
- Импорт MIDI-файлов.
- Рендер в стерео WAV: паттерн, весь сонг или стемы по дорожкам. Ресэмплинг дорожки в новый сэмпл.
- Wi-Fi: веб-страница для заливки файлов и прошивки.
- 17 тем оформления.

## Железо

Основа — плата WT32-SC01 Plus (ESP32-S3, тач-экран 480×320, слот microSD). К ней подпаяны: энкодер EC11, расширитель PCF8575 с кнопками Play, Shift, A, B и 8 кнопками дорожек, ЦАП PCM5102A с усилителем для наушников MAX97220, MIDI-выход TRS, питание от LiPo на IP5306 и, по желанию, датчик заряда INA226.

- Схема подключения, распиновка и проверки перед включением: [docs/wiring_ru.md](docs/wiring_ru.md).
- Список деталей: [docs/bom_ru.md](docs/bom_ru.md).
- Корпус и схема питания: [enclosure/](enclosure/README_ru.md).

## Сборка и прошивка

Нужен [PlatformIO](https://platformio.org/).

```
pio run -e wt32 -t upload     # собрать и прошить по USB
pio run -e wt32-ota -t upload # по Wi-Fi: на трекере открыт FILE → Wi-Fi transfer
pio test -e native            # тесты ядра на компьютере
```

Таблица разделов своя (`partitions.csv`): два слота прошивки по 3 МБ и раздел `samples` (~9,9 МБ) под flash-кэш сэмплов. После перехода на неё прошить один раз по USB (`pio run -e wt32 -t upload`): OTA таблицу разделов не меняет. Настройки Wi-Fi (NVS) сохраняются — `nvs` и `otadata` на прежних адресах.

## Структура

| Папка | Содержимое |
|---|---|
| `lib/core` | ядро без железа: модель, секвенсор, fx, лады, Euclid и Fill, формат файла, парсер MIDI, синтезатор (CHIP, SAMPLE, FM, DRUM, фильтр), парсер WAV, банк сэмплов, список сэмплов проекта, пресеты |
| `src/engine` | задача секвенсора на ядре 0 (таймер, MIDI-выход) |
| `src/audio` | встроенный звук: I2S на внешний ЦАП PCM5102A, аудио-задача, банк сэмплов во flash, импорт WAV |
| `src/hw` | ввод (энкодер, кнопки), MIDI UART, SD, конфигурация дисплея |
| `src/ui` | экраны интерфейса |
| `src/storage` | сохранение и загрузка проектов и пресетов |
| `src/net` | Wi-Fi, веб-страница передачи файлов, OTA |
| `test` | Unity-тесты ядра |
| `docs` | руководство, схема подключения, список деталей и планы разработки |
| `enclosure` | корпус: модель OpenSCAD и STL |
