# Изменения

Собрано по истории git. English: [CHANGELOG.md](CHANGELOG.md).

## Не выпущено
- MIDI IN: неназначенные ноты играют текущую дорожку напрямую с исходной высотой и velocity. NOTE больше не обучается и не показывается; сохранённые PAT / PERF / MUTE совместимы. PERF занимает только 8 нот, остальные доступны для игры. Удержания различаются по каналу и ноте.
- MIDI devices: убрана нижняя панель EXIT / PAGE / действий. Стандартные заголовок, PageBar с фокусом, A + поворот и B + Shift + поворот; B — назад, долгое нажатие — контекстное меню; Add device — строка списка.
- MIDI REC HOLD: удержание длиннее 8 шагов записывается через TIE и OFF на отпускании, включая переход через конец дорожки; занятые шаги защищены, максимум — один оборот дорожки.
- MIDI devices: общая полоса вкладок и строки по 24 px; LEARN только выбранной функции, меню строки для обучения / правки / отвязки. REC LENGTH TRACK / HOLD: запись длительности удержания мелодических пэдов в GAT (1–800%, KIT использует длительность дорожки). Настройка сохраняется в устройстве.
- **KIT: 16 лейнов** ([мануал](docs/manual_ru.md#kit)): в ките 16 лейнов (было 8), ноты по умолчанию 60…75.
  Страницы INST у KIT — MAIN | LN1-8 | LN9-16. GRID: пэд лейнов в Detail — 2 ряда по 8, маска в Overview / Detail
  8 × 2, пианоролл — 16 строк; в правке <kbd>Shift</kbd>+кнопка дорожки N переключает лейн N + 8 (кнопки дорожек
  в REC по-прежнему пишут лейны 1–8; лейны 9–16 пишутся с BLE-пэдов или касанием). Новый fx **AC2** — маска
  акцентов лейнов 9–16 (hex, бит 0 = лейн 9), только драм-дорожки; ACC остаётся за лейнами 1–8, каждый отвечает
  за свою половину, без него эта половина играет с громкостью шага. Импорт MIDI в кит кладёт ноты лейнов 9–16
  (по умолчанию 68…75) в эти лейны, а не отбрасывает. MUT: поле CA на дорожке KIT всегда в 16 рядов (в шапке
  4 группы по 4), поэтому CA1D / CA2D старых проектов может развиваться иначе; шум попадает только на лейны с
  инструментом или сэмплом. Заводские KIT-пресеты и DICE по-прежнему заполняют лейны 1–8. Старые проекты
  открываются (лейны 9–16 пустые, ноты 68…75, совпавшая нота переезжает на свободную); **новые проекты на старой
  прошивке не открываются** (формат шага вырос). Протокол линка 19: прошить обе платы (ESP + Teensy по OTA).
  Шаг со всеми 16 лейнами × RAT 8 — 256 событий: три такие KIT-дорожки на одном шаге могут терять note-on
  (очередь событий 1024, из них 256 под note-off).
- **Bluetooth MIDI-контроллер** ([мануал](docs/manual_ru.md#ble)): трекер сам подключается к BLE MIDI-устройствам
  (класса M-VAVE SMC-PAD / FM-1, Mac с Bluetooth Advertise); всегда ведущий по клоку, клок на вход не принимается.
  Банки пэдов учатся для каждого устройства (LEARN: удар по пэду 1 банка для NOTE / PAT / PERF / MUTE): **NOTE**
  играет текущую дорожку с velocity (мелодическая — 16 ступеней лада от октавы дорожки; KIT — пэды 1–16 = лейны 1–16) и
  пишет в звучащий шаг при включённом REC в GRID; **PAT** ставит в очередь паттерны 1–16; **PERF** — пэды 1–8
  держат эффекты PERF с любой вкладки во время игры; **MUTE** переключает дорожки 1–16. **Ручки:** выберите
  строку в INST / TRACK / PROJ, держите <kbd>Shift</kbd>, поверните ручку контроллера — `KNOB CC21 > TRK2 CUTOFF`;
  привязка к этой дорожке, работает с любой вкладки, ABS или относительная (REL1 / REL2) определяется следующим
  поворотом, без скачков; <kbd>Shift</kbd>+поворот на её же строке отвязывает. До 16 привязок, хранятся в проекте
  (новый блок `KNOB`; старые файлы грузятся). Отвалившийся контроллер снимает свои ноты и эффекты;
  переподключение каждые 2 с. В статус-баре `BT`; в FILE → SYSTEM — **Internal RAM min**. Пока открыто окно
  Wi-Fi, Bluetooth выключен.
- **MIDI-выход по Bluetooth** ([мануал](docs/manual_ru.md#bleout)): когда OUT-устройство подключено, ноты, CC,
  Program Change и Start / Stop MIDI-дорожек идут на него вместе с MIDI OUT; клок — при **BLE clock** ON (по
  умолчанию). При переподключении OUT — All Notes Off на каждый канал MIDI-дорожек; потерянные сообщения
  считаются в мониторе.
- **MIDI devices…** в FILE ([мануал](docs/manual_ru.md#ble)): страницы DEVICES / PADS / KNOBS (PAGE). До 6
  запомненных устройств с ролью IN / OUT / IN+OUT: ADD (поиск, выбор, роль), TURN ON / OFF (выключенное остаётся
  выключенным после перезагрузки), MORE (роль, удаление, BLE clock); один IN и один OUT одновременно, включение
  другого выключает конфликтующее (`FM-1 OFF`). PADS: обучение или правка канала и первой ноты каждого банка,
  CLEAR / CLEAR ALL. KNOBS: правка CC / CH / TRK / MODE, DELETE, CLEAR ALL. Монитор последних входящих сообщений
  и потерь. Протокол линка не менялся, прошивать Teensy не нужно.

## 2026-10-28
- **Фразы DICE** ([мануал](docs/manual_ru.md#dice)): строка Length (AUTO / 16 / 32 / 64 / 128; AUTO — 64 у
  мелодичных стилей, 32 у грувовых), хранится в устройстве; все четыре паттерна одной длины. Партии строятся
  четырёхтактными фразами A A′ A B: аккорды с голосоведением обращений, добавленными нотами по стилю и
  упреждением в последнем такте; бас подходит к следующему корню; арп разворачивается в 4-м такте; лид
  отвечает в B с каденцией на тонику или квинту и звучит и в MAIN (проще, тише); барабаны меняются по тактам,
  в конце фразы мини-сбивка. При Variety 0 вариации фиксированные.

  возвращает темп до правки и срабатывает только после поворота.
- GRID: значение GAT с <kbd>Shift</kbd> шагает на ±10 % от показанного (к ближайшему значению GAT в сторону поворота) вместо ×10 сырых единиц; A + поворот в пианоролле шагает так же.
- **Пианоролл** в GRID: третий вид (<kbd>Shift</kbd>+клик — по кругу Overview → Detail → Roll, или меню →
  **Piano roll**) показывает текущую дорожку горизонтальным роллом — слева клавиши (корень акцентом, вне лада
  серые: белые темнее, чёрные светлее), строка корня в каждой октаве — подкрашенная полоса через сетку, 16 полутонов × 16 шагов, страницы за курсором; перекрестие на строке и столбце курсора. Ноты —
  полосы длиной в гейт (GAT, иначе Def gate), обрезанные следующей нотой, яркость — velocity; ноты CHD —
  контуром. A ставит ноту строки (в шаге с нотой fx и velocity остаются, пустой играет Def gate), A + поворот —
  значение GAT как правка GAT в сетке (±1, <kbd>Shift</kbd> ±10 % от показанного; 1..200; Def gate убирает GAT; toast `GATE n`) (`NO FX SLOT`, если слоты заняты), A держать + B стирает; одно нажатие A — один шаг undo. Дорожки
  KIT показывают 8 ударных, A переключает ударный. Формат файла и протокол линка без изменений.
- GRID: очистка шага — **A держать + B** во всех видах (Overview, Detail, Roll, дорожки KIT) вместо
  Shift+A (Shift+A в GRID больше ничего не делает). При выделении стирает выделение. Один шаг undo; после
  A + поворот нажатие и очистка — один шаг (раньше B при зажатой A отменял правку). При включённом PERF
  A затем B без поворота по-прежнему открывает XY-пад.
- Undo — только <kbd>Shift</kbd>+<kbd>B</kbd> (и пункт меню **Undo**): в GRID (все виды, и ролл)
  <kbd>Shift</kbd>+долгое нажатие энкодера и <kbd>Shift</kbd>+долгий тап больше не отменяют и ничего не делают.
- **REC -> SD** с MIX: кнопка **REC** в колонке MAIN (или долгое нажатие энкодера на MIX) пишет прямо в
  `/samples/rec/RECn.wav` на карте синта, без импорта, до 4 ГБ или места на карте. Запись идёт в фоне на любой
  вкладке (в статус-баре `● REC 03:41`, тап — вернуться к ней); стоп — STOP / B / долгое нажатие. Toast
  `REC12.WAV 3:41 SAVED`. Настройки REC (Source, усиления, Thresh, Mon) теперь помнятся после выключения.
  Протокол линка 18: шить обе платы.
- Окно REC (SAMPLE и REC -> SD): большая сенсорная кнопка **START / STOP** под строками вместо строки REC —
  беззвучный тап для записи с микрофона (красная рамка START / ARM, ARMED мигает, залитая STOP со временем,
  серая SAVING). Долгое нажатие энкодера в окне тоже стартует / взводит / останавливает; B до записи закрывает.
  RESAMPLE при остановленном транспорте: START ждёт Play (мигает `ARMED: PLAY`), Play запускает запись
  перед транспортом — первая нота в дубле; тап во время ожидания — назад в READY.
- Строка Cancel окна REC: во время дубля, взвода, старта или ожидания Play выбрасывает дубль (DROP THE
  TAKE / CANCEL ARM, файл удаляется) или снимает ожидание (CANCEL WAIT), окно остаётся открытым в READY;
  в READY она называется CLOSE и закрывает окно.
- Окно REC: STOP (кнопка, B, долгое нажатие или запись, остановившаяся сама) сохраняет с toast и оставляет
  окно открытым в READY для следующего дубля (SAMPLE по-прежнему привязывает дубль к инструменту). B в READY
  и уход с INST закрывают окно.
- Окно REC: тап A (нажать и отпустить без поворота) стартует / взводит / останавливает, как большая кнопка;
  обычное значение A (шаг маркера, Shift+A — вид SCENE) в открытом окне не действует.
- FILE → SAMPLES → Import WAV… и FILE → Import MIDI…: B в подпапке — на папку вверх (курсор на папке, из
  которой вышли); на верхнем уровне закрывает список, как раньше.
- **MUT**: EVO и VAR — один мутатор на дорожку: страница TRACK **MUT** (вкладки MAIN INS FOL NOTE GEN MUT
  MIDI) вместо EVO и VAR. Строка **Mut** выбирает OFF / EVO / CA1D / CA2D (только дорожки KIT) / MARKOV;
  видны только строки выбранного режима, в шапке — его состояние. Режимы больше не складываются. Старые
  проекты, где включены EVO и VAR, открываются как VAR; CA2D на мелодической дорожке — как CA1D (то же
  правило). В TEVO настройки EVO вне режима EVO помечены битом маски 0x80 (старая прошивка его
  отбрасывает).
- Меню GRID: один **Capture live** вместо Capture gen / evo / var: пишет то, что дорожка играет (MUT, затем
  GEN), в паттерн (undo), затем GEN выключается, а MUT идёт дальше с чистого состояния — звук не скачет. Undo возвращает
  паттерн и GEN.
