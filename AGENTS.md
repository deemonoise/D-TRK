# Инструкции для агента

Отвечай на русском, если пользователь не попросил другой язык.

## Разрешения на работу с проектом

- Создание, изменение и удаление файлов в репозитории разрешены без дополнительного подтверждения.
- Сборки, запуск тестов и другие локальные проверки проекта разрешены без дополнительного подтверждения.
- Не запрашивай повторное разрешение на эти действия в рамках поставленной задачи.
- Перед `git commit` и `git push` (включая force push) покажи конкретный diff / действие и получи явное ручное подтверждение пользователя, если эта конкретная операция ещё не была явно разрешена.
