# Проверка Motion REC и Automation view

Проверять на отдельной копии проекта. Для первого теста: INT-дорожка с FM TONE,
фильтр LP, короткий паттерн с нотами. У INST выбран инструмент этой дорожки.

## Основные проверки

- [ ] A + Play включает ноты + ручки, B + Play — только ручки. На остановке включение запускает
  воспроизведение; повтор сочетания выключает запись, сохраняя воспроизведение.
  Отпускание A / B не добавляет ноту, не вызывает Back / Undo; Play не срабатывает второй раз.
- [ ] A + Play, открыть INST: MIDI-ноты и движения ручки записываются одновременно.
- [ ] B в Automation завершает правку, но не переключает вид. Shift + клик меняет вид.

- [ ] После OTA трекер загрузился, проект открывается, воспроизведение и звук работают.
  В меню GRID есть **Motion REC**; Automation view доступен циклом Shift + клик и отсутствует в меню.
- [ ] GRID → **Motion REC: OFF** включает режим; в шапке GRID на месте REC виден `MREC`; при записи обоих режимов — `REC+`.
  В правой части статус-бара остаётся индикатор CPU.
  Нажать Play, перейти в INST и менять Cutoff энкодером. Остановить воспроизведение.
  В GRID через Shift + клик → Automation → Parameter → FILTER CUTOFF появились столбики FLT на шагах.
  На первом проходе последнее значение пишется до конца прохода. На втором и следующих
  проходах без движения ручки существующая автоматизация не меняется. Сдвинуть ручку на
  втором проходе: последнее значение пишется до его конца. На третьем проходе без движения
  уже записанные значения не меняются.
- [ ] Выключить Motion REC, повторно запустить паттерн: записанный рисунок фильтра слышен.
  Stop сбрасывает удерживаемые значения, но оставляет режим записи включённым; после нового
  Play без движения ручки новые локи не добавляются. Проверить это на пустой дорожке / новом паттерне.
- [ ] При включённом Motion REC повторить запись с изменением параметра перетаскиванием в INST,
  затем обученной MIDI-ручкой. MIDI-проверку делать после выхода из режима Wi-Fi и подключения BLE.
  Запись попадает на дорожку, назначенную MIDI-ручке, даже если выбрана другая.
- [ ] Записать Pan в TRACK / MIX и через удержание кнопки дорожки с поворотом в режиме PAN.
  В Automation view соответствующей дорожки появились локи PAN.
- [ ] В Automation view: энкодер выбирает шаг и переключает страницы по 16 шагов;
  Shift + поворот меняет параметр. **Track…** позволяет выбрать любую из 16 дорожек.
  Клик + поворот и A + поворот меняют значение. Касание / перетаскивание рисует столбики.
  Ноль отображается столбиком у основания, отсутствие лока — знаком `-`.
- [ ] Задать значение на первом шаге → **Set ramp start**; задать другое на более позднем
  шаге → **Ramp to cursor**. Между ними получилась равномерная рампа. Повторить справа налево.
- [ ] **Copy parameter lane**, выбрать другую дорожку, **Paste parameter lane**:
  скопировался только выбранный параметр; ноты, KIT-маски и другие FX не изменились.
  Пустые клетки источника удалили соответствующие локи приёмника.
- [ ] A + B / **Clear lock** удаляет только выбранный лок; **Clear parameter lane** — только
  этот параметр на всей дорожке. Undo возвращает результат каждой операции.
  После undo следующая правка снова имеет собственный снимок.
- [ ] Сохранить проект, загрузить его заново: столбики и звучание сохранились.
  Сделать WAV-рендер: записанная автоматизация слышна в файле.

## Отсчёт, метроном и ONE PASS

- [ ] GRID → Recording setup: COUNT-IN 1 BAR, Metronome REC ONLY, Record ONE PASS.
  На остановке A + Play: четыре щелчка и COUNT 4…1, затем начинается паттерн и запись.
  Ноты и повороты во время отсчёта не появляются в шагах.
- [ ] После первого прохода REC и MREC погасли, воспроизведение идёт дальше.
  Следующий проход не перезаписывается даже при игре пэдом или вращении ручки.
- [ ] Во время воспроизведения B + Play начинает запись ручек без отсчёта и завершает
  её на ближайшей границе паттерна. Ноты при этом не записываются.
- [ ] Count-in 2 BARS даёт восемь ударов; Play посреди отсчёта отменяет запуск.
  Следующий Play запускает новый полный отсчёт.
- [ ] SONG с BPM стартового слота, отличным от проекта: отсчёт соответствует слоту.
- [ ] Metronome OFF молчит при игре, REC ONLY — только при записи, PLAY + REC —
  и при обычном воспроизведении. Первые четверти акцентированы; смена BPM меняет ритм клика.
- [ ] В режиме LOOP запись продолжается после границы. Длинный удержанный MIDI-пэд
  в ONE PASS записывает длительность до границы, а не до последующего отпускания.
- [ ] REC → SD из MIX и внутренний ресэмплинг не содержат клика; WAV и стемы тоже.
- [ ] Настройки сохраняются после перезапуска. На обеих платах актуальные прошивки одного протокола (21).

## Редактирование и квантование

- [ ] В Automation счётчик FX соответствует всем командам текущего шага, включая NDG/GAT/PRB;
  при шести занятых слотах текст красный. REC / MREC / REC+ остаются в общем месте.
- [ ] Выделить диапазон → Edit tools → Clear notes: удалились только ноты, velocity и KIT-маски.
  Undo вернул их. Clear automation удаляет локи параметров и LFO, сохраняя ноты, NDG и GAT.
- [ ] Записать ноты с отклонениями: появились NDG. Quantize 1/16, 50 % уменьшает отклонения,
  100 % убирает их. Velocity и высота сохраняются, undo возвращает исходное время.
- [ ] Quantize 1/4 переносит ноты, сохраняя локи на исходных шагах. Проверить x2 и медленную дорожку,
  KIT и выделение нескольких дорожек. Ноты вне диапазона и за собственной длиной не меняются.
- [ ] Две ноты на одной цели сетки: NOTES COLLIDE, весь паттерн остался прежним.
  Заполненный FX у цели также отменяет всю операцию.
- [ ] На длинной TIE-ноте с FLT / LFO: Automation OFF возвращает базовые параметры без note-off.
  AUTO OFF виден в GRID; Automation ON возвращает локи оставшихся голосов.
  Другая дорожка и музыкальные команды не затронуты.
- [ ] Переключатель сравнения не сохраняется, загрузка проекта его сбрасывает;
  экспорт и Capture используют сохранённые локи. На обеих платах протокол 21.

## Граничные случаи

- [ ] На дорожке с длиной 5 шагов и скоростью x2, затем 1/4, запись следует её собственной
  позиции, а не общей строке паттерна. Проверить на нескольких проходах.
- [ ] На шаге занять все шесть FX-слотов командами, отличными от записываемого параметра.
  При попытке записи появляется `MOTION STOP: NO FX SLOT`, режим выключается,
  содержимое заполненного шага остаётся прежним.
- [ ] Один такой заполненный шаг внутри диапазона рампы или вставки: операция целиком
  отклоняется, остальные шаги диапазона остаются прежними.
- [ ] Undo записи выключает Motion REC. Загрузка другого проекта также выключает запись.
  Смена паттерна сбрасывает удерживаемые параметры: новый паттерн не заполняется без нового движения.
- [ ] Ручная правка в Automation view выключает Motion REC и не перезаписывается latch.
  При входе в Automation view нотный REC и PERF выключаются; A / кнопки дорожек не добавляют нот.

Записываются 17 существующих p-lock-параметров INT-дорожек. Громкость дорожки, мастер,
морф сцен, LFO и параметры без поддерживаемой FX-команды в эту реализацию записи не входят.
Макросы зависят от типа инструмента; SAT записывается только для FM.

## Компактное меню GRID

- [ ] Основное меню: 10 строк без прокрутки; одинаковый порядок с выделением и без.
- [ ] Edit step → Clear notes очищает только текущий шаг; Shift+B возвращает его.
- [ ] Edit selection → Clear automation затрагивает только выделение, сохраняя ноты.
- [ ] Process track → Quantize работает со всей дорожкой; Process selection — только с выделением.
- [ ] Track → Clear → Clear all очищает всю текущую дорожку даже при активном выделении; Undo восстанавливает.
- [ ] B из каждого подменю возвращает на прежнюю строку родителя; B из корня закрывает.
- [ ] В Recording setup и Quantize выбор значения обновляет строку, оставаясь в группе; B возвращает выше.
- [ ] Тап по `<` возвращает выше; долгий энкодер и тап вне меню закрывают всё дерево.
- [ ] Grid settings → Edit step / Follow меняются и корректно показывают новое значение.
- [ ] Automation: 9 команд; Parameter / Track возвращают в меню с обновлённой целью.
- [ ] A+Play, B+Play, Shift+B и Shift+клик энкодера работают как раньше.

## Rotate / Duplicate / Paste / Velocity

- [ ] Rotate +1 ALL переносит последний шаг в начало диапазона; −1 возвращает исходник. Shift+B отменяет одной операцией.
- [ ] Rotate NOTES ONLY сохраняет FX на исходных позициях; AUTOMATION сохраняет ноты и музыкальные FX.
- [ ] При собственной длине дорожки Rotate без выделения работает в её пределах; с выделением — в точном диапазоне.
- [ ] Duplicate step и выделения копируют сразу следом, заменяя назначение; буфер обмена не меняется.
- [ ] Duplicate у конца паттерна сообщает NOT ENOUGH STEPS и ничего не меняет.
- [ ] Pattern x2: 16 → 32 → 64 → 128, повтор всех дорожек; свои длины/скорости сохраняются; Undo возвращает длину и данные.
- [ ] Paste notes only сохраняет автоматизацию и NDG/GAT назначения; пустой источник очищает только ноты.
- [ ] Paste automation only сохраняет ноты и музыкальные FX; пустой источник очищает только локи.
- [ ] При нехватке FX-слотов Paste/Rotate automation не меняют ни одной ячейки.
- [ ] Velocity SET/ADD/RAMP/HUMANIZE меняют только существующие удары, включая KIT без потери пэдов 9–16.
- [ ] ADD с DEF использует Def vel дорожки; значения остаются в диапазоне 1–127.
- [ ] Cancel/B/долгий энкодер в формах Rotate/Velocity не меняют паттерн; Apply — один Undo и запись выключена.
