
# Схема пайки трекера

Всё, что паяется к WT32-SC01 Plus: питание от аккумулятора, MIDI OUT, энкодер, Play и Shift, восемь кнопок дорожек со светодиодами, гнездо для наушников. Дисплей, тач и microSD уже разведены на плате.

English: [wiring.md](wiring.md)

## Принципиальная схема

![Общая схема: LiPo через IP5306 и тумблер питает плату 5 В; GPIO10 через 10 Ом на Tip MIDI-гнезда, 3,3 В через 33 Ом на Ring; энкодер на GPIO 11, 12, 13; Play на 14, Shift на 21; PCF8575 на GPIO 43 и 44 разъёма Debug с восемью кнопками и восемью светодиодами.](img/wiring_ru-1.svg)

- красная — питание (5 В от IP5306, 3,3 В от платы)
- чёрная (в тёмной теме белая) — GND
- синяя — сигнал на GPIO
- зелёная — кнопка
- оранжевая — катод LED

*Каждый знак «земли» — провод на общий GND платы, флаг «3,3 В» — на вывод 3V3 платы. Все входы платы с внутренней подтяжкой, внешние резисторы к кнопкам и энкодеру не нужны. Блок PCF8575 с кнопками дорожек необязателен: без него прошивка работает.*

## Таблица соединений

| Откуда                            | Куда                                | Примечание                                                  |
|-----------------------------------|-------------------------------------|-------------------------------------------------------------|
| **Питание** |                                     |                                                             |
| `LiPo + / −`                      | `IP5306 B+ / B−`                    | аккумулятор 103450 с платой защиты                          |
| `IP5306 VOUT`                     | `тумблер → плата 5V`                | VOUT и GND — площадки выпаянного USB-A модуля               |
| `IP5306 GND`                      | `плата GND`                         |                                                             |
| **MIDI OUT** |                                     |                                                             |
| `плата IO10`                      | `10 Ом → Tip`                       | MIDI DIN pin 5                                              |
| `плата 3V3`                       | `33 Ом → Ring`                      | MIDI DIN pin 4                                              |
| `плата GND`                       | `Sleeve`                            | MIDI DIN pin 2, экран                                       |
| **Энкодер EC11 и кнопки** |                                     |                                                             |
| `плата IO11 / IO12`               | `энкодер A / B`                     | крайние выводы тройки; крутится наоборот — поменять местами |
| `плата GND`                       | `энкодер C`                         | средний вывод тройки                                        |
| `плата IO13`                      | `кнопка вала`                       | второй вывод кнопки вала — на GND                           |
| `плата IO14`                      | `кнопка Play`                       | второй вывод — на GND                                       |
| `плата IO21`                      | `кнопка Shift`                      | второй вывод — на GND                                       |
| **Наушники (необязательно)** |                                     |                                                             |
| `разъём SPK+`                     | `150 Ом → Tip`                      | левое ухо                                                   |
| `разъём SPK+`                     | `150 Ом → Ring`                     | правое ухо, свой резистор                                   |
| `разъём SPK−`                     | `Sleeve`                            | **не GND**: гнездо изолировано                              |
| `разъём SPK+ / SPK−`              | `динамик + (через выключатель) / −` | динамик 4–8 Ом, выключатель по желанию                      |
| **Кнопки дорожек (необязательно)** |                                     |                                                             |
| `плата 3V3`                       | `PCF VCC + шина 3,3 В`              | шина питает все 8 резисторов LED                            |
| `плата GND`                       | `PCF GND`                           | A0, A1, A2 не паять: прошивка сама найдёт адрес 0x20–0x27   |
| `Debug TXD0 (IO43) / RXD0 (IO44)` | `PCF SDA / SCL`                     | разъём Debug; 3V3 и GND можно взять с него же               |
| `—`                               | `PCF INT`                           | не подключать: модуль опрашивается каждые 5 мс              |
| `PCF P00 … P07`                   | `кнопка 1 … 8`                      | второй вывод кнопки — на GND                                |
| `PCF P10 … P17`                   | `катод LED 1 … 8`                   | анод — через свой резистор на 3,3 В                         |

Желательно конденсаторы 10 нФ с выводов A и B энкодера на GND — меньше дребезга. Не обязательно: в прошивке есть фильтр.

## Питание: важное

- Тумблер стоит после IP5306, поэтому аккумулятор заряжается через Type-C модуля и при выключенном трекере.
- **Прошивать только с выключенным тумблером.** Иначе на линии 5V встретятся два источника: USB компьютера и IP5306.
- Аккумулятор не подключать напрямую ни к 5V, ни к 3V3 платы — только через IP5306.
- Минусы аккумулятора, IP5306 и платы — общая земля; всё остальное на схеме садится на неё же.

## MIDI-гнездо

- Распиновка TRS **тип A**: Tip = pin 5, Ring = pin 4. Для устройств с типом B (некоторые Arturia, Novation) — переходник A→B или поменять местами провода на Tip и Ring.
- Для 5-контактного DIN: те же резисторы на pin 5 и pin 4, GND на pin 2.

## Наушники

![Наушники: SPK+ через два резистора 150 Ом на Tip и Ring гнезда 3,5 мм, SPK− на Sleeve. Динамик подключён параллельно, плюс через выключатель. Sleeve не соединяется с GND.](img/wiring_ru-2.svg)

- фиолетовая — SPK+
- бирюзовая — SPK− (не земля)

*Встроенный усилитель NS4168 выведен на разъём SPK платы, пайка к GPIO не нужна. Сигнал моно, на оба уха одинаковый. Выключатель в проводе динамика необязателен: без него динамик и наушники звучат вместе.*

**Выход SPK мостовой: ни один из двух выводов не земля.** Sleeve гнезда — на SPK−, никогда на GND платы. Гнездо не должно касаться GND, корпуса MIDI-гнезда и USB. В это гнездо — только наушники: кабель в микшер, звуковую карту или активные колонки соединит SPK− с их землёй и замкнёт выход усилителя.

- Резисторы 100–220 Ом, 0,25 Вт, по одному на Tip и Ring. Меньше 100 Ом — громко и большой ток через наушники, больше — тише. 150 Ом — середина.
- Гнездо — в пластиковом корпусе или в пластиковой стенке: печатный корпус подходит.
- Встроенный размыкающий контакт гнезда для отключения динамика не подходит: у обычных гнёзд он соединён с Tip, а Tip идёт через резистор. Нужен отдельный выключатель.
- Первое включение — с громкостью PROJ → Volume на минимуме и не надевая наушники.

## Какая кнопка дорожки какая

![Расположение кнопок: под экраном Shift, Play, энкодер; ниже кнопки 1–4, у переднего края 5–8. Вид снизу зеркален: кнопка 1 справа.](img/wiring_ru-3.svg)

*Номер кнопки = номер дорожки = номер вывода +1 (кнопка 1 — P00 и P10). При пайке крышка лежит лицом вниз, поэтому слева направо порядок обратный: кнопка 1 оказывается справа.*

## Полярность светодиода

![Светодиод: длинная ножка — анод, к резистору и 3,3 В; короткая ножка со стороны среза — катод, к выводу P1x.](img/wiring_ru-4.svg)

*Светодиод вставляется в окно корпуса свича MX, ножки проходят насквозь. Перевёрнутый светодиод не сгорит, просто не будет светить.*

## Резисторы светодиодов

| Цвет светодиода            | Падение       | Резистор   | Ток        |
|----------------------------|---------------|------------|------------|
| красный, жёлтый, оранжевый | `≈ 2,0 В`     | `330 Ом`   | `≈ 4 мА`   |
| зелёный (жёлто-зелёный)    | `≈ 2,1 В`     | `330 Ом`   | `≈ 3,5 мА` |
| белый, синий, ярко-зелёный | `≈ 2,9–3,1 В` | `47–68 Ом` | `≈ 3–8 мА` |

С белыми и синими при 3,3 В запас по напряжению всего 0,2–0,4 В, и яркость заметно гуляет от экземпляра к экземпляру. Красные или жёлтые с 330 Ом надёжнее. Не меньше 47 Ом: PCF8575 держит до 25 мА на вывод, но 8 светодиодов вместе не должны брать больше ~80 мА.

## Перед включением


1.  Прозвонить: 5V и GND платы не закорочены; тумблер в положении «выкл.» размыкает VOUT.
2.  Если стоит гнездо наушников: Sleeve не звонится с GND платы, Tip и Ring звонятся с SPK+ через 150 Ом.
3.  A0, A1, A2 на модуле можно не трогать. Если модуль то находится, то нет (адрес «плавает»), замкнуть все три площадки на GND.
4.  Посмотреть, есть ли на модуле резисторы подтяжки SDA и SCL (обычно 4,7–10 кОм к VCC). Если нет — поставить 4,7 кОм от каждой линии на 3,3 В.
5.  Питать модуль только от 3,3 В, не от 5 В: иначе на GPIO платы придёт 5 В.
6.  Прозвонить, что TXD0 и RXD0 не закорочены между собой и на GND. GPIO 1, 2, 42 не трогать: они заняты встроенным RS485.
7.  После прошивки открыть монитор порта: строка `trackio: PCF8575 not found` значит, что модуль не отвечает — проверить SDA/SCL и питание; `trackio: PCF8575 at 0x..` — найден.
