# FM-машины в стиле Model:Cycles / Syntakt — дизайн

Дата: 2026-10-05. Продолжение [встроенного звука](2026-10-04-internal-audio-design.md) (CHIP, SAMPLE) и пункта «FM 4-op» из [future-audio.md](future-audio.md). Все цифры по CPU — оценки до замера.

## Решения

| Вопрос | Решение |
|---|---|
| Стиль | только машины с макросами, без редактора операторов |
| Машины | KICK, SNARE, METAL, PERC, TONE, CHORD, CLAP, HAT (8) |
| Макросы | DECAY, COLOR, SHAPE, SWEEP, CONTOUR (PITCH = нота + transpose/fine) |
| P-lock | fx `DEC`, `COL`, `SHP`, `SWP`, `CON` в существующих 2 слотах шага |
| Жизнь лока | как Elektron: только нота своего шага; на шаге без ноты — звучащий голос до следующей ноты |
| Огибающая | ударные — one-shot от DECAY; TONE и CHORD — A, S, R из ADSR, DECAY вместо D |
| LFO | один на инструмент, без синхронизации с темпом |
| Полифония | ударные — моно с choke; TONE — MONO/POLY инструмента; CHORD — моно, аккорд в одном голосе |
| Архитектура | общее 4-op ядро + машины как маппинги `macros → параметры ядра` |

## 1. Модель и формат

`InstrType::Fm` перед `Count`. Новые поля `Instrument` (однобайтовые, аудио-задача читает без лока):

- `machine` 0..7 — индекс в таблице машин; новые машины только в конец;
- `decay`, `color`, `shape`, `sweep`, `contour` 0..127; при выборе машины — её значения по умолчанию (макросы 64, DECAY под роль);
- `lfoWave` (sine, tri, saw, square, random S&H), `lfoRate` 0..127 (экспоненциально ~0,05…30 Гц), `lfoDepth` −64..63, `lfoDest` (PITCH, DEC, COL, SHP, SWP, CON, VOL).

ADSR остаётся: у ударных не используется, у TONE и CHORD — A, S, R.

Файл: запись `INST` фиксирована (48 байт), поэтому FM-поля — в новом чанке `FMIN`: 16 записей × 16 байт (11 полей + резерв). Версия 1. Старые прошивки пропускают `FMIN`; неизвестный `type` в `INST` клампится в `Chip`. Старые проекты без `FMIN` — FM-полей по умолчанию.

Fx: `DEC`, `COL`, `SHP`, `SWP`, `CON` перед `Count`, значение 0..127. Входят в `fxSynthOnly` (диапазон `SLD..Count`). Действуют только на FM-инструментах, на остальных INT-инструментах — игнор (как `OFS` вне SAMPLE). Серые — только на MIDI-дорожках, как все synth fx (по типу инструмента GRID не красит, `OFS` тоже).

## 2. FM-ядро

`lib/core/src/synth_fm.{h,cpp}`, без зависимостей от железа. Состояние голоса — `FmVoice` внутри `Voice` (как `ChipOsc`, `Env`).

Оператор (4 шт.): фаза `uint32_t`, синус из таблицы 1024 float с линейной интерполяцией (4 КБ, внутренняя RAM), `ratio`, `level` (индекс у модулятора, громкость у несущей), своя AD-огибающая, `fb` (самомодуляция).

Алгоритмы (`>` — модулирует):

1. `4>3>2>1` — стек;
2. `4>3>1`, `2>1`;
3. `4>3`, `2>1` — две пары;
4. `4>1`, `4>2`, `4>3`;
5. 1, 2, 3, 4 — все несущие.

Общее на голос: огибающая питча (глубина в полутонах, время, кривизна); шум xorshift со своей AD-огибающей (с перезапусками — для CLAP), уровнем и SVF; выход = (несущие + шум) × огибающая громкости.

Темп обновления: маппинг машины, LFO, локи — control-rate (`Synth::kControl` = 32 сэмпла, 1 мс). Огибающие и питч между точками — линейная интерполяция по сэмплам (иначе ступенька на атаке KICK).

Алиасинг: маппинги ограничивают индекс модуляции сверху по высоте ноты.

Стоимость: ~100–150 тактов на голос (в 2–3 раза дороже CHIP), 16 FM-голосов ≈ 25–35 % ядра 0. Если бенч > 60 % — не больше 8 FM-голосов.

### Фильтр — отдельный модуль

SVF (Simper/TPT, LP/BP/HP, cutoff, Q) — в `lib/core/src/synth_filter.h`, не внутри FM-ядра. Здесь он нужен шуму SNARE/CLAP/HAT; позже тот же модуль встанет в CHIP и SAMPLE (отдельный план «фильтр на все типы»).

## 3. Машины

`lib/core/src/synth_fm_machines.cpp`: чистые функции `(machine, macros, note) → FmParams`, таблицы ratio и кривые.

Нота — высота относительно базовой частоты машины на C4: KICK 55 Гц, SNARE 180, PERC 200, METAL 400, HAT 3,5 кГц, CLAP — центр фильтра. Ударные: атака 0,5 мс, DECAY 5 мс…4 с экспоненциально. SWEEP — глубина огибающей питча, CONTOUR — её время и кривизна (кроме отмеченного).

| Машина | Алг. | COLOR | SHAPE | SWEEP / CONTOUR |
|---|---|---|---|---|
| KICK | `2>1` | индекс: синус → панч, клик | ratio модулятора 0,5…2 + fb несущей | sweep 0…48 полутонов / время 5…200 мс |
| SNARE | 2 тона + шум | баланс тон / шум | cutoff BP/HP шума | sweep тона / длина шума относительно тона |
| METAL | `4>1,2,3` | индекс | негармоничные наборы ratio: колокол → коубелл → гонг → тарелка | лёгкий sweep / модулятор гаснет быстрее несущих |
| PERC | `2>1` | индекс: том → дерево, рим, клик | ratio 1…7, есть негармоничные | sweep / время |
| TONE | по SHAPE | индекс (яркость) | зоны: синус, «пила» (fb), «квадрат» (нечётный ratio), стек, колокол | глубина огибающей индекса (pluck) / её время |
| CHORD | все несущие | fb: синус → пила | тип: maj, min, sus2, sus4, 7, m7, maj7, dim, aug, 5, oct, m9 | огибающая fb / время |
| CLAP | шум → BP | частота фильтра | число и разнос бёрстов (5…15 мс) | Q / уровень хвоста к бёрстам |
| HAT | все несущие, негармоничные ratio + fb, шум → HP | cutoff HP | баланс металл / шум | разнос ratio / кривизна спада |

Закрытый / открытый хэт — DECAY (лок `DEC`); choke между ними — моно дорожки.

Расширение: 808/909 — новые машины того же ядра (BD8, SD8, HH8, BD9, SD9 …) в конце таблицы, отдельным планом. Недостающий узел ядра добавляется как опция (как перезапуски шума для CLAP).

## 4. Синт и UI

### Локи

`TrackRt`: `lock[5]`, `lockMask`. `kSynthStep` сбрасывает маску (как `cut`, `sld`). Шаг с нотой: fx пишут в `lock`, note-on даёт голосу макросы = инструмент + локи. Шаг без ноты (ветка `now` в `Synth::fx`): значение сразу в макросы звучащего голоса дорожки, держится до следующей ноты.

### LFO

Фаза в голосе, сброс на note-on. Control-rate. Добавка: макрос ±64, PITCH ±12 полутонов, VOL ±100 %; кламп, затем пересчёт маппинга.

### Голоса

- Ударные: всегда моно на дорожке; новая нота перезапускает голос с fade 2 мс (без легато).
- TONE: MONO/POLY инструмента, glide и SLD как у CHIP.
- CHORD: один голос, моно; аккорд — ratio несущих.

Существующие fx на FM: SLD, VIB, ARP, VSL, CUT, PBN, PGM работают; OFS — серый. ARP на CHORD — весь аккорд от новой ноты.

### UI

- INST, тип FM: MACHINE, DECAY, COLOR, SHAPE, SWEEP, CONTOUR · LFO WAVE, RATE, DEPTH, DEST · VOL, TRANSPOSE, FINE, ADSR. У ударных A, D, S, R серые; у TONE и CHORD серый D. MONO активен только у TONE. PREVIEW — C4.
- GRID: новые fx в выборе; серые на MIDI-дорожках (общее правило synth fx). `fx_info` — описания, 0..127.

## Тесты (native)

- Ядро: частота несущей, нулевой индекс — чистый синус, маршрутизация алгоритмов, fb ограничен.
- SVF: LP пропускает низ / режет верх, стабильность при максимальном Q.
- Маппинги: границы, монотонность COLOR, нет NaN/inf, индекс ограничен на высоких нотах.
- Локи: шаг с нотой / без ноты, сброс на следующем шаге.
- LFO: формы, кламп.
- Choke: новая нота ударной машины занимает тот же голос, fade без скачка.
- Формат: `FMIN` туда-обратно, старый файл без `FMIN`, неизвестный тип в `INST`.

## Риски

- Реальная стоимость FM-голоса — до замера неизвестна; запасной вариант — ≤ 8 FM-голосов.
- Wi-Fi-стек на ядре 0 конкурирует с аудио — бюджет закладывать ~60 %.
- Тембры машин подбираются на слух на железе; native-тесты проверяют только корректность.
