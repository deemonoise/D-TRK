# Клэмпы v2 — план реализации

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 4 лапки, прижимающие модуль за угловые бобышки, на существующих стойках верха.

**Architecture:** Новый `module clamp2(dx, dy)` в `enclosure/case.scad`: hull винта и бобышки,
площадка `foam_t` и штырёк в отверстие бобышки. `part = "clamp2"` — 4 лапки на столе,
assembly показывает лапки. Коммиты не делать (правило пользователя).

**Tech Stack:** OpenSCAD 2021.01 (`/Applications/OpenSCAD-2021.01.app/Contents/MacOS/OpenSCAD`).

В «Производные» после `clamp_ys`:

### Task 2: module clamp2 и part

**Files:** Modify: `enclosure/case.scad` (после `module clamp`, assembly, выбор part)

```
// ---------- Лапка v2: винт на стойке, площадка со штырьком на бобышке ----------
// (dx, dy) — смещение центра бобышки от винта
module clamp2(dx, dy) {
    difference() {
        union() {
            hull() {
                cylinder(r = post_r, h = clamp_t);
                translate([dx, dy, 0]) cylinder(d = boss_d, h = clamp_t);
            }
            translate([dx, dy, clamp_t - 0.01]) {
                cylinder(d = boss_d, h = foam_t + 0.01);
                cylinder(d = pin_d, h = foam_t + pin_h + 0.01);
            }
        }
        translate([0, 0, -1]) cylinder(d = screw_d, h = clamp_t + 2);
    }
}
function clamp2_off(i, j) = [boss_xs[i] - clamp_xs[i], boss_ys[j] - clamp_ys[j]];
```
Assembly: заменить строку старых планок на
```
for (i = [0, 1], j = [0, 1]) color("orange")
    translate([clamp_xs[i], clamp_ys[j], clamp_zt - clamp_t])
        clamp2(clamp2_off(i, j)[0], clamp2_off(i, j)[1]);
```
Выбор part: `else if (part == "clamp2") for (i = [0, 1], j = [0, 1]) translate([i*25, j*30, 0]) clamp2(clamp2_off(i, j)[0], clamp2_off(i, j)[1]);`
Шапку файла дополнить `"clamp2"`.
