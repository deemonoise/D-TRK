# FILL: генераторы аккордов (CHORDS) и баса (BASS) — дизайн

FILL получает ещё два типа: CHORDS пишет аккордовую последовательность на одну дорожку (корень +
CHD), BASS — басовую линию в гармонии с аккордами. Оба устроены как ARP: чистые модули в
`lib/core`, live preview / OK / Cancel / undo — общие из FillDialog, factory + user-паттерны,
Capture.

## 1. Встраивание

- `FillSpec::arp` (bool) → `FillType type {Fill, Arp, Chords, Bass}`; строка `Type: FILL / ARP /
  CHORDS / BASS`. `ChordSpec` и `BassSpec` живут в GridScreen рядом с `fillSpec_` / `arpSpec_` (RAM).
- Модули: `lib/core/src/chord_gen.{h,cpp}`, `lib/core/src/bass_gen.{h,cpp}`; native-тесты
  `test/test_chords`, `test/test_bass`.
- Ритм обоих — формат токенов ARP (`x X o . - s l ~ :vel:gate:nudge`, arp_gen.h). Из `arp_gen`
  в общий доступ выносятся: токенайзер шага, `putFx`, `arpFx`, `gateValue`, `mutateStep`.
- Запись на Dest заменяет note / vel и «арповые» fx (GAT TIE SLD NDG RAT PRB CHD ARS ARP), остальные
  локи остаются; нет свободного слота — fx пропускается. Drum Dest — ничего не пишется (строка
  красная), как в ARP.
- User-файлы: `/presets/PRG/NAME.prg` (прогрессии), `/presets/BAS/NAME.bas` (бас-паттерны);
  storage по образцу `arp_store`. Ритмы CHORDS — только factory.

## 2. CHD: новые типы и обращения

Значение: `val = inv * kChordTypes + type`, inv 0..3. Старые 0..7 не меняются (inv 0) — проекты
совместимы. 35 типов × 4 = 140 значений (< 0xFF = `kNoArpChord`). FX-диапазон CHD:
`0 .. kChordTypes * 4 - 1`, линейно энкодером.

Показ — 4 символа: 3 — тип, 4-й — обращение (пробел / `1` / `2` / `3`): `MA7 `, `MA71`, `tri2`.
Обращение k: k нижних нот аккорда +12 (k ≥ числа нот — по кругу). Выход `chordNotes` — по
возрастанию; нота шага остаётся корнем аккорда. Лимит 4 ноты, ноты > 127 отбрасываются.

Диатоничные (строчные, ступени лада от ноты; Chromatic = мажор от ноты):

|---|---|---|---|---|
| `tri` | 1 3 5 | | `ad9` | 1 3 5 9 |
| `7th` | 1 3 5 7 | | `pwr` | 1 +7 пт |
| `su2` | 1 2 5 | | `oct` | 1 +12 |
| `su4` | 1 4 5 | | `9th` | 1 3 7 9 |
| `6th` | 1 3 5 6 | | `7s4` | 1 4 5 7 |
| | | | `a11` | 1 3 5 11 |

synth ARP-аккорд, arp_gen, fx_info, FILL ARP Chord) получают новые значения через `chordNotes` /
`chordName` без своих изменений, кроме диапазонов.

## 3. CHORDS

### Прогрессия (текст)

Токены через пробел: `[b|#]ступень[качество][*длина]`.
- ступень 1..7 от scale root проекта по ладу (короткие лады — дальше в следующую октаву, как
  `degreeNote`). С `b` / `#` — римская нотация: ступень мажорной гаммы от scale root ± полутон
  (`b6` = +8, `b7` = +10 в любом ладу); `n` — ступень мажора без сдвига (`n6` в миноре = натуральная
  VI).
- качество — имя CHD-типа (`MI7`, `DOM`, `tri`…). Без качества: диатоничный тип из параметра Type;
  с `b` / `#` без качества — `MAJ`.
- `*N` — длина в единицах Length (по умолчанию 1).
- Примеры: `1 5 6 4`, `2MI7 5DOM 1MA7*2`, `1 b7 b6 5`.

Разворачивается в список сегментов `{корень, CHD, шагов}` (≤ 16 аккордов).

### Параметры

- **Progression**: factory → user → RANDOM
- **Chords** (только RANDOM): 2..8
- **Octave**: октава корней, C2..C5
- **Type**: TRIAD / 7TH / 9TH / SUS — для токенов без качества (`tri` / `7th` / `9th` / `su4`)
- **Voicing**: ROOT (inv 0) / CLOSE (обращение каждого аккорда — с минимальной суммой сдвигов
  голосов от предыдущего; первый — inv 0; корень держится в пределах Octave ± 6 полутонов, иначе
  ±12)
- **Length**: шагов на единицу аккорда, AUTO = диапазон / сумма длин; 1..64
- **Dest**, **Rhythm**, **Gate %**, **Vel Lo / Hi**, **Mutate %**, **Seed / Reseed**, **Capture...**

### Запись

Ритм перезапускается с каждым аккордом. Удар (`x X o`) — корень + CHD (с обращением) + velocity
(как в ARP: ghost = Lo, acc = Hi, norm = середина, `:vel` — точная) + GAT (Gate, short / long,
`:gate`). `-` — TIE на предыдущей ноте; конец аккорда / пауза после тая — OFF. Тай до конца
диапазона — длинный GAT (до 800 %), как в ARP. Модификаторы высоты токенов (`r p ^ v`) в ритмах
игнорируются, `^` / `v` — октава аккорда.

### RANDOM

Markov по функциям: T (I, vi, iii) → S (IV, ii) → D (V) → T, отдельные таблицы весов для
мажорных и минорных ладов (минорные — с b6 / b7: i, iv, v, VI, VII). Первый аккорд — I, последний
тяготеет к V или IV (цикл замыкается). Детерминирован по Seed.

**Mutate %** (и для factory / user): замена аккорда родственным (мажор: I↔vi, ii↔IV, iii↔V; минор: i↔III, iv↔VI, v↔VII) и смена
Type у токенов без качества и без `b` / `#` / `n`; плюс мутации ритма как в ARP.

### Factory

Ритмы (~16): HOLD, HALF, QUARTER, 8THS, STAB, OFFBEAT, CHARLESTON, HOUSE PNO, DUB SKANK, REGGAE,
TRNC GATE, SYNCOPA, PUSH, FUNK, POP 8, BALLAD.

Прогрессии (~30): POP (1 5 6 4, 6 4 1 5, 1 6 4 5, 1 4 6 5), JAZZ (2 5 1, 1 6 2 5, 3 6 2 5,
2MI7 5DOM 1MA7), MINOR (1 b6 b3 b7, 1 b7 b6 b7, ANDALUS 1 b7 b6 5, 1 4 5 1), HOUSE / DEEP (1MI7
4MI7, 1MI9 b7MA7, 2MI7 1MA7), TRANCE (1 b6 b3 b7, 6 4 1 5, 1 b6 b7 1), SYNTHWAVE (1 b6 b7 1, 6 4 5
5), DUB (1 b7), BLUES (12 тактов 1 1 1 1 4 4 1 1 5 4 1 5, доминанты), ROCK (1 b7 4 1, 1 4 5 4),
MODAL (DORIAN 1 4, PHRYG 1 b2, LYDIAN 1 2).

### Capture

Dest-диапазон: новый аккорд там, где меняются нота или CHD. Ступень — от scale root; нота в ладу —
ступень + качество (имя CHD); вне лада — `n` / `b` / `#` + качество; нота без CHD — `MAJ` / `MIN` по ладу.
Длина — `*N` в шагах; файл начинается токеном `@steps`, при нём Length = 1 шаг. Имя с клавиатуры,
`/presets/PRG/NAME.prg`.

## 4. BASS

### Источник аккорда на шаге

- **ROOT**: тоника лада (Root / Octave), триада лада от неё — весь диапазон.
- **SELECTION**: как в ARP — нижняя нота + CHD шага выделения задаёт аккорд до следующей смены
  аккорда; читается из снимка на open(). «Следующий аккорд» ищется и за концом диапазона (до конца
  паттерна), иначе — первый аккорд диапазона.
- **PROGRESSION**: текущая прогрессия CHORDS (тот же `ChordSpec`, сегменты на диапазон).

Корень аккорда переносится в октаву Octave (C1..C3).

### Паттерн

Токен ARP, высота — роль относительно аккорда шага:
- `1` корень (по умолчанию), `3` `5` `7` — тоны аккорда (нет такого тона — ступень лада от корня)
- `^` / `v` — октава вверх / вниз (комбинируется: `5^`)
- `a` — подход полутоном снизу к корню следующего аккорда (последний аккорд — к первому)
- `w` — шаг по ладу от предыдущей ноты к корню следующего аккорда
- `r` — повтор предыдущей ноты
- ритм / акцент / длина / slide / `:vel:gate:nudge` — как в ARP

Парсер / формат — свои (`parseBassPattern` / `formatBassPattern`), на общем токенайзере.

### Параметры

**Source**, **Root** (ROOT), **Octave**, **Dest**, **Pattern** (factory → user), **Rate** ×1..4,
**Rotate**, **Gate %**, **Swing**, **Vel Lo / Hi**, **Slide**, **Mutate %**, **Seed / Reseed**,
**Capture...**. Запись — как ARP (TIE / OFF / SLD / GAT / NDG), без RAT / PRB.

### Factory (~24)

HOUSE OFF, DISCO OCT, TECHNO RL, TECHNO 16, ACID 1..3 (slide / acc), DNB, REESE, DUB, REGGAETN,
SYNTHW 8, ELECTRO, FUNK, WALKING, ROCK 8, TRNC OFF, PSY (16-е, пауза на долю), UKG, BOOGIE,
OCT JUMP, ROOT 5TH, APPROACH.

### Capture

Dest-диапазон (≤ 32 шагов) → паттерн как `captureArp`, высота — роль относительно аккорда шага
по текущему Source: корень / 3 / 5 / 7 (± октава), полутон под следующим корнем — `a`, та же
нота — `r`, иначе ближайший тон аккорда. `/presets/BAS/NAME.bas`.

## 5. UI

FillDialog: строки CHORDS и BASS — свои наборы в `buildRows`, как ARP; Seed / Reseed — только при
RANDOM / Mutate. Списки user-файлов читаются при первом показе типа (вне project lock), как ARP.
Toast на OK: `CHORDS` / `BASS`. Preview / restore / undo покрывают выделение и Dest.

## Проверка

native-тесты:
- scale: все новые типы `chordNotes` (мажор / минор / Chromatic), обращения 1..3, совместимость
  0..7, `chordName` 4 символа.
- chords: парс / формат прогрессий, `b` / `#` / качество / `*N`; разворот Length / AUTO; RANDOM
  детерминирован по Seed, первый — I; CLOSE-голосоведение (минимальные сдвиги); TIE / OFF / GAT;
  Capture round-trip.
- bass: роли 1 / 3 / 5 / 7 / ^ / v / a / w / r; смены аккорда SELECTION и PROGRESSION; ROOT;
  Mutate детерминирован; Capture round-trip.

`pio test -e native`, сборка wt32, проверка на железе; коммит — после проверки на железе.
