# Планы на будущее: свои KIT-пресеты

Статус: **не сделано** (напоминание от 2026-10-09).

Сейчас у KIT только заводские пресеты (`[FACTORY]` → KIT, `lib/core/src/presets_factory.cpp`):
кит + его барабаны в блоке INS25..32 (INS17..24 для кита там же), `factoryBuildKit`. PRESET на KIT
сразу открывает Load; Save для KIT нет, папки `/presets/KIT` нет (`presetTypeHas(Kit) == false`).

## Что сделать

- Сохранять свой кит на SD: дорожки (`KitLane`) + инструменты, на которые они ссылаются (INST-дорожки),
  одним файлом — `.mti` хранит один инструмент, нужен свой формат (например `.mtk`).
- SAMPLE-дорожки хранят имя сэмпла: при загрузке — как SAMPLE-пресет (есть в проекте — берём, нет — красный).
- Загрузка: барабаны в тот же блок, что у заводских (`factoryKitBlock`), CANCEL откатывает блок.
- Папка `/presets/KIT` (создание на SD, `file_rules`, веб-страница Presets), тип KIT в Save.
- Тесты: round-trip файла, загрузка в блок, откат.
