# Предпрослушка WAV при импорте

## Задача

FILE → SAMPLES → Import: в списке WAV кнопка Play проигрывает файл под курсором, не импортируя его.

## Решения

- Отдельный одноразовый плеер в аудиозадаче (`mt::OneShot`, lib/core): подмешивается к выходу синта
  после рендера. Синт, банк и flash не трогаются.
- UI читает файл с SD той же цепочкой, что импорт (`wavParse` → `wavToMono` → `Downsampler`),
  в буфер PSRAM: моно, ≤ 32 кГц, первые 8 с (≤ 512 КБ). Пока грузится — «LOADING...».
- Передача буфера UI → аудиозадача: атомарный номер запроса; аудиозадача подтверждает каждый
  запрос. Буфер освобождается только после подтверждения остановки (тайм-аут — буфер не
  освобождается, утечка безопаснее чтения освобождённой памяти). park() (запись flash) тоже
  останавливает плеер и подтверждает.
- Громкость: как сэмпл на vol 127 с учётом Master (`mv/100`), сложение с насыщением.
- Управление: Play на файле — играть, повторный Play — стоп; сдвиг курсора, вход в папку, выбор
  файла, закрытие списка, уход с экрана — стоп. Play на папке / Back — ничего. В режиме списка WAV
  кнопка Play транспорт не запускает (тач-кнопка транспорта в шапке работает).
- Ошибки чтения — тост с текстом `bankResultText`.
- Банк (уже импортированные сэмплы) не прослушивается — не нужно.

## Тесты

native: `test_oneshot` — проход 1:1, половинная частота (вдвое длиннее, интерполяция), конец
буфера (тишина, playing() = false), stop(), громкость и насыщение.
