# Вторая волна переноса Teensy → ESP

Основа — текущее проверенное рабочее дерево после первых шести блоков. Снимок исходного DSP: `/private/tmp/dtrk-wave2-baseline`. Без коммитов/push. Production WT32 прошивать после готовности; N16R8-стенд разрешено прошивать диагностическими сборками для измерений. RGB стенда выключать при старте.

## Объём

1. Извлечение области/слайса, нормализация, float32 WAV.
2. BPM detection, новый onset scan, 128 слайсов.
3. Офлайн time-stretch с сохранением высоты, длительность 50–200%.
4. Sample → wavetable и DRAW ключевых кадров.
5. PERF repeat/scratch; по последнему указанию пользователя убрать триольные длительности, сохранив безопасное чтение старых raw IDs.
6. Матрица модуляции: 8 маршрутов, legacy LFO работают как раньше; только поддерживаемые текущими движками цели.

Сохранить старый FM, KIT8, частоту 32 кГц, производственную quad PSRAM N16R2. Для N16R8 отдельная octal-конфигурация. Без новых FM/HyperSaw/STRING/сложных фильтров.

## Распределение

- Sample worker: алгоритмы, локальные порционные jobs, SampleEditor и диалог извлечения/stretch.
- WT worker: maker, draw/editor/audition, WT UI.
- DSP/bench worker: матрица, DSP-интеграция, LED и исключительный доступ к USB-стенду.
- Интегратор: общая модель/кодеки, PERF, bank backend и InstScreen/App, документация и общая проверка.

## Форматы

Заморозить legacy SLCE32; расширенные SLX1 и MODM чанки проекта. Новые пресеты ESP: v12 с header tag E8, прежним FM v8-prefix и расширениями SLX1/MODM. v1–8 читаются без миграции FM; v9–11 другой FM-семьи отвергаются явно. Зарезервировать AC2 ID перед M01…M08 для совместимых числовых IDs, не предлагать AC2 в KIT8 UI.

## Проверка и критерии

- Сначала поведенческие регрессии: формат, отмена/ошибка без изменения оригинала, неполные/невалидные WAV, границы слайсов, матрица с пустыми маршрутами bit-exact, locks/motion, legacy PERF IDs.
- Все операции доступны через UI и работают через местный банк/SD, без RPC/Teensy link.
- Ограниченная временная RAM, порционная обработка и отмена offline jobs; результат публикуется только после успеха.
- Полный native suite, sanitizer host tests, production WT32 и N16R8 builds, clangd, применимые quality-gates с точным отчётом об ограничениях C++.
- На стенде: время/RAM offline операций, сравнение DSP до/после с пустой и заполненной матрицей, PERF active/inactive. Подтверждать активные голоса/PCM/DONE и фактическую N16R8. Не выдавать headless за проверку экрана/SD/quad PSRAM.
