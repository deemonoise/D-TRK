files written by a newer block do not open on older firmware).

Block 2, tasks 6–11 (2026-10-06): synth lanes (`Voice::lane` / `laneInst`, `instrOf`, `allocVoice(...,
polyMax)`), Euclid lane, Transpose skips drum tracks, MIDI import onto lanes, GRID mask / lane pad /
track buttons, Euclid dialog `Lane`, INST KIT pages (MAIN + LANES), no KIT presets (`presetTypeHas`),

sample list, so lanes were already covered; FILE → SAMPLES Delete now asks through

host stubs only — `pio run -e wt32` still to run. `Voice` grew by `sizeof(Instrument)` (358 B on
the host), ~5.7 KB for 16 voices: check the boot heap log.

Rules for every session: no commits unless asked; run `pio test -e native` and `pio run -e wt32`
at the end of each task; do not stop for hardware checks — finish the plan, then summarize what to
verify on the device.

Dropped / deferred ideas (see the discussion of 2026-10-06): more than 16 patterns (chain transpose
covers it), song loop points, USB-MIDI device, SMF export, LSDJ-style tables, pan (mono output).
