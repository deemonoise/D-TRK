Block 3 (2026-10-06): chain items with transpose / passes / scene (`CHN2`), per-track length
(`TLEN`, `Pattern::trackLen`), mute scenes (`SCNS`, BANK tiles), fill (`CND FIL / NFL`, Shift + Play
held), REC and PERF on the track buttons (`PlayRelease` / `TrackRelease` events, `Cmd::Fill / PerfOn /
PerfOff`, `Status::fill / stepT / stepUs`). 772 native tests pass (g++ + a Unity shim, the PlatformIO
registry still unreachable); UI, engine and trackio type-checked against host stubs only. Choices
beyond the plan: an out-of-range scene in `CHN2` loads as none; deleting the playing chain item
advances at the pass end; REC on a drum track toggles lanes; PERF Fade on a MIDI track halves the
velocity; tapping a track name in REC selects the track instead of muting. To verify on the device:
`pio run -e wt32`, button release timing (fill, PERF), REC landing on the right step, BANK row fields
and scene tiles, the GRID loop line of a short track.

Block 4 (2026-10-06): `Drive` (tanh table, per voice before the filter, lock `DRV`, LFO `DRIVE`),
`Reverb` (Freeverb-lite, 23 KB float buffer in PSRAM, send per instrument, lock `RVB`, idles once its
tail dies out), `Compressor` (master, sidechain bus of `scTrack`), `ARM` modes / rate and ARP + CHD
(`kSynthArpChord`, chord computed at note-on from the played note), velocity -> cutoff / DECAY.
Formats: FMIN bytes 10..13, AUDI 13 bytes, presets v4. 807 native tests pass (g++ + Unity shim);
UI type-checked against host stubs. Choices beyond the plan: ARM DOWN starts from the top note;
makeup gain = threshold drop / 4 (design text) not / 2 (plan code); KIT sampler lanes take the kit's
Rvb send; KIT MAIN page shows Rvb send. To do on the device: `pio run -e wt32`, the CPU bench
(`pio run -e wt32-fxbench`, numbers into the design doc), listening.

Block 5 (2026-10-06): `mt::OfflineRender` (own sequencer on a virtual block clock, live synth,
analytic length, only note-offs after the end, deterministic seed), `Sequencer::setTrackMask`,
`storage::renderWav` / `resample`, `audio::Paused` / `liveSynth`, `audio::cacheWrite` (bank write from
generated data, `finishImport` shared with WAV import), FILE `Render WAV...`, GRID `Resample track /
pattern`, TRACK MIXER view (MAIN = master volume, gone from PROJ), hold a track button + turn =

strips 1-8, MAIN, 9-16. Block 4 still waits for its device check (CPU bench numbers).

After the blocks (2026-10-06, from device feedback):
- Step arp `ARS` (fx, INT and MIDI): the sequencer plays the arp as real notes on the following
  steps without a note, every 1..8 steps, ARM orders, 1..4 octaves (`U12` = up, every step, 2
  octaves); notes = CHD chord, else ARP 0/x/y, else the root over at least 2 octaves; stops on a
  note step, OFF, a pattern change, stop. The fast synth ARP / ARM stay as they were.
- Fx command order grouped by meaning in GRID (`fxNextCmd` table; the enum / file format is
  unchanged): notes and arp, timing, chance, pitch and level, sound locks, sample, sends, MIDI only.
- MIDI import: no second project copy (the confirmation runs `importPlan`, the commit imports
  straight into the live project under the lock); the note buffer follows the file size. Fixes NO
  MEMORY on confirm.
- SD: WAV data clamped to the file size (cut files no longer read past the end); `hw::sdRecover`
  remounts only when the card stops answering; `sdBegin` retries with a bus reset. Fixes the card
  being lost until reboot after a sample import / preview error.
- MIXER became the MIX tab of the bottom bar (seven tabs); the Shift + tap / Shift + click / menu
  toggles are gone.
