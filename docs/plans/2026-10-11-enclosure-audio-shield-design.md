# Корпус под Teensy Audio Shield — дизайн

Ветка `feature/teensy`, `enclosure/case.scad`, вариант `trk = true`. Вариант без кнопок дорожек не меняется.

## Цель

Звук — Teensy Audio Shield Rev D (SGTL5000) вместо ЦАП PCM5102A и усилителя MAX97220. Платы на дне не клеятся, а заезжают по пазам.

## Решения

| Вопрос | Решение |
|---|---|
| Шилд | рядом с Teensy на проводах (I2S + MCLK 7, 8, 20, 21, 23; I2C 18, 19; 3V3, GND), не бутербродом |
| Наушники | гнездо шилда торчит в переднюю стенку (рядом с картой Teensy), подпись PHONES; заднее гнездо PHONES убрано |
| Задняя стенка | тумблер, MIDI, Type-C |
| Размеры шилда | футпринт PJRC Rev D: 36,83 × 35,56, гнездо на крае 36,83, ось в 5,1 мм от правого угла (вид сверху, гнездо к себе) |
| Профиль паза | полка под краем 0,8, губа над краем 0,8 × 1,2, зазоры 0,15 над платой и к стенке |
| Teensy | сзади вперёд; губы только на передних 30 мм (провода — с 35 мм), задняя часть на двух рейках между рядами пинов; назад держит упор верхней части за USB |
| Шилд | сзади вперёд, пазы на всю длину, защёлка-клин 0,25 за задним краем |
| IP5306 | спереди назад, Type-C в заднюю стенку, пазы на всю длину, защёлка перед передним краем; ставить до аккумулятора |
| PCF8575 | бортики, переехал за шилд |

Отклонено: шилд бутербродом на коротких штырях (пользователь выбрал провода), губы по всей длине Teensy (края с проводами), защёлка для Teensy (губ у заднего края нет — упор на верхней части).

## Раскладка (мм, от левого переднего угла)

Teensy: центр x = 21, передний край y = 2,5, полки 3 мм. Шилд: x = 34…70,8, передний край y = 2,7, полки 2 мм, ось гнезда x = 65,7, z = 4,6. PCF8575: центр (71, 66). Упор Teensy — между рядами свичей (y 64,6…66,4).

## Замерить

`aud_jack_dx`, `aud_jack_z`, `aud_jack_out` (гнездо), `teensy_usb_out`, посадка в пазах (`rail_gap`, `rail_clr`, `snap_h`).
