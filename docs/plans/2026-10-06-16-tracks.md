# 16 Tracks Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Raise the track count from 8 to 16; old project files still load; the GRID overview and the 8 track buttons work on the half (1–8 / 9–16) that holds the cursor.

**Architecture:** `kTracks` becomes 16 and everything sized by it follows. The PATN reader infers the file's track count from the chunk size instead of assuming `kTracks`. The "half" is not state: it is `curTrack / 8`, so moving the cursor is the only way to switch it. Activity / LED masks widen to 16 bits in the core and the engine; the LED mask for the 8 physical LEDs is cut out of the half that holds the selected track.

**Tech Stack:** C++17, PlatformIO (`pio test -e native` for the core, `pio run -e wt32` for the firmware), Unity tests. Design: `docs/plans/2026-10-06-16-tracks-design.md`.

```cpp
// A PATN body: `tracks` tracks of `stepBytes`-byte steps (6 = the 2-slot format, 14 = current).
static std::vector<uint8_t> patn(uint8_t idx, uint8_t len, int extraBytes = 0, int tracks = kTracks,
                                 int stepBytes = 6) {
  std::vector<uint8_t> p = {idx, len, static_cast<uint8_t>(Resolution::Eighth), 60};
  for (int t = 0; t < tracks; ++t)
    for (int s = 0; s < len; ++s) {
      std::vector<uint8_t> st(stepBytes, 0);
      st[0] = static_cast<uint8_t>((t + s) % 128);
      st[1] = 100;
      p.insert(p.end(), st.begin(), st.end());
    }
  if (extraBytes > 0) p.resize(p.size() + extraBytes, 0);
  if (extraBytes < 0) p.resize(p.size() + extraBytes);
  return p;
}
```

```cpp
// 16 tracks on 8 LEDs: the half (tracks 0-7 or 8-15) holding the selected track; flash bit = track.
inline uint8_t trackLedMaskHalf(int selected, uint16_t flash) {
  const int half = selected >= 8 && selected < 16 ? 1 : 0;
  const uint8_t f = static_cast<uint8_t>(flash >> (half * 8));
  return trackLedMask(selected >= 0 ? selected - half * 8 : -1, f);
}
```

```cpp
void App::updateLeds(uint32_t now) {
```
