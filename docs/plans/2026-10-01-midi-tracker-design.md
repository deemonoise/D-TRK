# MIDI-трекер на WT32-SC01 Plus — дизайн

Дата: 2026-10-01

## Цель

MIDI-секвенсор с трекерным интерфейсом на WT32-SC01 Plus: 8 MIDI-дорожек, длина паттерна 4–128 шагов (по умолчанию 16, общая для всех дорожек), MIDI OUT (миниджек TRS type A), энкодер, кнопки Play/Stop и Shift, тач. Сохранение/загрузка проектов на SD, импорт MIDI-файлов, генератор Euclidean-ритмов с ладом.

Решения, принятые на брейншторме:

- синхронизация: только мастер (внутренний темп, MIDI Clock + Start/Stop/Continue на выход), MIDI IN нет;
- банк из 16 паттернов с квантованным переключением, формат файла с заделом под song mode (chain);
- разрешение шага и swing задаются на паттерн; nudge — модификатор шага;
- дорожки монофонические, аккорды через модификатор `CHD`;
- импорт MIDI с полным экраном маппинга;
- глобальный лад проекта со scale lock;
- UI: LovyanGFX + собственный рендер (без LVGL).

## 1. Железо и распиновка

Плата: ESP32-S3 (WT32-S3-WROVER-N16R2: 16MB flash, 2MB PSRAM), дисплей 3.5" 480×320 ST7796 (шина 8080, 8 бит), тач FT6336U (I2C), microSD (SPI).

Разъём Extended IO (5V, GND, IO10–14, IO21):

| GPIO | Функция | Реализация |
|---|---|---|
| 10 | MIDI OUT | UART1 TX, 31250 бод |
| 11 | Энкодер A | PCNT (аппаратная квадратура) |
| 12 | Энкодер B | PCNT |
| 13 | Кнопка энкодера | вход, pull-up, дебаунс 5 мс |
| 14 | Play/Stop | вход, pull-up |
| 21 | Shift | вход, pull-up |

Кнопки замыкают на GND. Энкодер EC11, желательны конденсаторы 10 нФ на A/B.

MIDI OUT, TRS type A, 3.3 В:

```
+3.3V  ──[33 Ω]── Ring   (MIDI pin 4, source)
GPIO10 ──[10 Ω]── Tip    (MIDI pin 5, sink)
GND    ────────── Sleeve (MIDI pin 2, экран)
```

UART без инверсии. Опционально буфер 74HC14 (два инвертора последовательно).

Встроенная периферия: SD — CS 41, MOSI 40, CLK 39, MISO 38; тач — SDA 6, SCL 5, INT 7, RST 4 (общий с LCD).

Резерв: RS485 (GPIO 1, 2, 42), I2S-усилитель (GPIO 35, 36, 37) — например, под метроном.

## 2. Модель данных

**Шаг** (6 байт):
- `note`: 0–127, пусто, или `OFF` (явный note-off, обрывает `TIE`);
- `vel`: 1–127 или пусто (дефолт дорожки);
- `fx1`, `fx2`: команда (1 байт) + значение (1 байт).

**Паттерн** (×16): длина 4–128 (по умолчанию 16), разрешение (1/4, 1/8, 1/16, 1/32, 1/8T, 1/16T), swing 50–75%, 8 дорожек × 128 шагов. Весь банк ≈ 96 КБ в PSRAM.

**Дорожка** (на проект): имя, MIDI-канал 1–16, дефолтные velocity и gate, номера CC для слотов A/B, опциональный Program Change при старте, mute/solo (сохраняются).

**Проект**: имя, BPM 20–300, лад (тоника + тип: major, minor, dorian, phrygian, lydian, mixolydian, locrian, harmonic minor, melodic minor, pentatonic major/minor, blues, chromatic), 16 паттернов, chain[64] (зарезервировано под song mode).

**Модификаторы шага** (2 слота):

| Код | Значение | Действие |
|---|---|---|
| `CHN` | 1–16 | канал только для этого шага |
| `RAT` | 2–8 | ratchet: N повторов внутри шага |
| `PRB` | 0–100% | вероятность срабатывания |
| `GAT` | 1–800% | длина ноты в % шага |
| `TIE` | — | легато до следующей ноты, без ретригера |
| `NDG` | −50..+50% | микросдвиг во времени |
| `CHD` | тип | аккорд от ноты в ладу (triad, 7th, sus2, sus4, power, octave…) |
| `STR` | 1–50% | strum: разнос нот аккорда во времени |
| `CND` | A:B, `FST` | условие: играть на A-м проходе из B; `FST` — только первый проход |
| `VRN` | 0–64 | случайный разброс velocity ± |
| `NRN` | 1–7 | случайная нота ± N ступеней лада |
| `CCA`/`CCB` | 0–127 | CC (номер задан в дорожке) |
| `PBN` | −64..+63 | pitch bend |
| `PGM` | 0–127 | program change |

## 3. Движок секвенсора (ядро 0)

**Тайминг** — планировщик событий с абсолютным временем в мкс:
- в начале шага N просчитывается шаг N+1 целиком (lookahead нужен для отрицательного `NDG`): ноты, ratchet, strum, аккорды, note-off по gate, CC/PB/PGM;
- события кладутся в min-heap по времени;
- `gptimer` ставит alarm на ближайшее событие, ISR будит задачу с наивысшим приоритетом, она пишет байты в UART1;
- целевой джиттер < 100 мкс независимо от UI и SD.

**MIDI Clock** 24 PPQN — отдельный поток событий в том же планировщике.

**Транспорт:**
- Play: старт/стоп. Старт — `Start` (0xFA), clock с начала паттерна; стоп — `Stop` (0xFC), note-off всех нот, сброс в начало;
- Shift+Play: пауза/продолжение. Пауза — `Stop` + note-off; продолжение — `Song Position Pointer` + `Continue` (0xFB).

**Swing**: каждый чётный шаг задерживается на `(swing − 50) / 50 × длина шага`.

**Note-off**: таблица активных нот [канал][нота]; повтор той же ноты закрывает предыдущую; на стоп и смену паттерна закрываются все (`TIE` не переживает смену паттерна).

**Смена паттерна**: в очередь, применяется в конце прохода. Счётчик проходов на паттерн — для `CND`.

**Live-правки**: BPM, длина, swing применяются сразу (уменьшение длины заворачивает плейхед). Запись шага из UI — под коротким spinlock.

**Mute/solo** проверяются при просчёте шага; звучащие ноты не обрываются.

Running status не используется.

## 4. Интерфейс и управление

Экран 480×320, горизонтально.
- Верхняя строка: проект (`*` если не сохранён), паттерн (`P03→P05` при очереди), BPM, длина/разрешение, состояние транспорта, счётчик проходов.
- Нижняя строка: вкладки `GRID | TRACK | BANK | PROJ | FILE`, индикатор Shift.
- Сетка: 17 строк по 16 px, номера шагов, подсветка плейхеда, режим follow.

Виды сетки:
- **Overview** — 8 дорожек: нота, полоска velocity, маркеры наличия fx;
- **Detail** — 2 дорожки: `нота vel fx1 fx2`.

Энкодер:
- навигация: поворот — вверх/вниз; Shift+поворот — влево/вправо;
- нажатие — правка поля: поворот меняет значение (нота по ладу), Shift+поворот — грубо (октава / ×10); нажатие — выход;
- долгое нажатие (0.5 с) — контекстное меню (copy/paste/clear шага или дорожки, Euclid, транспонирование, настройки дорожки);
- Shift+нажатие — Overview ↔ Detail;
- Shift+долгое нажатие — undo (кольцевой буфер ~32 правок).

Тач:
- тап по ячейке — курсор; повторный тап — правка (значение энкодером);
- при правке ноты — мини-клавиатура на октаву с подсветкой нот лада;
- свайп — прокрутка;
- тап по заголовку дорожки — mute, Shift+тап — solo;
- Shift+тап по ячейке — выделение диапазона для блочных copy/paste/clear/transpose;
- тап по BPM/длине/swing в верхней строке — правка энкодером.

BANK: сетка 4×4. Тап — в очередь, Shift+тап — сразу, долгий тап — меню (copy в…, clear, длина/разрешение).

Play/Stop срабатывает по нажатию.

Остальные экраны — списки параметров: TRACK, PROJ, FILE, диалоги Euclid и импорта MIDI.

## 5. Хранение, импорт MIDI, Euclid

Структура SD:

```
/projects/*.mtp   проекты
/midi/*.mid       файлы для импорта
/last.txt         последний проект (грузится при старте)
```

Формат `.mtp` — бинарный чанковый: заголовок `MTRK` + версия; чанки `PROJ`, `TRKS`, `PATN` (только непустые паттерны, только `length` шагов), `CHAN`. Неизвестные чанки пропускаются. CRC32 в конце.

Запись: снапшот в PSRAM → `name.tmp` → проверка CRC → старый в `name.bak` → rename. Сохранение работает во время воспроизведения. Автосейва нет.

FILE: Save, Save As (экранная клавиатура), Load (подтверждение при несохранённом), New, Import MIDI.

Импорт MIDI (SMF 0/1, PPQ-деление; SMPTE → ошибка):
1. парсинг в PSRAM (лимит ~1 МБ), группировка нот по источнику (трек + канал);
2. экран маппинга: источник (имя, канал, число нот, диапазон) → дорожка 1–8 или skip; транспонирование ±24; смещение начала в тактах; разрешение квантования; моно-редукция (верхняя / нижняя / первая); опции «канал источника», «темп из файла», «сохранять микротайминг» (→ `NDG`);
3. длительность → `GAT`, если отличается от дефолта дорожки;
4. длинный материал режется на паттерны подряд от выбранного (до P16).

Euclid (на дорожку): hits, length (≤ длины паттерна, повторяется), rotation; заполнение нот root / up / down / up-down / random в ладу; базовая октава, диапазон; velocity + акцент; seed; replace или merge (только пустые шаги). Превью в сетке до OK, undo.

## 6. Структура кода, ошибки, тесты

Платформа: pioarduino (Arduino-ESP32 3.x / ESP-IDF 5, нужен `gptimer`). Плата `esp32-s3-devkitc-1` с переопределением под 16MB flash и PSRAM `qio_qspi`. Библиотеки: LovyanGFX, SD (SPI), PCNT из IDF.

```
lib/core/      model, scale, euclid, step_expand, project_io, smf_parser  (без железа)
src/hw/        display, touch, input, midi_uart, sdcard
src/engine/    scheduler, transport, clock
src/ui/        экраны и виджеты
src/main.cpp   инициализация, задачи по ядрам
```

Ядро 0 — движок; ядро 1 — UI, тач, энкодер, SD. Обмен: очередь команд UI → движок, снапшот состояния движок → UI.

Ошибки:
- нет SD — сообщение, секвенсор работает, FILE недоступен;
- битый CRC — ошибка и предложение загрузить `.bak`;
- ошибка записи — старый файл цел (запись через `.tmp`);
- неподдерживаемый/слишком большой MIDI-файл — сообщение, проект не меняется;
- лимит событий на шаг; лишние note-on отбрасываются, note-off — никогда;
- all notes off на стоп и смену паттерна;
- watchdog задач.

Тесты:
- `env:native` + Unity для `lib/core`: Euclid против эталонов (E(3,8), E(5,8)…), привязка к ладу, развёртка шага (ratchet, swing, nudge, strum, `PRB`/`NRN` с фиксированным seed, `CND`), round-trip и forward-compat формата, парсер SMF;
- на железе: MIDI-монитор на Mac через USB-MIDI, проверка джиттера; debug-режим дублирует MIDI-байты в USB-serial.
