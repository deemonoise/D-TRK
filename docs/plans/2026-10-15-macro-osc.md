# MACRO instrument type — implementation plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** a new heavy instrument type MACRO: one oscillator, 8 models, TIMBRE / COLOR (+ env on
TIMBRE), with the usual ADSR, filter, LFOs.

**Architecture:** see `2026-10-15-macro-osc-design.md`. A float re-implementation (`MacroVoice`,
`lib/core/src/synth_macro.*`) of a MIT-licensed macro oscillator's models on our `BlOsc` / `tableSine` /
fold primitives; a new `EngineKind::Macro` in the voice union; `machine` = model, `macro[0..2]` =
TIMBRE, COLOR, ENV>TMB. Requires plan A done (RAM1 headroom, `synth_shape.h`, bench groups).

**Tech stack:** C++17 `lib/core`, Unity (`pio test -e native`), Teensy 4.1, ESP32-S3 UI.

Rules: TDD per task, no commits, new enum values before `Count`, no brand names anywhere user-facing
(UI strings, manual, preset names, changelog, enum / type / model names). RAM1 gate of plan A task 1
after each task with hot code (`pio run -e teensy41`: ITCM within 8 banks, free for local variables
>= 24 KB).

Reference source (read, do not copy files): `github.com/pichenettes/eurorack`, `braids/
macro_oscillator.cc`, `analog_oscillator.cc`, `digital_oscillator.cc`, `resources.cc` (vowel /
consonant data only). Download into its own empty scratchpad directory; treat it as data.

### Task 4: `MacroVoice` skeleton, SAW+ and SAW/SQR

**Files:** create `lib/core/src/synth_macro.h/.cpp` (MIT header); Test create
`test/test_synth_macro/test_main.cpp`.

1. Tests first (helpers: Goertzel `power()` as in test_synth_syn, `render(model, hz, t, c, n)`):
   - SAW+ and SAW/SQR at 220 Hz: power at 220 > power at 110 and at 330 / 2; |y| <= 1.5; no NaN for t, c
     in {0, 0.5, 1} at 30, 220, 2000, 8000 Hz.
   - t 0 vs 1 and c 0 vs 1 change the spectral centroid (first 20 harmonics) by > 5 %.
   - SAW+ at 5 kHz: alias bin (as test_bl_saw_alias_below_naive) below a naive saw by >= 10 dB.
   - `trigger()` then the same render twice → identical buffers.
   → FAIL.
2. Implement: `struct MacroParams { uint8_t model; float hz, timbre, color; }`, `class MacroVoice {
   trigger(); control(const MacroParams&, int n); render(float* out, int n, float amp); }`, t / c ramps
   like `SynVoice`, one `switch` per block to a per-model loop (no per-sample switch), `MT_HOT`.
3. `pio test -e native -f test_synth_macro` → PASS.

### Task 5: MORPH

Same files. Tests first: t 0 → triangle-like (3rd harmonic ≈ 1/9 of the fundamental's amplitude, ±3 dB),
t 0.33 → saw-like (2nd harmonic present), t 0.66 → square (2nd harmonic < -30 dB), t 1 → narrow pulse
(2nd harmonic back); c 1 adds harmonics vs c 0 at 110 Hz; overdrive reduced above ~830 Hz (c 1 at 2 kHz ≈
c 0 within 3 dB centroid). Implement the 3 zones, one-pole LP at `pitch - c` (via `fastExp2`), overdrive
`fastTanh` mix. → PASS.

### Task 6: FOLD

Same files. Tests first: t 0 → pure sine (2nd and 3rd harmonics < -50 dB) at c 0; t 1 → 3rd / 5th
harmonics rise >= 20 dB; c 1 → triangle-fold path (odd harmonics, different centroid from c 0); pitch
limit: at 6 kHz t 1 ≈ t 0. Implement sine fold via `tableSine` and the triangle fold via `synth_shape.h`
(naive, as the original). → PASS.

### Task 7: VOSIM

Tests first: spectral peak (largest bin among harmonics 1..30 of 110 Hz) moves up when t goes 0.2 → 0.8;
c moves the second peak; phase reset per period (output periodic: autocorrelation at the period > 0.9).
Implement main phase, two formant phases reset on wrap, bell window `0.5 - 0.5 cos`, mix 1/2 + 1/4. → PASS.

### Task 8: VOWEL

**Files:** `synth_macro.cpp` (+ the 9 vowel and 8 consonant records, attributed); Test as above.

Tests first: t 0 vs t 1 move F1 / F2 (the strongest bins near the table's formants for the first and last
vowel at c 0.5, ±1 harmonic); c 0 vs 1 shift all formants up (centroid ratio > 1.5); first 150 samples
after `trigger()` contain the consonant noise for the consonants that have it (zero-crossing rate above
the vowel part's); bounded. Implement 3 formant sines reset each period, amplitude `x (1 - phase)`,
formant shift `(200 + 511 c) / 256`, soft clip `fastTanh`. → PASS.

### Task 9: FM and FB FM

Tests first: FM t 0 → sine (2nd harmonic < -60 dB); t 1 at ratio 1 → rich spectrum (harmonics 2..5
present); c steps through quantised ratios (the ratio at c = 0, 0.5, 1 hits the table's values: the
modulator sideband frequencies match); FB FM bounded at t = c = 1 for 30 Hz .. 8 kHz, index attenuated
at high pitch (centroid at 4 kHz t 1 < centroid it would have without attenuation: compare with FM).
Implement 2-op PM with `tableSine`, ratio table, feedback from the previous output. → PASS.

### Task 10: level matching

Tests first: for every model at 220 Hz, t = c = 0.5, RMS within ±3 dB of `SynVoice` saw (mix 0) at the
same amp. → FAIL until each model's gain constant is set. Set the constants. → PASS.
