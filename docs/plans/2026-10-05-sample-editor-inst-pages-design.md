# Редактор сэмплов (зум, чопы) и страницы INST — дизайн

Дата: 2026-10-05

## Цель

1. Экран INST разбит на страницы вместо длинного списка (26–29 строк).
2. Страница SMPL — полноценный редактор сэмпла: большая волна, зум, маркеры
   Start/End/Loop, слайсы (авто и ручные), привязка к транзиентам с Shift.
3. Слайсы играются нотами (NOTE) или командой `SLC` (FX).

## Страницы INST

Шапка 28 px без изменений (стрелки, `INSn name`, PRESET, PREVIEW). Под ней
полоса страниц 24 px (5 равных вкладок), ниже область страницы 220 px
(до 9 строк по 24 px).

| Страница | Содержимое |
|---|---|
| MAIN | Name, Type, Volume, Transpose, Fine, Mode, Glide |
| ENV | Attack, Decay, Sustain, Release + мини-график ADSR |
| тип | CHIP `OSC`: Wave, Duty, PWM rate, PWM depth · SAMPLE `SMPL`: редактор · FM `FM`: Machine + 5 макросов · DRUM `DRUM`: Machine + макросы |
| FILT | Filter, Cutoff, Reso, Flt env, Flt attack, Flt decay, Key track |
| LFO | LFO wave, rate, depth, dest |

Переключение: тап по полосе страниц; энкодер — поворот за последнюю строку
уводит на следующую страницу, перед первой — на предыдущую (сквозной список,
порезанный на экраны, с переходом по кругу). Shift+поворот — смена инструмента
(как сейчас), страница запоминается. Смена типа сохраняет индекс страницы.

## Страница SMPL

- Волна 480×136: Start (зелёный), End (красный), Loop (жёлтый, если Loop≠OFF),
  слайсы — голубые линии с номерами; выбранный маркер ярче/толще.
- Полоса инструментов 24 px: `◀` `▶` (выбор маркера: S, E, L, слайсы по
  порядку), `−` `+` (зум), `CHOP` (авто-чоп по текущим настройкам),
  `CLR` (удалить выбранный слайс; долгое нажатие — все слайсы).
- Список 2–3 видимые строки (скролл): Sample, Root, Start, End, Loop,
  Loop start, Reverse, Slice mode, Chop mode, N / Threshold.

Управление волной:

- Тап — выбрать ближайший маркер. Горизонтальный drag — двигать выбранный
  маркер; с Shift — прилипание к ближайшему транзиенту. При зуме >1 drag по
  пустому месту (далеко от маркеров) скроллит окно.
- Долгий тап по волне — новый слайс в точке (с Shift — в ближайшем транзиенте).
- Энкодер, когда фокус на волне: поворот двигает выбранный маркер на 1 пиксель
  текущего зума; Shift+поворот — к соседнему транзиенту. Фокус волна/список:
  энкодер ходит по строкам списка, «строка» Wave — первая в списке страницы
  SMPL; клик на ней включает режим правки маркера (как edit строки).
- Зум ×1, ×2, ×4 … до 1 сэмпла на пиксель, центр — выбранный маркер.

Кэш волны: min/max по колонкам для окна `[viewStart, viewLen]`, пересчёт при
смене окна, данных или generation() банка.

## Модель

В `Instrument`:

- `sliceMode` — OFF / NOTE / FX
- `chopMode` — EQUAL / TRANS
- `chopN` — 2…32
- `chopThresh` — 0…100
- `sliceCount` — 0…32
- `slices[32]` — `uint16`, доля от всего сэмпла (/0xFFFF), по возрастанию

Слайс i: от `slices[i]` до `slices[i+1]`, последний — до End. При смене
сэмпла слайсы сбрасываются. Авто-чоп работает в пределах Start…End.

## Воспроизведение (`Synth::startSample`)

- OFF: как сейчас.
- NOTE: idx = нота − root; вне 0…count−1 — нота молчит. Родная высота
  (Transpose/Fine применяются).
- FX: `SLC xx` защёлкивается до следующего note-on (как OFS); слайс играет с
  питчем ноты. Без команды или xx ≥ count — весь регион.
- В слайс-режиме Loop игнорируется (one-shot), Reverse — внутри слайса.
- Без слайсов (count = 0) NOTE и FX ведут себя как OFF.

## Транзиенты (`lib/core/src/onset.*`)

- Энергия окнами 256 сэмплов, шаг 128.
- Onset-функция: положительный прирост лог-энергии.
- Пики выше адаптивного порога, минимальный зазор 40 мс.
- Уточнение назад до начала подъёма (точность 32 сэмпла).
- Выход: до 128 онсетов {позиция, сила}. Считается при открытии SMPL / смене
  сэмпла. Snap — к ближайшему онсету; TRANS-чоп — до 32 сильнейших с силой
  выше порога (chopThresh: 0 — только сильные, 100 — все найденные).

## Формат

- Проект: новый чанк `SLCE` — как FMIN/FLTR: count + записи по 72 байта на
  каждый инструмент (`sliceMode, chopMode, chopN, chopThresh, count, 3 резерв,
  32 × u16 позиции`), ~1,2 КБ. Старые прошивки чанк пропускают,
  `kProjectVersion` без изменений.
- Пресет `.mti` v2: после FLTR — блок слайсов (те же поля, count + 32 позиции,
  фиксированный размер), весь под CRC. v1 читается без слайсов.
- `applyPreset`: сэмпл найден — слайсы из пресета; не найден — сэмпл, root и
  слайсы текущего инструмента остаются. Режимы — из пресета всегда.

## Тач

`touch.h`: Drag получает `dx`; ось захватывается по первому смещению
(горизонталь/вертикаль), вертикальный drag в списках работает как прежде.

## Тесты (native)

Онсеты (синтетические щелчки, шум, тишина), равный чоп, roundtrip `SLCE`,
пресет v1/v2, выбор слайса в синте (NOTE/FX, вне диапазона), `SLC` в fx_info.
UI — на железе.
