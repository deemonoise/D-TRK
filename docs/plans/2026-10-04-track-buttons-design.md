# Кнопки дорожек со светодиодами — дизайн

Дата: 2026-10-04. Основа — [future-track-buttons.md](future-track-buttons.md); здесь — что добавлено и уточнено.

## Железо

- PCF8575 на `Wire` (I2C-порт 0; порт 1 занят тачем LovyanGFX): SDA GPIO 43, SCL GPIO 44 (TXD0/RXD0 разъёма Debug; GPIO 1/2/42 оказались заняты встроенным RS485), без INT — опрос каждые 5 мс, 400 кГц, адрес — первый ответивший из 0x20–0x27.
- P00–P07 — кнопки 1–8 на GND, читаются как 0.
- P10–P17 — светодиоды 1–8: 3,3 В → 330 Ом → анод, катод → P1x. Активный низкий: 0 = горит. PCF уверенно тянет вниз (до 25 мА), вверх — только слабая подтяжка, поэтому включение только по катоду. ~4 мА × 8 = 32 мА — в пределах чипа.
- LED 3 мм в штатном окне корпуса свича MX, колпачки прозрачные или с окном. Корпус не меняется.

## Прошивка

### Драйвер `src/hw/trackio.{h,cpp}`

- Задача FreeRTOS — единственный владелец `Wire`. Цикл 5 мс: при флаге INT или каждые 20 мс читает 2 байта; антидребезг 5 мс; на нажатие кладёт `InputEvent{TrackPress, delta = N, shift}` в очередь ввода `src/hw/input.cpp`.
- `hw::trackLeds(uint8_t mask)` (бит = горит) — атомарно; задача пишет порт при изменении: младший байт всегда 0xFF (кнопки остаются входами), старший — `~mask`.
- Нет ответа по I2C при старте — задача не запускается, остальное работает.

### Логика в `lib/core` (native-тесты)

- `scale.h`: `degreeNote(button, root, type, octave)` — кнопка 0..7 → MIDI-нота. Кнопки 1–7 — ступени I–VII, 8 — I + октава; лады короче 7 ступеней продолжаются в следующую октаву; Chromatic → мажор от тоники. Октава 4 = C4 = 60. Клип 0..127.
- `track_leds.h`: `trackLedMask(selected, flash)`. Активность — `Sequencer::takeActivity()` (дорожка в `SchedEvent::track`).

### Поведение

- Вне edit: N — выбрать дорожку N (общий курсор GRID/TRACK); Shift + N — mute дорожки N (на любом экране).
- В edit: N — ступень, Shift + N — ступень октавой выше. Запись в шаг под курсором с undo (как у энкодера), курсор на шаг вниз. Октава: нота под курсором → последняя введённая на этой дорожке → 4.
- OFF — как раньше, через контекстное меню.

### Светодиоды

- Движок на каждом note-on звучащей дорожки ставит бит в атомарной маске активности; UI забирает её (`engine::takeActivity()`) и держит вспышку 50 мс.
- Обычная дорожка: горит во время вспышки.
- Выбранная (курсор): горит постоянно, на вспышке гаснет (инверсия вместо тусклого ШИМ — ШИМ через I2C требует ~1 кГц записей).
- Заглушённая: не вспыхивает; выбранная заглушённая просто горит.
