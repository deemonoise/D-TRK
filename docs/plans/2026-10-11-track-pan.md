# Track Pan Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Stereo output with mono instruments: per-track pan, step fx `PAN` (lock), instrument LFO target `PAN` (autopan).

**Architecture:** See `docs/plans/2026-10-11-track-pan-design.md` (read it first). Voices stay mono; each voice gets control-rate pan gains normalised to 1 at centre, so all-centre projects stay bit-exact. The synth mixes into L/R buses; sends stay mono. Reverb grows a second output allpass (pseudo-stereo), the compressor and DJ filter go stereo-linked. `Synth::renderStereo` feeds the DAC and Render WAV; `Synth::render` stays as the mono downmix (tests, resample).

**Tech Stack:** C++17, PlatformIO. Core in `lib/core/src` (host-testable, Unity tests in `test/test_*`), firmware in `src/` (ESP32-S3, Arduino, LovyanGFX).

**Commands:**
- One native test suite: `pio test -e native -f test_synth` (swap the name).
- All native tests: `pio test -e native`.
- Firmware build: `pio run -e wt32`.

**Rules for every task:**
- Do NOT commit (the user commits everything after testing on the device).

- File-format enums: append before `Count` only.

**Reverb**
- Third allpass `ap2'` of length 464 (`kApRLen = 441 + 23`), its own index. `kBufLen` += 464 (now 6398). The setBuffer layout appends it after the two allpasses.
- `process(const float* in, float* mixL, float* mixR, int n, size, damp, level)`: the comb sum `acc` → ap1 → split: L = ap2(acc1), R = ap2'(acc1) (same g = 0.5 Freeverb form). `mixL[i] += L * wet`, `mixR[i] += R * wet`. Peak for idle = max(|L|, |R|). Idle clear also zeroes the new line / index.
- L is exactly today's output (do not reorder the arithmetic).
- Tests: existing tests updated to the new signature, checking `mixL` against their old expectations (must still pass bit-exact); new: impulse in → L and R both non-zero and differ; level 0 → both buffers untouched; idle after silence covers both.

**Compressor**
- `process(float* l, float* r, const float* scL, const float* scR, int n, amt, rel, scDepth)`: key = `max(fabsf(l[i]), fabsf(r[i]))`, plus `max(|scL|, |scR|) * scW` when sc; one gain on both. With l == r and scL == scR it equals today's math.
- Tests: existing ones updated (pass the same buffer content in l and r, assert both); new: l loud, r silent → r scaled by the same gain as l (equal ratio).

Keep the build green: add the stereo `process` overloads NEXT TO the existing mono ones (the mono ones keep working, `synth.cpp` is not touched); Task 3 switches the synth over and deletes the mono overloads. ### Task 3: Synth engine — pan, buses, stereo render

Depends on Tasks 1 and 2.

**Files:**
- Modify: `lib/core/src/synth.h`, `lib/core/src/synth.cpp`, `lib/core/src/synth_voice.h`
- Modify: `lib/core/src/render.h`, `lib/core/src/render.cpp` (`renderBlockStereo`)
- Test: `test/test_synth`, `test/test_render`

**Voice** (`synth_voice.h`, next to `send` / `rsend`): `float gl = 1, gr = 1;` current gains, `float dgl = 0, dgr = 0;` per-sample steps, `bool panSet = false;` (false = snap on the next control()). Reset `panSet = false` wherever a voice is started (where `lockMask` is set in noteOn, ~synth.cpp:622).

**Gains:** a 128-entry table built once (static, filled on first use or constexpr-free init in the constructor): `θ = π/4 · (1 + (p − 64) / (p < 64 ? 64 : 63))`, `gl = √2·cos θ`, `gr = √2·sin θ`. Then force the exact values: p = 64 → gl = gr = 1.0f; p = 0 → gr = 0; p = 127 → gl = 0. Monotonic, constant power ×√2.

**control()** (after the RVB line ~synth.cpp:834):
```cpp
  const uint8_t pb = (v.lockMask & (1u << kLockPan)) ? v.lock[kLockPan] : trackPan(v.track);
  const uint8_t pan = u7(pb + 64.f * la[ld(LfoDest::Pan)]);
  setPanTarget(v, pan, dt ? dt : ctlLeft_);
```
`trackPan(track)`: `track < kTracks ? p_.tracks[track].pan : 64` clamped (mirror `trackVol`; preview track = centre). `setPanTarget`: if `!v.panSet` → `gl/gr = target`, steps 0, `panSet = true`; else steps = (target − current) / len (len ≥ 1). The ramp must end exactly on target at the next control update: in the mixing loop clamp by recomputing from steps only, and in setPanTarget always start from the current gl/gr.

**fx():** add `case Fx::PAN:` to the lock group (~synth.cpp:316) with `cmd == Fx::PAN ? kLockPan` in the k chain. PAN is not a macro.

**Buses** (`synth.h`): `mix_[kBlock]` → `mixL_[kBlock], mixR_[kBlock]`; `sc_` → `scL_, scR_`; `send_`, `rsend_` unchanged; add a second DJ filter state (`dj2_` or an array). 

**render core:** rename the body of `render()` into a private `renderCore()` that fills `mixL_ / mixR_` up to the DJ filter and master gain + softClip as floats in place (or into two float arrays), then:
```cpp
void Synth::renderStereo(int16_t* lr);  // lr[2*kBlock], interleaved
void Synth::render(int16_t* out);       // mono: (L + R) >> 1 of the int16 channels
```
Mono must be computed from the two converted int16 values: `out[i] = static_cast<int16_t>((static_cast<int>(l) + r) >> 1)`, so centre-pan output is bit-exact to today. Note `>> 1` on a negative odd sum rounds down: equal L and R never hit that.

**Mixing loop:** every voice goes through `tmp` (drop the direct `renderVoice(v, mix_ + pos, n)` path but keep its `v.on = false` logic). Per sample: `x = tmp[i]`; `gl += dgl; gr += dgr` (or apply then step: be consistent so the segment ends on target); `dryL += x*gl; dryR += x*gr`; sends `send_ += x*vs; rsend_ += x*vr` (mono, pre-pan, as today); sidechain key track: into `scL_/scR_` with the same gains (keyAround) or additionally (not keyAround), as today; peak from `fabsf(x)`. At centre `x*1.f == x`, so the mix is bit-exact.

**Master chain:** `delay_.process(send_, mixL_, …)` then copy the return into R as well: change `Delay::process` to take `mixL, mixR` and add the same return to both (update `test_synth_delay` call sites, asserting both). Reverb → `reverb_.process(rsend_, mixL_, mixR_, …)`. Compressor → `comp_.process(mixL_, mixR_, sc?scL_:nullptr, sc?scR_:nullptr, …)`. keyAround adds `scL_/scR_` back. `djFilter` on both channels with separate states. Master gain + softClip per channel.

**Profiling marks / takeTrackPeaks:** unchanged semantics.

**OfflineRender:** add `bool renderBlockStereo(int16_t out[2 * Synth::kBlock])` sharing the sequencing code with `renderBlock` (factor a private `step()`); peak / clips over all samples written.

**Tests (test_synth):**
- Centre: a project with drum + synth voices, delay and reverb off → `renderStereo` L == R sample by sample, and equal to `render()` of an identical second synth.
- `tracks[t].pan = 0` → R channel all zero, L non-zero; pan = 127 → L zero.
- `Fx::PAN` lock 0 on a note step of a centre track → R silent for that note.
- LFO dest PAN, square wave, full depth, fast rate → L and R energies alternate over blocks.
- Ramp: change pan from 0 to 127 between blocks on a sustained voice → the per-sample |ΔR gain| bounded (no jump bigger than one control segment step); simplest: the max sample-to-sample difference of R stays well below the jump a hard switch produces.
- Reverb on, centre → L ≠ R (pseudo-stereo) and `render()` still runs.
- Existing tests in all suites must pass unchanged, except reverb-dependent ones whose mono downmix now averages a different R; if any fail for that reason only, update the expectation with a comment.

**test_render:** `renderBlockStereo` yields 2·kBlock samples per call, block count equal to `renderBlock`'s; centre project → L == R.

Run `pio test -e native` → all PASS.
