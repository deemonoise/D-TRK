# Синт-плата Teensy 4.1 — дизайн

Ветка `feature/teensy`. Заменяет черновик [future-teensy.md](future-teensy.md) (писался до перехода на PCM5102A) в части решений; отметка про стриминг остаётся там.

## Цель

Перенести весь звук и все файлы с ESP32-S3 на Teensy 4.1 и сразу поднять движок:

- стерео + панорама дорожек, стерео delay / reverb;
- 44,1 кГц вместо 32 кГц;
- пул 32 голоса, тяжёлых (FM / DRUM / WT) стартово 16 (итог — по бенчу);
- сэмплы в банке во flash Teensy (≈5,8 МБ), SD у Teensy — единственная карта.

ESP остаётся секвенсором, UI, MIDI OUT и Wi-Fi-прошивальщиком. ESP-сборка «без Teensy» не поддерживается (старый вариант — в `main`).

Вне рамок v1: аудиовход (у PCM5102A его нет), PSRAM, стриминг длинных сэмплов (**обязательно позже**, см. [future-teensy.md](future-teensy.md#обязательно-позже-стриминг-длинных-сэмплов-с-sd)), компенсация задержки INT относительно MIDI.

## Решения

| Вопрос | Решение |
|---|---|
| ЦАП | имеющийся PCM5102A + MAX97220 переезжают на Teensy (I2S1) |
| Сэмплы | банк во flash Teensy (кэш), без PSRAM |
| Линк | прямой UART 3,3 В на освободившихся GPIO 13/14 ESP, полный дуплекс, 3 Мбод |
| Карты | одна, у Teensy; ESP ходит к файлам через линк |
| Wi-Fi | только прошивка (ESP `.bin`, Teensy `.hex`); файловый менеджер убирается |
| Архитектура | Teensy = звуковой сервер + файл-сервер; состояние — диф-зеркало |

Отклонено: RS485 (лишний модуль, полудуплекс), Teensy владеет проектом и секвенсором (не влезает в RAM без PSRAM), явные сообщения на каждый параметр (рассинхрон, много протокола), стриминг с SD в v1 (риск щелчков, много нового кода), сборка ESP-only (двойная поддержка).

## 1. Железо и разводка

```
WT32-SC01 Plus (Extended IO)        Teensy 4.1
  GPIO 13 (UART TX) ───────────────── 0  (RX1)
  GPIO 14 (UART RX) ───────────────── 1  (TX1)
  GPIO 21           ───────────────── 2  (запас, в v1 не используется)
  5V (выход IP5306) ───────────────── VIN
  GND               ───────────────── GND

PCM5102A                            Teensy 4.1
  BCK  ──────────────────────────────  21 (BCLK1)
  LRCK ──────────────────────────────  20 (LRCLK1)
  DIN  ──────────────────────────────  7  (OUT1A)
  VIN  ──────────────────────────────  3V3 Teensy (или 5 В)
  SCK, FMT, FLT, DEMP ── GND;  XSMT ── 3V3
MAX97220 — без изменений, за ЦАП.
```

- Оба 3,3 В, согласование уровней не нужно; пины Teensy не 5 В-толерантны.
- UART 3 Мбод базово (≈300 КБ/с полезных); на стенде проверить 4–5 Мбод. Скорость — константа в обеих прошивках.
- Перемычку VUSB–VIN на обороте Teensy разрезать (USB компа и IP5306 не должны питать друг друга).
- USB Teensy остаётся внутри корпуса: первая прошивка — до сборки, восстановление — со вскрытием. Поэтому OTA Teensy проверяет образ до копирования.
- Корпус: Teensy на бортиках дна рядом с ЦАП / усилителем, **прорезь к слоту microSD Teensy** (короткий торец, напротив USB) — карта меняется без разборки. Прорезь карты ESP закрыть.
- На ESP освобождается SPI карты (GPIO 38–41) — резерв.

## 2. Линк и протокол

**Кадр.** COBS, разделитель `0x00`. Внутри: `[type][seq][payload ≤ 512][crc16]`. Код — `lib/core/src/link_frame.*`, общий для обеих прошивок.

**Классы трафика.**
- RT (события, время): без подтверждения, потеря — счётчик. На ESP RT-очередь уходит раньше bulk; худшее ожидание — один bulk-кадр 512 Б ≈ 1,7 мс.
- Запрос / ответ (файлы, банк, состояние): `seq` + таймаут + повтор, 1–2 запроса в полёте — естественный backpressure.

**Сообщения.**

| Тип | Направление | Назначение |
|---|---|---|
| `Hello` | ↔ | версии протокола и прошивки, boot-id |
| `Time` | ESP→T, ~50 мс | часы ESP для смещения |
| `Ev` | ESP→T | метка времени + дорожка + 1–3 байта; несколько в кадре |
| `StateSet` / `Ack` | ESP→T | кусок `SynthModel` |
| `Open/Read/Write/Close/Stat/List/Remove/Rename/Mkdir` | ESP→T | удалённая ФС |
| `BankSync`, `AssetsSave`, `BankImport`, `SampleInfo`, `BankClear` | ESP→T | банк |
| `WavePeaks`, `Onsets` | ESP→T | редактор сэмплов |
| `PreviewNote`, `PreviewSlice`, `PreviewFile`, `PreviewStop` | ESP→T | прослушивание |
| `RenderStart` / `RenderBlocks` / `RenderEnd` | ESP→T | рендер WAV |
| `Meters`, `Phones`, `Profile` | ESP→T | настройки вывода и диагностики |
| `Status` | T→ESP, ~25 Гц | CPU, срывы, голоса, late, пики 16 дорожек, пик выхода; скоп 512 — только при включённых метрах |
| `Progress` | T→ESP | ход `BankSync` / импорта / рендера / прошивки |
| `FwFromFile` | ESP→T | OTA Teensy |
| `Log` | T→ESP | строка в Serial ESP |

**Задачи.** ESP — FreeRTOS-задача линка владеет UART (RX-парсер, TX с приоритетом RT); `post` неблокирующий (engine), запросы — блокирующие с таймаутом (UI). Teensy — разбор в `loop()`, звук в прерывании Audio Library, события в аудио-код через lock-free очередь.

## 3. Время и состояние

**Время.** Секвенсор по-прежнему зовёт `audio::post(t, …)` с `engine::nowUs()`.
- Teensy по каждому `Time(tEsp)` берёт `tПриёма − tEsp` по своим `micros()`; смещение = минимум за скользящее окно ~2 с (минимум отсекает очередь, окно следит за дрейфом). Код — `lib/core/src/time_sync.*`.
- Событие играет в `tEsp + смещение + L`, `L ≈ 4 мс`. Аудио-прерывание помнит `micros()` начала блока; событие встаёт в блок со смещением до сэмпла. Опоздавшее — в начало текущего блока, счётчик `late`.
- Задержка INT ≈ L + 2 блока ≈ 10 мс (было ~14), джиттер ≈ 0.

**Состояние.** `lib/core/src/synth_model.*`: `struct SynthModel` — всё, что `Synth` читает из `Project`: `bpm`, `scaleRoot`, `scaleType`, `TrackCfg[kTracks]`, `Instrument[kInstruments]`, `masterVol`, `dly*`, `rvb*`, `comp*`, `sc*`, `djFilter`, списки сэмплов и таблиц проекта. `Synth` переходит на `const SynthModel&`; `toSynthModel(const Project&, SynthModel&)` — на ESP и в тестах.
- ESP каждый кадр UI собирает модель и сравнивает с теневой копией по кускам: инструмент N, дорожки, мастер, список сэмплов, список таблиц. Изменённый кусок → `StateSet` → по `Ack` обновляется тень. Любой путь правки (энкодер, пресет, undo, Shift-отмена, загрузка) синхронизируется сам; p-lock'и идут событиями, как сейчас.
- Teensy применяет `StateSet` в `loop()` под коротким запретом аудио-прерывания.
- Барьер: после загрузки проекта и после нового boot-id Teensy Play ждёт подтверждения всех кусков и конца `BankSync`; на экране прогресс.

## 4. Карта, удалённая ФС, банк

**Карта Teensy.** SdFat (SDIO 4-бит), FAT32 и exFAT, длинные UTF-8 имена. Папки прежние: `/projects`, `/midi`, `/samples`, `/wavetables`, `/presets/<TYPE>`, рендеры, плюс `/firmware`. Переезд — скопировать содержимое старой карты ESP.

**Удалённая ФС на ESP.** `src/storage/remote_fs.*`: `RemoteFSImpl` / `RemoteFileImpl` под Arduino `fs::FS`; `hw::sdFs()` отдаёт её, `storage`, `presets`, `render_io`, `sdList*`, `sdNextEntry` не переписываются. Упреждающее чтение и буфер записи по 4 КБ, листинг постранично. Проект 466 КБ ≈ 1,6 с. SPI-драйвер карты ESP удаляется.

**Банк во flash Teensy.** Логика `sample_bank` (`lib/core`) — без изменений: кэш, имена = hex CRC32, вытеснение, ключи таблиц `w`+crc. Бэкенд записи — flash Teensy (подпрограммы FlasherX). Разметка 8 МБ: прошивка ≤ 1 МБ | буфер OTA 1 МБ | банк ≈ 5,8 МБ | служебные секторы Teensy (EEPROM-эмуляция, restore) в конце; точные границы — в плане. Запись во flash останавливает чтение → аудио на паузе на время записи. Встроенные `*NAME` таблицы генерируются в банк при первом старте.

**Локально на Teensy.**
- `BankSync(список)` — при загрузке проекта: ищет `/projects/NAME/*.wav` и `/projects/NAME/wt/`, подтягивает недостающее в банк.
- `AssetsSave(NAME)` — при сохранении: пишет WAV / таблицы проекта из банка в папку проекта.
- `BankImport(путь)` — импорт WAV / таблицы через `wav.cpp`; ответ: имя, CRC, кадры, rate.
- `WavePeaks(сэмпл, от, до, колонок)` — min/max на колонку; `Onsets(сэмпл, …)` — точки авто-чопа (`onset.cpp`).
- `PreviewFile(путь)` — WAV из списка импорта стримом с SD одним голосом через кольцевой буфер ~16 КБ (прототип будущего стриминга).

Миграция `legacy.idx` убирается (индекс относился к flash ESP). Проекты без списка сэмплов грузятся с пометкой «сэмпл не найден».

## 5. Движок

- **44,1 кГц**: константа частоты синта = 44100; блок 128 (= `AUDIO_BLOCK_SAMPLES`), контрольный шаг 32. Тесты с числами от 32 кГц обновляются.
- **Стерео**: `Synth::render(int16_t* l, int16_t* r)`. Панорама на дорожке — `TrackCfg::pan` (−64…+63, 0 = центр), равномощный закон, строка в TRACK и MIX; чанк дорожек читается по размеру, старые проекты — центр. Delay — две линии L / R с общими параметрами; reverb — стерео-Freeverb; компрессор, sidechain, DJ-фильтр, мастер — стерео со связанным управлением. Скоп — моно-сумма, метры дорожек как сейчас. Рендер WAV — стерео 16 бит 44,1 кГц.
- **Голоса**: пул 32, тяжёлых 16, защита нагрузки остаётся; итог — по бенчу `teensy41-bench`. `MT_HOT` = `FASTRUN`.
- **RAM** (1 МБ): OCRAM — delay 2 × 2 с int16 ≈ 353 КБ, буфер превью, буферы линка / ФС; DTCM — `Synth`, reverb ≈ 47 КБ, `SynthModel`, очереди. Запас ≥ 64 КБ; не влезает — delay короче.
- **Teensy Audio Library**: только `AudioOutputI2S` + свой `AudioStream` с двумя выходами.

## 6. UI, OTA, раскладка кода

**UI на ESP.** `audio.h` сохраняется, реализация — клиент линка: `post` / `preview*` → сообщения; `takeLoad`, `scope*`, `trackPeaks` ← из `Status`; `setMeters`, `setPhones`, профиль → команды. `Paused`, `liveSynth`, `samplesBase`, `pauseForFlash` удаляются, вызовы переходят на команды Teensy. Редактор сэмплов: волна из `WavePeaks` с кэшем на зум, авто-чоп — `Onsets`.

**Состояния синт-платы.**
- Старт: «Synth: connecting…» до `Hello`.
- Нет ответа 3 с или пропал `Status` > 1 с — `NO SYNTH` в статусбаре; FILE и всё про карту недоступны; секвенсор с пустым проектом и MIDI OUT работают; переподключение в фоне.
- Версия протокола не совпала — экран «обновите прошивку синт-платы» + Wi-Fi.
- PROJ → SYS: версия Teensy, счётчики линка, карта, CPU-профиль Teensy, «Update synth from card».

**Wi-Fi.** Только `/firmware`: `.bin` ESP (как сейчас) и `.hex` Teensy. Файловые API и страницы удаляются.

**OTA Teensy.** `.hex` → ESP пишет на карту Teensy `/firmware/teensy.hex` → `FwFromFile` → FlasherX пишет в буфер OTA, проверяет CRC и границы, только потом копирует и перезагружается → ESP ждёт `Hello` с новой версией. Без Wi-Fi — файл на карту + «Update synth from card».

**Раскладка.**
- `platformio.ini`: env `teensy41` (`build_src_filter = +<teensy/>`), `teensy41-bench`; у `wt32*` — `-<teensy/>`.
- `lib/core` (оба): `link_frame`, `link_msg`, `synth_model`, `time_sync`.
- ESP: + `src/link/` (UART-задача, клиент, `audio::` поверх линка), `src/storage/remote_fs`; − `src/audio`, SPI-карта в `hw/sdcard`, файловый менеджер в `net/web`, раздел `samples` в `partitions.csv` (разовая прошивка по USB).
- Teensy (`src/teensy/`): `main`, сервер линка, `audio_out`, бэкенд банка, ФС-сервер, стрим превью, обновление; FlasherX — `lib/flasherx` с лицензией.

## 7. Ошибки и тесты

**Ошибки.**
- CRC — выброс кадра, счётчик. Запросы — 3 повтора (200 мс, SD-операции 2 с), потом ошибка наверх как у SD сейчас. RT не повторяются.
- Новый boot-id Teensy — ESP переотправляет состояние и `BankSync`, транспорт не останавливается.
- Карта вынута — ответы с кодом ошибки; банк продолжает играть.
- Срывы аудио / опоздания — `stalls` / `late` в `Status`, CPU красный.

**Тесты.**
- Нативные: COBS / кадр / CRC (порча, обрыв, ресинк); кодек каждого сообщения; `time_sync` (джиттер, дрейф, выбросы); диф `SynthModel`; `Synth` на `SynthModel`; стерео / панорама; 44,1 кГц; чтение старого чанка дорожек.
- Петля без железа: клиент ↔ сервер через виртуальный канал (ФС на временной папке, `StateSet`, барьер).
- Железо: эхо UART 3 / 4 / 5 Мбод; бенч голосов; SYNTEST / DRMTEST на слух и по CPU; OTA Teensy с карты и по Wi-Fi.

## Порядок работ

1. Железо на макетке, env `teensy41`, синус на выходе; UART-эхо.
2. Линк: кадр, `Hello`, `Time`, `Ev` → Teensy играет `lib/core` по нотам ESP.
3. `SynthModel` + диф-синхронизация; удаление `src/audio`.
4. Удалённая ФС + SdFat; проекты, пресеты, импорт MIDI; удаление SPI-карты ESP и Wi-Fi-файлов.
5. Банк во flash Teensy, `BankSync` / `AssetsSave` / `BankImport`, превью, `WavePeaks` / `Onsets`.
6. 44,1 кГц, стерео, панорама, стерео delay / reverb, пул 32 + бенч.
7. Рендер WAV через Teensy.
8. OTA Teensy.
9. Корпус, `docs/wiring*`, руководство, README.
10. Позже, отдельно: стриминг длинных сэмплов (обязательно), PSRAM.
