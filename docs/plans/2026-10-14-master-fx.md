# Master / send effects — implementation plan

Design: `2026-10-14-master-fx-design.md` (decisions: recommended options, except shimmer interval
selectable +12 / +7 / +24, PERF MOD THROW / TAPE WOBBLE in this feature, MOD bus first).

Rule for every step: DSP header + native test first (no Synth change), then integration, then a
device check on `wt32-fxbench`. Commit after the device test (project rule).

## Phase A — standalone DSP blocks (done, this pass)

Hardware-free headers in `lib/core/src`, each with its own native test dir. No `Synth`, model,
file or UI change.

- [x] A0 `synth_fxutil.h`: shared helpers — `fxSin` (LFO sine, parabolic, < 0.1 % error),
      `FxLfo` (phase accumulator, rate 0..127 -> 0.05..8 Hz exp), `fracRead` (linear interpolated
      int16 line read), `toLine` (float -> int16 with saturation), `softSat`, `OnePoleTpt`.
- [x] A1 `synth_modfx.h/.cpp` — `ModFx` (MOD bus): CHORUS / ENSEMBLE / FLANGER / PHASER on one
      internal int16 line (1024 samples, 2 KB, member array). Mono in -> stereo return added to the
      mix. OFF / level 0 / idle: mix untouched (bit-exact). Level ramps per block, depth / fb
      smoothed per 32-sample segment, type change fades the old type out (64 samples), clears, fades
      the new one in. Test: `test/test_synth_modfx`.
- [x] A2 `synth_eq.h/.cpp` — `MasterEq`: TPT one-pole low shelf 120 Hz + high shelf 5 kHz, +-12 dB,
      64 / 64 = skipped (bit-exact), gains ramp per block. Test: `test/test_synth_eq`.
- [x] A3 `synth_shimmer.h/.cpp` — `PitchShift` (two-tap crossfaded delay-line shifter, +12 / +7 /
      +24, caller-owned int16 buffer of 2048 samples = 4 KB, ~6 kHz LP) and `Shimmer` (the feedback
      helper: reverb input = send + softSat(HP200(shift(previous wet)) x g), g = amount x
      2 sqrt(1 - fb^2) (max 0.5) from the reverb size, muted on FREEZE). The HP is required: DC is not
      shifted and the combs' DC gain (1 / (1 - fb) ~ 50 at size 127) made the loop ring up; with it
      the tail dies out at every size (tested to 10 s).
      Test: `test/test_synth_shimmer`.
- [x] A4 `synth_delay.h/.cpp` — `Delay` gains `DelayMode` (DIGITAL / TAPE / PING-PONG) through a new
      `process(..., mode, chr)` overload; the old `process` is DIGITAL and unchanged (bit-exact,
      old tests pass). TAPE: fractional read, wow + flutter, time glide (slew-limited), feedback HP +
      saturation, Wear smoothed (~100 ms), Wear 0 + settled = DIGITAL path; TAPE -> DIGITAL runs the
      tape loop with Wear 0 until settled (no jump). PING-PONG: two half lines, width. Switching into /
      out of PING-PONG fades the return out and wipes the line in chunks (delay mute ~0.25 s).
      Test: `test/test_synth_delay` (extended).

## Phase B — integration (done; device check pending)

- [x] B1 Model: `Project` fields at the end (`dlyMode, dlyChar, rvbMode, rvbShim, modType, modRate,
      modDepth, modFb, modLevel, eqLow, eqHigh`, plus `shimInt` for the +12 / +7 / +24 choice —
      AUDI byte order to be fixed once, appended after `eqHigh`), `TrackCfg::modSend`. Teensy mirror.
- [x] B2 File: AUDI 14 -> 26 bytes (`kAudiMfxSize`), TINS +1 byte (`modSend`), round-trip tests.
- [x] B3 Synth: `msend_` in `runStrip`; `ModFx` (member, 2.2 KB internal) return before the delay;
      `Delay::process(..., mode, chr)`; shimmer around `Reverb::process` (`Shimmer::process(rsend_,
      prevWet, rvbIn, n, rvbShim, rvbSize, freeze)` -> reverb; the reverb wet must be captured
      without the return level (Reverb writes wet x level into the mix: render into zeroed temps and
      divide, or add a wet-out pointer to Reverb), keep last block's L as prevWet; the reverb idle test
      then sees the shimmer input by itself); `MasterEq` after comp + key track, before
      PERF. Buffer: shimmer 4 KB with the reverb buffer (internal if 24 KB free, else PSRAM; Wi-Fi
      move). Bit-exact default render test.
- [x] B4 Locks / LFO: Fx `MOD`, `kLockMod` = 13, LfoDest `ModSend`; fx_info `MOD "MOD SEND"`.
- [x] B5 PERF: `MOD THROW` (all tracks to the MOD bus while held), `TAPE WOBBLE` (Wear -> 127 while
      held, delay forced to TAPE).
- [x] B6 UI: PROJ pages SONG / DLY / RVB / MOD / MSTR / PERF; TRACK `Mod send` row; PageBar fit.
- [x] B7 Bench (`wt32-fxbench`: TAPE, SHIMMER, ENSEMBLE / PHASER, EQ), profiler stages `kProfMod`,
      `kProfShim`, `kProfEq`; manual ru (en lags for features 1-5, separate pass); one demo (DEMO-HOUSE:
      TAPE delay, ENSEMBLE on the MOD bus, PERF MOD THROW). Integration test: `test/test_synth_mfx`
      (incl. default render bit-exact). Cycle figures on the device are still to be measured.
