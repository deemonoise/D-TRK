# Стриминг сэмплов с SD — дизайн

Ветка `feature/teensy`. Закрывает пункт «обязательно позже: стриминг длинных сэмплов» из [future-teensy.md](future-teensy.md#сделано-стриминг-сэмплов-с-sd) и меняет решение «сэмплы в банке во flash» из [2026-10-09-teensy-synth-design.md](2026-10-09-teensy-synth-design.md).

## Цель

Все сэмплы играются стримом с SD Teensy, как у Dirtywave M8: нет лимита банка (≈5,8 МБ), нет записи сэмплов во flash (паузы звука при `BankSync`, износ). PSRAM (8 МБ, один чип на CS1) — необязательное ускорение: всё работает, если её нет или она отвалилась на ходу.

## Решения

| Вопрос | Решение |
|---|---|
| Сэмпл-голоса | до 16 одновременно (константа), стримом; голоса из PSRAM в лимит не входят |
| Формат | моно int16, исходная частота; импорт конвертирует |
| Источник истины | `/projects/NAME/<имя>.wav` на SD |
| Flash Teensy | wavetable-таблицы + «головы» сэмплов (ключ — CRC) |
| PSRAM | «головы» не нужны (flash отображён), целые сэмплы проекта от коротких к длинным |
| PSRAM отвалилась | тест при старте + сторож на ходу; при сбое — переход на flash + SD до перезагрузки |
| Недогрузка | глушим только этот голос (фейд 2 мс), счётчик, значок на ESP; транспорт не останавливается |
| Подкачка | кооперативно в `loop()` (вариант A) |
| Буфер PERF | в PSRAM CS1 (6 с стерео ≈1 МБ, участок до кэша сэмплов); нет PSRAM или сторож поймал сбой — PERF молчит |

Отклонено: асинхронный DMA-ридер SDIO (свой драйвер поверх FAT, риск; возможный переход позже без изменения голоса), подкачка из IntervalTimer (общая карта с ФС-сервером — блокировки), стоп транспорта при перегрузке (рвёт живое исполнение), стерео-сэмплы (отдельная фича), «головы» в RAM (не влезают), без «голов» (старт ноты зависит от латентности карты).

## 1. Данные

**SD.** `/projects/NAME/<имя>.wav`, моно, 16 бит, исходная частота. `BankImport` конвертирует (`wav.cpp`) и пишет сразу в папку проекта. Файл не в каноническом формате (8 / 24 бит, float, стерео), положенный вручную, при загрузке проекта конвертируется в фоне рядом с исходником. `BankSync` / `AssetsSave` остаются только для таблиц.

**Flash Teensy (≈6 МБ банка).** Логика `sample_bank` прежняя (таблица, CRC32-имена, вытеснение), содержимое меняется:

- wavetable-таблицы — как сейчас;
- «головы» сэмпла: начало (100 мс ≈ 8,8 КБ при 44,1 кГц), loopStart (100 мс), каждая точка слайса (25 мс, до 32 → ≈70 КБ на нарезанный сэмпл). Ключ — CRC сэмпла; общие для проектов, переживают перезагрузку.
- Пишутся при импорте и при загрузке проекта (нет «головы» или изменились loopStart / слайсы); на время записи звук коротко глушится (`park`), как сейчас.

**PSRAM (если жива).** После загрузки проекта в фоне копируются целые сэмплы проекта по возрастанию длины, пока хватает 8 МБ (минус зарезервированный участок сторожа). Сэмпл доступен голосам только после полной копии и проверки CRC. Начало арены до кэша занимает буфер PERF (6 с стерео), поэтому PSRAM инициализируется до `allocPerf` и `link::begin` (`Hello.perfSec`).

**RAM2.** Пул из 16 слотов по 6 КБ (6 блоков × 512 кадров) = 96 КБ. Превью (`PreviewFile`) перестаёт держать своё кольцо 16 КБ и берёт слот пула. Delay — 2 с моно. Буфер PERF (из main, 2026-10-13) в RAM2 не берётся: с пулом ему не хватает места, он живёт в PSRAM.

**Миграция.** Старый проект, чьи сэмплы есть только в банке: при первой загрузке после обновления сэмплы выгружаются из банка в папку проекта (через тот же путь, что `AssetsSave`), затем банк чистится от сэмплов.

## 2. Голос

**Блочный кэш.** Слот = 6 блоков по 512 кадров, каждый помечен номером блока файла. Аудио-прерывание по `pos` находит блок и интерполирует (линейно, как сейчас); карту не трогает. Подкачка в `loop()` по `dir` грузит 1–2 блока впереди, вытесняя самый дальний позади. Одним механизмом: forward, reverse (впереди = назад по файлу), ping-pong (на развороте сыгранные блоки ещё в кэше), петля (прыжок на loopStart попадает в «голову» петли, кэш догружает продолжение).

**Источники кадра по порядку:** PSRAM (весь сэмпл) → «голова» во flash → блок кэша. Нет нигде — недогрузка: фейд 2 мс в тишину, счётчик; данные появились — фейд обратно.

**Старт с произвольной точки.** Начало, loopStart, слайсы — из «голов». Остальное (параметр start) — упреждение: ESP за шаг до события (≈100 мс при 120 BPM) шлёт подсказку `{0xF4, note, ofs}` в `EvBatch` (`0xF6` занят PERF); голос заранее занимает слот и начинает подкачку. Живая игра с произвольным start — только упреждение линка (4 мс), худший случай — начало ноты с фейдом.

**Лимит.** SAMPLE без PSRAM занимает слот; слотов нет — крадётся самый старый сэмпл-голос (как обычная кража, фейд `kStealMs`).

**Приоритет подкачки** — по запасу времени (кадры в кэше впереди / шаг), не по числу блоков: голос на октаву выше читает вдвое быстрее.

## 3. Планировщик, PSRAM, ошибки

**`loop()`.** Каждый проход: подкачка голосов — до 4 блоков (≤ 4 КБ чтения каждый) по возрастанию запаса. Если у всех запас > ~30 мс — одна порция одной фоновой задаче (сервер ФС, импорт, конвертация, наполнение PSRAM, запись «голов»). Задачи, читающие / пишущие карту большими кусками, дробятся. Рендер (офлайн) и стирание flash — с выключенным звуком, как сейчас.

**PSRAM.** При старте — своя инициализация CS1 (загрузчик Teensy ищет второй чип только при живом первом), тест: адресные линии + 64 КБ паттернов; не прошёл — `psram off` в логе, работа без неё. Сторож: раз в ≈100 мс пишет / читает контрольные слова в зарезервированном участке; сбой — флаг `psram ok` снят, голоса со следующего блока идут на flash + SD (играющая из PSRAM нота может уйти в фейд), буфер PERF отцепляется — PERF молчит. Вернуть — только перезагрузкой.

**Ошибки.**

- Карта вынута — голоса доигрывают из «голов» / PSRAM, остальные в фейд; линк жив, автомонтирование при возврате (есть).
- Файла нет — голос молчит, на ESP «не найден» (есть).
- «Голова» битая / CRC не совпал — перезапись в фоне, до неё — SD с упреждением.

**Видимость.** `Status` += занятые сэмпл-голоса, недогрузки / с, минимальный запас (мс), PSRAM вкл / выкл и заполнение. ESP: значок перегрузки; FILE → SYSTEM — строка «Samples: SD / PSRAM, underruns». `kProtocol` 2 → 3.

## 4. Проверка

**Native (`lib/core`).**

- Блочный кэш на искусственном источнике с задаваемой тестом задержкой: forward / reverse / ping-pong / петля / слайсы / произвольный start — бит-в-бит с нынешним воспроизведением из RAM, когда источник успевает.
- Недогрузка: фейд и возврат, счётчик, нет скачков выше порога.
- Планировщик: меньший запас — раньше; фоновые задачи не получают порцию при голодных голосах.
- Источники PSRAM → голова → кэш; при снятом `psram ok` нет чтений PSRAM.
- Миграция банка в папку проекта; конвертация WAV (8 / 24 / float / стерео → канон).

**Desk (`link_desk.py`).** Бенч стрима: 16 длинных разных сэмплов на исходной высоте и октаву выше — минимальный запас, недогрузки, CPU; карты Kingston и SmartBuy. Рендер со стримом = рендер из RAM. Вынимание карты. Сторож PSRAM (сбой имитируется командой). Замер RAM2 (пул 96 КБ при delay 2 с, PERF в PSRAM).

**С ESP.** `Prefetch` от секвенсора, нарезанные лупы на быстром темпе, значок перегрузки.

**Готово, когда:** 16 голосов на исходной высоте на Kingston — 0 недогрузок за 10 минут; октава выше — недогрузки допустимы только на SmartBuy, без зависаний.
