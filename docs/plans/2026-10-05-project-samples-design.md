# Сэмплы как часть проекта

## Задача

Сейчас флеш-банк — общий пул устройства: при загрузке любого проекта видны все когда-либо
импортированные сэмплы, а проект на SD не самодостаточен. Нужно: проект владеет своими сэмплами,
его можно перенести (SD / Wi-Fi) на другое устройство, и сэмплы подтянутся сами.

## Модель

- Флеш-банк — анонимный кэш по содержимому. Имя записи банка = CRC32 данных (int16 после
  конвертации), 8 hex-символов в существующем `name[16]`. Формат таблицы не меняется (v1, 128
  слотов). Одинаковые данные в разных проектах — одна запись; одноимённые разные сэмплы разных
  проектов не конфликтуют.
- `Project::samples[128]`: `{name[17], crc, frames}` + счётчик. `name` — видимое имя, на него
  ссылается `Instrument.sample`; уникально без учёта регистра в пределах проекта.
- `.mtp`: новый chunk `SMPL`. Файл без него читается (миграция ниже).
- Резолв: `SampleSource::find(name)` → элемент `live.samples` → `bank.find(hex crc)`, frames
  сверяются (см. «Конкурентность»).
- SD: `/projects/NAME.mtp` + `/projects/NAME/<sample>.wav` — mono, 16 bit, частота банка (на
  устройстве заливается без даунсемплинга). В WAV свой chunk `mtcr` с CRC данных; без него (файл с
  ПК) CRC считается по содержимому.
- `/samples/` остаётся библиотекой для импорта.

## Потоки

**Импорт WAV** (FILE → SAMPLES → Import): конвертация в банк как сейчас, CRC на лету. Если запись
с таким CRC уже есть — новая удаляется, берётся существующая. Запись переименовывается в hex CRC,
в `live.samples` добавляется элемент. SD не трогается — всё пишет save (работает и для нового
проекта без имени).

**Нехватка места** (импорт и загрузка): удалять записи банка, которых нет в `live.samples`, от
больших к меньшим, пока не влезет; если мешает фрагментация — `compact()`; иначе `BANK FULL`.

**Сохранение** (`storage::save`): `.mtp` как сейчас (tmp → проверка → .bak), затем синхронизация
`/projects/NAME/`: для каждого сэмпла списка без файла или с файлом другого CRC — записать WAV из
флеша (`data()`, mmap); файлы не из списка — удалить. Save as в новое имя пишет папку целиком.
Сэмпл missing (нет в банке) файл не перезаписывает и не удаляет.

**Загрузка** (`storage::load`, autoload): прочитать `.mtp`, остановить движок; для каждого сэмпла
— есть запись `crc` в банке → готово, иначе импорт из `/projects/NAME/<name>.wav` (с проверкой CRC).
Прогресс-бар: файл, байты. Нет файла / битый / CRC не совпал → missing (тишина), в конце тост
`N SAMPLES MISSING`; элемент остаётся в списке.

**Удаление сэмпла** — из списка проекта; банк не трогается, файл удалит следующий save.

**Rename** — только в проекте (+ ссылки инструментов), флеш не трогается.

## UI

- FILE → SAMPLES: список `live.samples` (имя, длина, метка `MISSING`); Import, Rename, Delete;
  строка `BANK: X KB free / cache Y`; Compact; `Clear cache` — удалить из банка всё, что не в
  текущем проекте.
- INST: выбор сэмпла только из `live.samples`.
- Импорт / rename / delete ставят dirty.

## Wi-Fi

Разрешены пути `/projects/<name>/<file>.wav` (upload / download / delete); на странице папка
проекта раскрывается рядом с `.mtp`. Перенос проекта — `.mtp` + WAV по одному. Zip не делаем.

## Миграция

`.mtp` без `SMPL`: список строится из `Instrument.sample` всех инструментов. Имя ищется сначала в
банке по старому имени — найденная запись переименовывается в hex CRC (CRC по данным во флеше), а
пара `имя crc frames` дописывается в `/projects/legacy.idx`; затем в `legacy.idx` (сэмпл уже
мигрировал из другого старого проекта). Не найдено — missing. Первый save пишет папку. Старые
записи, ни на что не сославшиеся, — обычный кэш (уйдут при вытеснении или `Clear cache`).

## Конкурентность

Синт ищет сэмпл только на note-on: имя → линейный поиск в `live.samples` → `bank.find(key)`.
Список меняется (импорт, rename, delete, загрузка) только при остановленном движке, как и банк
сейчас, — гонок нет, отдельная таблица резолва не нужна.

## Тесты (native, lib/core)

- `project_io`: round-trip `SMPL`; старый файл без chunk.
- Синхронизация списка с банком на RAM-флеше: попадание в кэш, импорт, вытеснение, дедуп по CRC,
  missing.
- CRC32 по кускам = CRC целиком.
- Резолв имя → индекс после rename / remove / compact.
