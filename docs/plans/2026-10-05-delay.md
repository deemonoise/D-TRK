# Delay Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Tempo-synced mono send delay for INT tracks: per-instrument send, DLY fx lock, global params on PROJ.

**Architecture:** `mt::Delay` (core, hardware-free) owns no memory: an int16 ring buffer is handed in
(firmware: 4 s in PSRAM). `Synth::render` sums each voice into `mix_` and, scaled by the voice's send,
into `send_`; the delay adds its return to `mix_` before master volume / soft clip. Send = DLY lock or
`Instrument::send`, like the FLT / RES locks.

**Tech Stack:** C++17, PlatformIO native tests (Unity), ESP32-S3 Arduino.

Test command: `pio test -e native -f <suite>`. No commits (user rule).

### Task 1: `mt::Delay` DSP

**Files:** Create `lib/core/src/synth_delay.h`, `lib/core/src/synth_delay.cpp`, `test/test_synth_delay/test_main.cpp`.

API:
```cpp
class Delay {
 public:
  static constexpr float kScale = 8192.f;  // int16 line: +-4.0
  void setBuffer(int16_t* buf, uint32_t len);  // nullptr = off; clears it
  void clear();
  // mix[i] += return; line <- send + return * feedback. delay in samples, clamped to 1..len-1.
  // fb / tone / level: 0..127 (Project dly*). tone 127 = no filter (bit-exact delay line).
  void process(const float* send, float* mix, int n, uint32_t delay, uint8_t fb, uint8_t tone, uint8_t level);
};
```
Tests (write first, see them fail): impulse at sample 0 returns at sample `d` with gain level/127;
fb 0 = one echo only; fb > 0 = second echo smaller at `2d`; tone < 127 smears the impulse (peak < input);
no buffer = mix unchanged; delay >= len clamps; clear() silences the line.

### Task 2: Model + lock bit + fx

**Files:** `lib/core/src/model.h`, `model.cpp`, `fx_info.cpp/.h`, `test/test_fx_info`, `test/test_model`.

- `LockBit { kLockFlt = kFmMacros, kLockRes, kLockDly, kLocks }` (8 bits, `uint8_t lockMask`).
- `Fx::DLY` after `OFF`. `kInfo`: `{"DLY", "DELAY SEND", 0, 127, 64, false}`.
- `fxSynthOnly`: SLD..SLC or DLY.
- `Instrument::send = 0` (0..127).
- `Project`: `dlyTime = 3` (1..16 sixteenths), `dlyFb = 50`, `dlyTone = 90`, `dlyLevel = 100`; reset() sets them.
  `constexpr int kDlyTimeMax = 16`.
- Tests: fxNextCmd(OFF, 1) == DLY, (DLY, 1) == None, (None, -1) == DLY; fxSynthOnly(DLY); name "DLY";
  Project defaults.

### Task 3: Synth integration

**Files:** `lib/core/src/synth.h`, `synth.cpp`, `synth_voice.h`, `test/test_synth`.

- `Voice::send` (0..1), set in `control()`: `lockMask & kLockDly ? lock[kLockDly] : m.send`, / 127.
- `fx()`: DLY joins the FLT / RES lock case with `k = kLockDly`.
- `Synth`: `Delay delay_; float send_[kBlock];` `setDelayBuffer(int16_t*, uint32_t)`; `reset()` clears the line.
- `render()`: voice with send > 0 renders into a scratch segment, added to mix and send; else as before.
  After the loop: `delay_.process(send_, mix_, kBlock, delaySamples(), p_.dlyFb, p_.dlyTone, p_.dlyLevel)`.
  `delaySamples() = dlyTime (clamped 1..16) * 24 * tickSamples()`.
- Tests: send 0 output identical with and without a buffer; send 127 + note produces output after the note
  ended (echo) at the expected delay; DLY lock on a step with a note sets only that note-on's send; DLY on a
  step without a note changes sounding voices; no buffer = no echo.
