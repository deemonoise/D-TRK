# Встроенный звук: chiptune и сэмплер — дизайн

Дата: 2026-10-04. Основа — [future-audio.md](future-audio.md) (вариант 1: звук на самом S3). Здесь — принятые решения.

## Решения

| Вопрос | Решение |
|---|---|
| Вывод | только встроенный усилитель NS4168 (разъём SPK), моно, без пайки |
| Движки v1 | chiptune + сэмплер |
| Привязка инструмента | на дорожку (`TrackCfg`), смена посреди паттерна — PGM |
| Полифония | общий пул 16 голосов; режим MONO / POLY (до 4) в инструменте |
| Сэмплы | банк в отдельном разделе flash (~9,9 МБ), импорт WAV с SD |
| Частота | 32 000 Гц; сэмплы хранятся с родной частотой ≤ 32 кГц |
| Эффекты | SLD, VIB, ARP, VSL, OFS, CUT |
| Волны chip | pulse, triangle, saw, noise, metal + 16 wavetable в прошивке |

## 1. Путь звука

- NS4168 на I2S0, GPIO 35/36/37 (BCLK / LRCK / DOUT — сверить со схемой платы на этапе 1). 32 кГц, 16 бит, одинаковый сигнал в L и R.
- Мост: оба вывода SPK под сигналом, ни один не GND. Наушники — только изолированное гнездо, через 100–220 Ом последовательно; не соединять с GND платы и с входами других устройств.
- Аудио-задача на ядре 0, приоритет ниже движка секвенсора. Блок 128 сэмплов (4 мс), DMA, буферы во внутренней RAM.
- Микшер: голоса × громкость инструмента × громкость дорожки × общая громкость, soft clip, моно.
- Громкость по умолчанию 40 %.

### Связь с секвенсором

- `Sequencer` отдаёт события в `MidiSink`. Маршрутизатор в `engine`: дорожка `Out::Midi` — в UART как сейчас; `Out::Int` — событие голоса с меткой времени (мкс таймера движка) в очередь синта.
- Секвенсор для INT-дорожек вместо MIDI-байтов шлёт `SynthEvent` (note on/off, параметры эффектов, PBN, PGM). Номер дорожки уже есть в `SchedEvent::track`.
- Синт ставит событие в блок с точностью до сэмпла: `offset = (t − tBlockStart) · 32000 / 1e6 + 1 блок`. Задержка постоянная ~8 мс, без джиттера. MIDI-дорожки её не имеют (компенсация — позже, если понадобится).

### Ядро (`lib/core`, native-тесты) и железо (`src/audio`)

- `lib/core`: генераторы, сэмплерный голос (линейная интерполяция, фиксированная точка 16.16 или 32.32), ADSR, распределитель голосов, эффекты, рендер блока, парсер WAV, аллокатор банка (над абстрактным интерфейсом flash).
- `src/audio`: I2S, задача, `esp_partition_mmap` банка, импорт с SD.

## 2. Инструменты и проект

16 инструментов в проекте.

Общие поля: имя (8), тип CHIP / SAMPLE, громкость, транспонирование (±24), подстройка (±50 центов), ADSR, MONO / POLY, время SLD по умолчанию (портаменто в MONO).

- CHIP: волна (pulse, triangle, saw, noise, metal, wt1–wt16), скважность pulse, PWM-свип (скорость, глубина).
- SAMPLE: имя сэмпла (16), корневая нота, start, end, loop (off / forward / ping-pong), loop start, reverse.

`TrackCfg`: `out` (MIDI / INT), `instr` 0..15, `vol` 0..127. Для INT: PGM меняет инструмент дорожки, CHN игнорируется.

`Project`: `masterVol`, `preview` (предпрослушка в GRID).

Файл: формат уже чанковый, неизвестные чанки пропускаются. Новые чанки `INST` (инструменты), `TOUT` (out/instr/vol дорожек), `AUDI` (masterVol, preview). Версия остаётся 1. Старые проекты — все дорожки MIDI.

Сэмпл не найден в банке: голос молчит, имя в INST красное. Ссылка по имени — после повторного импорта снова работает.

## 3. Банк сэмплов

Разделы (16 МБ): nvs, otadata — на прежних адресах (настройки Wi-Fi сохраняются); app0 / app1 по 3 МБ (OTA работает); `samples` ~9,9 МБ (~2,5 мин при 32 кГц). Новую таблицу заливать один раз по USB.

Формат раздела:
- сектор 0–1: заголовок (magic, версия) + таблица 128 записей: имя (16), смещение, длина в сэмплах, частота, корневая нота, loop по умолчанию, флаг занятости;
- данные: моно int16, начало каждого сэмпла выровнено по 4 КБ;
- выделение — первая подходящая дыра; удаление освобождает; «уплотнить» сдвигает данные к началу.

Чтение — `esp_partition_mmap` всего раздела (лимит окна MMU на S3 проверить на этапе 1).

Импорт WAV: PCM 8/16/24 бит, моно/стерео (сведение), любая частота; выше 32 кГц — понижение до 32 кГц, ниже — как есть. Только при остановленном воспроизведении (запись во flash останавливает кэш). Источник — `/samples` на SD; Wi-Fi-страница получает загрузку `.wav` до 4 МБ в `/samples`.

UI: вкладка FILE, раздел SAMPLES — список (имя, длительность, размер), полоса свободного места, «импорт из /samples», «удалить» (с подтверждением, если сэмпл используется), «уплотнить».

## 4. Интерфейс и эффекты

- Вкладки: GRID, TRACK, BANK, INST, PROJ, FILE (по 80 px).
- INST: выбор инструмента 1–16 и типа, список параметров (`ParamList`), для SAMPLE — вид волны с маркерами start / end / loop (двигаются энкодером), PREVIEW (C4).
- TRACK: поля OUT, INSTR, VOL; CHN / PRG / CCA / CCB серые на INT.
- GRID: на INT-дорожке ввод ноты (энкодер, кнопки дорожек) сразу звучит, если `preview` включён.
- PROJ: общая громкость, предпрослушка.

| fx | Значение | Действие |
|---|---|---|
| `SLD` | 1–255 | глайд от прошлой ноты дорожки к ноте шага (без ноты — к последней); время ≈ значение × 4 мс |
| `VIB` | `xy` | вибрато: x — скорость, y — глубина до ±1 тона |
| `ARP` | `xy` | нота, +x, +y по кругу, 3 переключения на шаг |
| `VSL` | −64…63 | изменение громкости за шаг, плавно |
| `OFS` | 0–255 | старт сэмпла с доли `value/256` длины (только SAMPLE) |
| `CUT` | 1–N | оборвать ноту через N тиков, без release |

На MIDI-дорожках новые fx игнорируются и показываются серыми. RAT, GAT, CHD, PRB, TIE, NDG, STR, CND — на обоих выходах; PBN — питч голоса (±2 полутона); PGM — инструмент; CCA, CCB, VRN, NRN, CHN — только MIDI. LED дорожек вспыхивают и на INT.

## 5. Этапы

1. Аудио-путь: таблица разделов, I2S, задача, тон, замер тактов, `mmap`, проверка щелчков при перерисовке.
2. Chiptune: голоса, ADSR, распределитель, wavetable, маршрутизатор, TRACK, чанки, вкладка INST (CHIP).
3. Эффекты на INT, предпрослушка.
4. Банк: формат, импорт WAV, FILE → SAMPLES.
5. Сэмплер: голос SAMPLE, loop, reverse, OFS, вид волны; загрузка `.wav` через Wi-Fi.
6. Документация: README, руководство, предупреждение про мост SPK.

## Тесты

Native (Unity): частота и форма генераторов, ADSR, распределитель (кража, mono legato), каждый fx, маршрутизатор (MIDI-дорожка не попадает в синт), чанки и совместимость со старыми файлами, парсер WAV (8/16/24 бит, стерео, лишние чанки), аллокатор банка (дыры, уплотнение — flash в RAM), рендер блока (событие на нужном сэмпле).

## Риски

- Реальная стоимость голоса: при нехватке CPU — меньше голосов или ниже частота. Решается замером на этапе 1.
  - Этап 1: замер ещё не сделан — нужен прибор. Как снять: добавить `-DAUDIO_BENCH` в `build_flags` `[env:wt32]`, прошить, в Serial раз в секунду `audio bench: render N us (peak M) / 4000 us` (16 голосов: float-фаза, линейная интерполяция из раздела `samples`, огибающая). Если 16 голосов > 60 % — пул 12 (`kVoices`). Без бенча нагрузка видна в PROJ (`CPU NN%`).
  - `mmap` всего раздела `samples` (~9,9 МБ): результат (`audio: samples mmap ok` / ошибка) печатается в Serial при старте — тоже ждёт прибора. При ошибке — окна по 4 МБ по требованию.
- Внутренний звук отстаёт от MIDI на ~8 мс.
- Во время импорта звука и воспроизведения нет.
