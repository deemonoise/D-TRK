# Планы на будущее: 8 кнопок дорожек

Статус: решение принято, реализация отложена. Записано 2026-10-02.

## Что решено

- 8 кнопок MX, по одной на дорожку, **два ряда по 4**, без светодиодов.
- Обычный режим: **N** — выбрать дорожку N (курсор на неё), **Shift + N** — mute/unmute дорожки N.
- Режим редактирования: кнопки вводят ноты — **ступени выбранного лада** проекта (`scaleRoot`, `scaleType`).
- Solo с кнопок не нужен.

### Ввод нот в режиме редактирования

- Кнопка 1–7 — ступени I–VII лада, кнопка 8 — I ступень октавой выше.
- Лады короче 7 ступеней (пентатоники — 5, блюз — 6): лишние кнопки продолжают лад в следующую октаву (у пентатоники 6 = I+окт, 7 = II+окт, 8 = III+окт).
- Хроматический лад (`Chromatic`): кнопки дают ступени мажора от тоники (белые клавиши от `scaleRoot`).
- Октава — по ноте под курсором; если шаг пуст — по последней введённой ноте на этой дорожке, иначе октава 4.
- Нота пишется в шаг под курсором так же, как при вводе с энкодера/тача (undo-снимок, `writeStep`), затем курсор сдвигается на шаг вниз.
- Решить при реализации: что делает Shift + N в режиме редактирования (вариант — та же ступень октавой выше) и как вводить OFF.
- Чистую функцию «кнопка N, лад, тоника, октава → MIDI-нота» положить в `lib/core/src/scale.h` и покрыть тестами.

## Железо

Прямых пинов не хватает: свободны только GPIO 1, 2, 42 и 35–37. GPIO 35–37 не трогать, это I2S под будущий звук (см. [future-audio.md](future-audio.md)).

Решение — расширитель портов I2C на отдельной шине:

| Пин | Назначение |
|---|---|
| GPIO 1 | SDA (`Wire1`) |
| GPIO 2 | SCL (`Wire1`) |
| GPIO 42 | INT расширителя (активный низкий, `INPUT_PULLUP`) |
| 3.3V, GND | питание модуля |

- Чип: **PCF8575** (есть в наличии). 16 линий P00–P07, P10–P17, квазидвунаправленные, со слабой встроенной подтяжкой, выход INT. Адрес по умолчанию 0x20 (A0–A2 на GND), проверить перемычки на модуле.
- Кнопки: между P00–P07 и GND, внешние подтяжки не нужны. Перед чтением все линии записать в 1 (после сброса и так 0xFFFF). P10–P17 — запас.
- Нажатая кнопка читается как 0.
- Подтяжки SDA/SCL 4,7 кОм к 3,3 В — обычно уже стоят на модуле, проверить.
- Тач на GPIO 5/6 не трогаем: его шина внутренняя, и выведена ли она на разъём, не проверено.

## Прошивка

Модель уже готова: `TrackCfg::mute`, `Project::trackAudible()` (`lib/core/src/model.h`), mute сохраняется в файл проекта. Лады — `lib/core/src/scale.h`. Режим редактирования — `GridScreen::edit_` (`src/ui/grid_screen.h`). Нужны только ввод и действия.

1. `src/hw`: драйвер расширителя.
   - `Wire1.begin(1, 2)`, 400 кГц.
   - По спаду на GPIO 42 (прерывание ставит флаг) читать 2 байта порта (младший — P00–P07) в цикле ввода; плюс опрос раз в ~20 мс на случай пропущенного INT.
   - Антидребезг 5 мс, как у текущих кнопок; события «нажата кнопка N».
   - Нет ответа по I2C при старте — просто работать без кнопок дорожек.
2. Обработка в UI (там же, где Shift и Play):
   - режим редактирования — ввод ступени лада (см. выше);
   - иначе без Shift — выбрать дорожку N: перевести курсор сетки на дорожку N на текущем экране (или открыть экран дорожки — решить при реализации);
   - иначе с Shift — `t.mute = !t.mute` для дорожки N, как в `grid_screen.cpp:276`.
   - Перерисовка имён дорожек (цвет mute уже есть).
3. Тесты: логику «нажатие N ± Shift ± edit → действие» и «ступень → нота» вынести в `lib/core` и покрыть native-тестами.
4. README: новые пины в таблицу подключения, руководство `docs/manual.html` — раздел про кнопки.

## Корпус — готов

Вариант уже в `enclosure/case.scad`, включается `trk = true`; STL — `enclosure/stl/case8_top.stl`, `case8_bottom.stl` (планки общие, `clamp.stl`).

- Корпус 98,4 × 145,4 × 26,5 мм (без кнопок — 98,4 × 105,4).
- Единая сетка 4 × 3, шаг 19 мм, по центру ширины. Верхний ряд (у экрана): Shift — колонка 1, Play — колонка 2, колонка 3 пустая, энкодер — колонка 4. Ниже кнопки 1–4, у переднего края 5–8.
- Переменные: `trk_pitch`, `trk_y0` (передний ряд), `pcf_w`, `pcf_d`, `pcf_y`. `sh_x`, `pl_x`, `enc_x`, `ctrl_y` действуют только без `trk`.
- На крышке бортик под модуль PCF8575 (по умолчанию 32 × 20 мм — замерить), под блоком кнопок; до низа выводов MX ~11 мм.
