# 6 FX, detail view одной дорожки, сэмплы до конца, FX OFF — дизайн

Дата: 2026-10-05.

## 1. Баг Transpose

`Transpose...` в GRID — разовый сдвиг нот (`mt::transposeSel`). Диалог помнил последнее значение:
после +12 показывал +12, выставленный 0 + OK ничего не делал (`amount_ == 0`).
Решение: `TransposeDialog::open()` сбрасывает `amount_` в 0; режим SCALE/CHROMATIC запоминается.
Вернуть = применить обратный сдвиг.

## 2. Шесть FX на шаг

- `model.h`: `constexpr int kFxSlots = 6; FxSlot fx[kFxSlots];`, `sizeof(Step) == 14`.
  `isEmpty()`, `find()` — цикл; новый `hasFx()`.
- `hasFx()` вместо `fx[0] || fx[1]`: sequencer (2 места), обзор GRID.
- Файл `.mtp`: чанк `PATN` прежний, размер шага из размера чанка:
  `size == header + 8 * len * 6` — старый (2 FX), `* 14` — новый. Пишется всегда 14.
- MIDI import: `slot < 2` -> `slot < kFxSlots`.
- `StepExpand`: `kMaxStepEvents` с запасом под 6 контролов.
- Память PSRAM: проект x2 + 32 undo + буфер обмена ≈ 930 КБ (было ≈ 310 КБ). При нехватке — undo 16.

## 3. Detail view — одна дорожка

- Колонки: NOTE 32 | VEL 32 | 6 x (CMD 32 + VAL 32) = 448 px (вся ширина после номеров шагов).
  Тонкие dim-линии перед каждой FX-парой. Шапка: «N NAME» и FX1..FX6.
- Поля `kNote, kVel, kFx1, kVal1 ... kFx6, kVal6` (14). Shift+поворот — по полям, за краем — на
  соседнюю дорожку (как раньше). Видна текущая дорожка.
- Тач: hit-test по одной колонке; тап в строке имён в detail ничего не делает.

## 4. Сэмплы и FX OFF

### 4a. Сэмпл звучит до OFF
SAMPLE-голос на дорожках 0..7 игнорирует note off (Loop OFF, FWD, PING, слайсы).
Гейт/GAT/TIE на него не влияют. ADSR работает (decay/sustain 0 может погасить).
Останавливают: стоп транспорта, OFF в колонке ноты, FX OFF, CUT, choke.
Превью-трек (`kPreviewTrack`) — по-старому, note off гасит (иначе вечное прослушивание лупа).

Моно-сэмпл: следующая нота всегда перезапускает сэмпл (раньше «легато держит позицию» работало
только из-за не отпущенного гейта). Legato-продолжение сэмпла — только при SLD.

### 4b. Choke
Нота SAMPLE на дорожке гасит её прежние сэмпл-голоса фейдом 3 мс (`Env::fade`), кроме голосов того
же шага с другой высотой (аккорд CHD / STR). Ретриггер той же ноты (RAT) гасит предыдущий.
`TrackRt::gen` растёт на `kSynthStep` с нотой, `Voice::gen` = gen при note on.

### 4c. FX OFF (NOTE OFF)
`Fx::OFF` в конец enum (перед `Count`), значение 0..96 тиков, по умолчанию 0, MIDI и INT.
Момент `off = nudge + N тиков` от старта шага (на шаге с нотой — не раньше `kMinGateUs`):
- ноты шага: NoteOff не позже `off`; удары RAT с NoteOn >= `off` не играют; TIE отменяется;
- висящий tie дорожки отпускается в `off`;
- INT-дорожка: синту 0xFF (release track) в `off` — гасит всё, включая сэмплы и DRUM.
`ExpandCtx.tps` (тиков на шаг), `ExpandOut.offUs` (-1 = нет OFF).

### 4d. OFF в колонке ноты
На INT-дорожке дополнительно шлёт 0xFF в старт шага (и при пропущенном шаге).
`dispatch` не пускает 0xFF на MIDI.

## Тесты (native)
- model/project_io: `sizeof(Step)`, `find` в слоте 5, round-trip 6 FX, загрузка старого PATN (6 Б).
- expand: OFF на пустом шаге, OFF урезает гейт, RAT после OFF выпадает, TIE отменён, min gate.
- sequencer: OFF шлёт 0xFF на INT, не шлёт на MIDI; OFF-нота шлёт 0xFF; tie отпускается в OFF.
- synth: note off не гасит сэмпл (луп и без), гасит на превью; choke между шагами; аккорд не
  гасится; RAT той же ноты гасит; 0xFF гасит; моно-сэмпл перезапускается.
