# UI: отмена правки, вид выбора вейвтейблов, Edit step — дизайн

## 1. Отмена правки Shift+клик
Только в режиме правки значения; вне правки Shift+клик работает как раньше.

- **ParamList** (INST, TRACK, PROJ, диалоги): при входе в правку запоминается текст значения
  (`format()`). Экран может задать область `setEditScope(ptr, size)` — тогда при входе снимок
  области, при отмене memcpy назад под `lockProject`. INST — текущий инструмент (смена типа,
  маркеры редактора сэмплов), TRACK — `TrackCfg` дорожки. Без области — откат шагами `edit(±1)`
  до совпадения текста (лимит итераций). Отмена выходит из правки, тост `CANCEL`.
- **GRID**: при входе в правку и при каждом переходе курсора внутри правки — снимок ячейки
  (паттерн, дорожка, шаг, `Step`). Shift+клик в правке возвращает её и выходит. Если в сессии
  менялась только эта ячейка — `dropUndo()`. Вне правки Shift+клик — смена вида.
- **BANK chain row**: снимок строки при входе в правку, Shift+клик — откат.
- **FILL**: в правке Shift+клик — отмена, вне правки — reseed.

## 2. Импорт вейвтейблов как импорт файлов
Шапка `IMPORT WT <хвост пути>` + `SD OK` справа, без кнопок. Строка 0: `< Back` в корне
(к таблицам) / `< Up (..)` в подпапке; папки со `/`, затем *.wav. Кольцевая прокрутка, drag,
EncLong — к таблицам. Пусто — тост как в FILE.

## 3. Список таблиц
Тот же вид: строка 0 `< Back` (отмена), вшитые, таблицы проекта, `IMPORT...`. Превью кадра 0
справа. Кольцевая прокрутка. Автопрослушки нет: поворот/тап двигают курсор, клик или тап по
выбранной — установить и закрыть. EncLong — отмена. Таблица ставится только при выборе.

## 4. Edit step в GRID
`editStep_` 0–16, по умолчанию 1, RAM. После ввода ноты кнопкой курсор идёт на N (0 — стоит);
лейны drum-дорожки курсор не двигают. Меню GRID: `Edit step: N` — список 0–16. Шапка GRID:
`STEP N`.

## Проверка
native-тесты + сборка wt32; на железе — чек-лист в плане.
