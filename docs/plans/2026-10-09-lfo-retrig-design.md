# LFO Retrig ON / OFF — дизайн

Сейчас фаза LFO у каждого голоса своя и сбрасывается на note-on (`Synth::resetLfos`). Нужен LFO, не
привязанный к началу ноты.

## Поведение
Строка `Retrig: ON / OFF` для каждого из 4 LFO (INST → LFO), после Sync. ON — как сейчас, по
умолчанию; старые проекты звучат как раньше.

Retrig OFF — одна фаза на инструмент (как Mono LFO у Virus): все голоса и все дорожки с этим
инструментом видят одно значение LFO, нота попадает в текущую фазу.
- FREE + OFF: фаза крутится непрерывно.
- TEMPO + OFF: фаза привязана к транспорту — при старте воспроизведения (`Sequencer::start`)
  сбрасывается в 0, дальше идёт в темпе: LFO 1 BAR начинается с начала такта, прогоны одинаковы.
- RND при OFF — одно случайное значение на период, общее.

## Реализация
- Фазы: `Synth` хранит `float instLfoPhase_[kInstruments][kLfos]` и `instLfoRnd_`; двигаются раз
  за блок рендера (не на каждый голос), только для LFO с depth != 0 и Retrig OFF.
- Транспорт: `Sequencer::start` шлёт в синт одно сообщение `0xFA` (со временем старта, как 0xFE);
  `Synth::apply` на 0xFA обнуляет фазы TEMPO+OFF. Офлайн-рендер идёт тем же путём.
- Хранение без смены формата: байт sync — бит 0 TEMPO, бит 1 Retrig OFF. Кодек (`inst_codec.cpp`
  pack/unpackLfo) хранит `sync & 3`; в коде хелперы `lfoTempo(sync)`, `lfoFree(sync)` вместо
  `sync ? ...`. Старая прошивка прочитает FREE+OFF как TEMPO — только при откате, приемлемо.

## Проверка
native: OFF — два голоса, взятые в разное время, дают одно значение LFO; ON — как раньше; TEMPO+OFF —
после 0xFA фаза 0; кодек — round-trip бита и чтение старых значений 0/1. Мануал: строка Retrig в
таблице LFO, абзац про сброс фазы. Железо: фильтр «дышит» поверх арпа, LFO 1 BAR с начала такта.
